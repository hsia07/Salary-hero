# 鐵時｜Q 版角色造型鎖定規格 v1.0

狀態：**設計基準鎖定，正式素材未驗收**。依據上一輪單人完整角色候選圖，供後續所有單體生成、分層、動畫、建模與驗收使用。

## 每次生成前
**先重新完整閱讀 `docs/FORMAL_ART_RULES.md`，再閱讀本檔。** 任一檔無法取得，停止生成。每次圖片生成請求均重新讀取，不能只看摘要。

## 不可改變的角色識別
- 名稱：打卡守衛・鐵時；稀有度 SR；職責為坦克／守護／團隊支援。
- **Q 版比例：2.5 頭身**（以頭頂至鞋底量測，容許 2.4–2.6），頭大但**身形瘦削**，不是壯漢、肥胖或幼兒比例。
- 臉：疲憊半垂的暗紅眼、微鬍渣、右頰一小塊白色貼布；神情倦怠、克制，不是邪惡或過度可愛。
- 髮：凌亂深黑／炭黑髮，**一束明顯白髮**；白髮是固定識別，不可用紫色反光取代。可保留少量暗紫反光。配件簡化，避免無意義的堆疊。
- 衣：鬆散白襯衫、黑／暗紅鬆領帶、深色長褲、黑色靴子；外層紫黑披風／外套，少量金色邊飾。服裝需可拆解、結構合理。
- 盾：**高大的直立矩形防暴盾**，紫黑主色＋金屬金包角，**中央橫向紅色數位顯示器**。未最終覺醒時嚴格為 `08:59`；只有最終和解覺醒才切換 `09:00`。字形後製，不靠生成模型猜數字。
- 盾牌高度在角色身高約 65%–80%，具有明確厚度與手柄；可遮住身體局部，但不得遮住主要臉部識別。
- 亡靈小燈／阿誠／阿遠不是常駐跟班，不出現在**單人造型基準圖**。

## 構圖鎖定
- 每張**角色基準圖只顯示鐵時一人**，正面或三分之四視角、完整頭到腳、盾牌全貌。
- 不要展示板、分鏡表格、UI、技能圖示、文字、其他角色、雜亂背景。
- 透明背景優先；邊緣乾淨，深色／淺色底都須可辨認。
- 清晰的日式 Q 版 RPG 美術，輪廓線一致、色塊有秩序、無隨機雜點／噪訊／雜邊／AI 錯誤。
- 單張候選圖**不是分層素材**。正式分層需重新製作可編輯來源，獨立部件、透明輸出、錨點、動作幀；不能直接從展示圖粗裁。

## 動畫拆分與驗收順序
1. 確認角色正面基準圖：頭身比、白髮、眼神、服裝、盾牌與 08:59。
2. 正／斜／側／背視角角色比例對照；不得自行加飾品。
3. 獨立分層：前後髮、頭／眼／口、軀幹、雙上臂／前臂／手、雙腿、披風、盾牌外殼／顯示器／握柄。
4. 待機、移動、盾擊（真實命中）、格擋、受擊紅閃、倒地的獨立幀及動作驗收。
5. 在手機直式六人隊伍戰場驗證可讀性與遮擋。
6. 只有完成 `docs/FORMAL_ART_RULES.md` 全項 QA 才能宣告正式美術完成。
