# 《薪水勇者》地獄星期一：副本／波次／敵人／Boss 四層規則 V1

> 2026-11-12 使用者修正：**不是從第一波起就連打四次文書牛魔**。正式副本先清若干波普通怪、精英，再進入魔王戰。原本 GitHub V4 是單一 Boss 複製四段血條的**動畫測試原型**，不代表正式副本流程完成。此文件為設計決策與待實作規格。

## A. 四層責任歸屬（不能混用）

| 範圍 | 使用對象 | 負責的事情 | 例子 |
|---|---|---|---|
| Dungeon 全域 | 副本內所有戰鬥波次 | 星期／副本基礎倍率、挑戰規則、獎勵、背景主題 | 地獄星期一：所有敵人 HP ×1.65、ATK ×1.4；EXP ×2；稀有掉率提升（尚未定數值） |
| Wave 波次 | 指定第 N 波 | 生成的怪物組合、入場音效、地形／短期環境事件、該波完成條件 | 第 2 波印表機卡紙，第 3 波精英主管登場 |
| Enemy 怪物個體 | 特定怪物在場時 | 該怪自己的 AI、普通攻擊、技能、個體 Debuff 與抗性 | 文件小鬼的流血、精英主管的破盾 |
| Boss 首領個體 | 僅 Boss 波且 Boss 存活時 | 魔王能量條、專屬招式、召喚、狂暴、Boss 專屬演出 | 文書牛魔七光束殲滅砲、巨爪拍擊、無限會議結界 |

*羈絆、職業技能、裝備是玩家隊伍技能來源，不是副本全域技能。狀態 `Dxx/Bxx` 是共享機制，同一種「過勞」可以由不同敵人施加不同強度，但必須記錄 `sourceId`、`scope`、命中率／CD。*

## B. 首版建議四波（可配置變成 2～5 波）

| 波次 | 類別 | 建議敵人 | 主要玩法／Debuff | 主題美術 |
|---|---|---|---|---|
| 1 | 小怪 | 文件小鬼 ×2、鬧鐘小怪 ×1 | 練習自動集火；以普通傷害為主，偶爾 D19 緩速 | 灰暗辦公室、工牌飄浮 |
| 2 | 混合小怪 | 卡紙印表機 ×1、文件小鬼 ×2、遠程報表怪 ×1 | 印表機偶爾 D01 流血／報表雨；隊伍護盾開始重要 | 影印機噴紙、辦公光管閃爍 |
| 3 | 精英關 | **催件主管（精英）** ×1、文件小鬼 ×2 | 精英的 D08 破盾或 D34 無限會議；打贏後進入短暫轉場 | 主管工牌紅光、鏡頭推進 |
| 4 | Boss 關 | **加班狂課長・文書牛魔** ×1；其個體技能可召喚小怪 | 專屬能量條、七光束大招、60% 狂暴；不把小怪波技能錯算成 Boss 被動 | 已核准的紅月辦公室，巨型 Boss 獨立精靈 |

- **副本波次數**和**Boss 自身階段數**是兩個不同概念：這裡是四波副本（其中最後一波是 Boss），Boss 關裡還有 100%～61% 和 ≤60% 的兩段技能邏輯。
- 普通怪可在既定 32 種普通怪造型基礎上換皮／共用行為原型，**菁英／Boss 必須有獨立正式美術與招式**。本表的新怪名為候選，非已製作資產。
- 所有波次預設自動戰鬥、陣容不變；玩家可在正式進場前編隊。戰鬥中不出現手動攻擊選單。

## C. 全域難度與獎勵：一次計算，不和 Boss 倍率重複

```js
dungeon = {
  id: "hell-monday",
  weekday: 1, // 星期一
  globalModifiers: {
    enemyHpMultiplier: 1.65,
    enemyAttackMultiplier: 1.4,
    expRewardMultiplier: 2,
    rareDropMultiplier: null // 「提高稀有掉率」已確認，但具體加成待測試
  },
  waves: ["mobs", "mixed-mobs", "elite", "boss"]
};
// 入場時獲得：modifiedEnemy = instantiate(enemyBase, globalModifiers);
// Boss 基礎技能倍率、狂暴倍率不可再套入第二次 1.65 / 1.4。
// 經驗、稀有掉落僅在結算時使用，不能每波重複領整副本倍獎。
```

- 「厭世」目前當作副本主題稱呼，**不是文書牛魔個人被動**；若要做全域 `D32 週一開機失敗`，另以獨立全域規則定義「每波入場時」可施加，但先不把它與 ×1.65／×1.4 疊起來，避免初期太難。
- Global 只用於屬性／獎勵統一倍率。特定怪個人擲骰施加 D32 是 Enemy 的技能，不會自動給每波所有怪。
- Boss 技能如 `無限會議結界` 的範圍僅在 Boss 波，不能帶回第一、第二波。

## D. 跨波持續：有消耗，但不能故意磨死玩家

1. **隊伍 HP、MP／指揮能量、戰鬥死亡狀態**：預設跨波繼承；死亡隊友不自動復活。
2. **控場／異常狀態**：硬控（暈眩、冰封等）於波次結束解除，並播放結束動畫；DOT 在波次結束停止，不跨場景無緣由持續扣血。
3. **一般臨時 Buff**：若持續秒數還沒到，可以跨波保留剩餘時間但轉場不計時；「只能開場觸發一次」的效果以副本開始判定，不因換波觸發四次。
4. **波後小額恢復**：建議每完成普通／精英波，存活隊友恢復**最大 HP 8%～12%**；正式值須平衡測試，**不採 V4 原型每波直接 +47 HP 百分點**。換波時應有精緻回血、取得碎片或通關提示。
5. **魔王進場**：真正的 Boss 才在第 4 波生成；Boss 個人 HP/怒氣/冷卻初始全新，不承接前 3 波「Boss HP」。精英技能不能無故留在場上。
6. **魔王大招召喚怪**：加入 Boss 波的 `spawnedByBoss` 怪物；它們跟一般波次小怪是同類型戰鬥實體，但來源標記為 Boss 技能，不額外算成第 5 波。

## E. 程式應有的四個分離模組

- `dungeon-definition`：波次列表、全域效果、獎勵表、難度版本（標準／挑戰／噩夢）
- `wave-director`：敵方陣容、波次完成條件、切波獎勵、轉場鏡頭
- `combat-status-engine`：共用 72 種 Buff／Debuff、來源與時間、疊層限制、角色美術掛點
- `boss-controller`：只有 Boss 創建後才註冊「巨爪、文件、藍條、七光束、召喚、狂暴」；Boss 死亡時立即卸載

建議資料事件順序：
`DUNGEON_START → WAVE_START → ENEMY_SPAWN → COMBAT_AUTO → WAVE_CLEAR → REWARD_PREVIEW → (NEXT_WAVE or BOSS_INTRO) → BOSS_PHASE_CHANGE → BOSS_DEFEATED → DUNGEON_REWARD`

## F. 施工門檻／驗收

- [ ] 第一波畫面只有小怪，不能一開始就出現文書牛魔大模型。
- [ ] 第三波精英有自己的攻擊、受擊與異常狀態特效。
- [ ] 第四波才出現巨型牛魔與 Boss 血條／藍條；第 1～3 波不得載入 Boss UI。
- [ ] 星期一 ×1.65 HP、×1.4 ATK 在所有波次只套用一次，並以測試驗證沒有重複乘。
- [ ] 隊員 HP 跨波持續、波後恢復合理；暈眩、流血與解除特效時間正確。
- [ ] Boss 七光束各自命中七個存活角色，對應 Debuff 數值與圖層不錯位。
- [ ] 通關才結算整份副本掉落；稀有掉率設計另驗證。
- [ ] 正式美術 9:16、無捲動，所有技能與狀態具有分層透明素材及實際命中動作。

**現況**：本文件僅將副本規則與 Boss 技能的責任分清。V4 仍是相同 Boss 場景反覆變更 HP 的試玩原型；並未實作正式小怪→精英→Boss 的完整流程。
