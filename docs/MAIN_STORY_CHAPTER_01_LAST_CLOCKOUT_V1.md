# 《薪水勇者》世界主線正式劇本 v1：第一章〈最後一次打卡〉
**狀態：正式敘事初稿／可供關卡與分鏡製作，尚未實裝。** 這是有場景、台詞、互動和後果的故事稿，不是世界觀提案。人物對白可在配音與演出階段微調，但已確立的死亡與召喚規則不得改寫。

## 世界觀鐵律（全60名可招募角色）
1. **每個角色都在各自原本世界「工作期間」死亡，死亡之後才抵達召喚世界**。工作可為醫護、貨運、神職、救援、司法、巡夜、收魂等；不是只有人類辦公室工作。角色不可只是昏迷、失業、傳送、被召回或在原世界仍存活。
2. 自主機械生命的唯一人格核心不可逆終止，視為死亡；冥府原住民在工作時魂體／魂核二次消亡，才被召喚；神話與異常生命同樣須在工作期間生命或神魂終止。
3. 召喚世界不是原世界的公司或地獄，**召喚不等於復活**；原世界留下的人不會因召喚而自動獲救，死亡造成的損失不可取消。
4. 不同原世界的角色不預設生前相識；跨世界人物恩怨始於召喚後。所有登場者的時間線需在正式分場稿中逐一核對。
5. 故事可以有悲劇、喜劇、背叛與不和解，但不可每人重演「揭發黑幕→救人犧牲→獲得原諒」。
6. 鐵時火災、三魂一盾、08:59→09:00是已鎖定設定，不能在世界主線裡另編一個互相衝突的死亡原因。

## 第一季大方向（故事弧線，不等於已完成劇本）
- 第一章〈最後一次打卡〉：召喚者到來；公會與登記局首次衝突；鐵時與七號交惡。
- 第二章〈誰替亡者簽字〉：白律與赫斯公開審理強制登記條款，判決並非大團圓。
- 第三章〈價碼與名字〉：伊芙與薇菈爭奪一批召喚資料的處置權；資料背後有真正的當事人。
- 第四章〈安靜的舞台〉：梨奈與露希亞為公會慶典的廣播權爭執；群眾安全與公開聲音無法兩全。
- 第五章〈沒有刪除鍵〉：蘇妲與墨言追查被更動的登記詞條，發現各方都有隱瞞。
- 第六章〈下班以後〉：三大勢力分裂重組，敵對者在共同災難下暫時合作；不強迫和解。

# 第一章〈最後一次打卡〉
**建議長度**：25–35分鐘，6個主要場景、3場可玩互動、1場正式戰鬥、2個後續關係旗標。玩家不需讀完大量世界觀說明才能開始操作。

## 場景1｜08:59，火場的門
**演出**：黑畫面。只聽見警鈴、急促腳步與一聲不斷重複的「門禁未授權」。一枚電子鐘顯示08:59。畫面不完整重演鐵時既定18場火災劇情，只擷取不改寫事實的瞬間。
- 鐵時（喘息）：「裡面還有人。」
- 門禁：「權限不足。」
- 鐵時：「我不是來打卡的。」
- 門禁：「請返回指定崗位。」
- 鐵時用盾抵住門。鏡頭切黑；遠處三個聲音交錯喊他的名字。
**轉場**：沒有顯示「復活成功」，只有打卡機吐出一張空白卡片。
**系統字幕**：「原世界：工作死亡已確認。來源記錄：不完整。」
**設計註記**：這是鐵時死亡後召喚的敘事入口；不得以空白卡片暗示他只是夢醒或假死。

## 場景2｜公會前台，沒有姓名的表格
**場景美術**：舊式旅館改建的下班公會。木桌、修補過的旗幟、沾著咖啡漬的委託板；魔法登記水晶在櫃檯後方發亮。不是純文字UI。
- 櫃檯員：「歡迎。姓名？」
- 鐵時：「……鐵時。」
- 櫃檯員：「生前職務？」
- 鐵時：「保全。」
- 櫃檯員翻過卡片，停住。
- 鐵時：「怎麼了？」
- 櫃檯員：「你有沒有……最後一次下班的記憶？」
- 鐵時看著手上的燒痕，沒有回答。
玩家第一次可以操控：走到櫃檯、觸摸打卡卡片、查看牆上的公會規則，或先去聽角落的爭吵。
**重要**：所有可招募者都死於原世界的工作中；櫃檯問的是記憶完整度，不是在確認角色是否死亡。

## 場景3｜門外的機兵
門外響起機械聲。七號正在檢查進入公會的人。
- 七號：「訪客請出示有效通行證。」
- 鐵時：「這裡也要？」
- 七號：「這裡尤其需要。」
- 鐵時：「有人受傷你也要先看證件？」
- 七號：「我曾經不看證件。也曾經只看證件。兩種情況都有人受傷。」
- 鐵時沉默了一瞬：「那你現在怎麼選？」
- 七號：「我還沒算出答案。」
此時一名陌生召喚者衝到門前，手上抱著一只會震動的封存箱；身後有追索封存物的無主機械。陌生人沒有通行證。
- 七號：「禁止通行。」
- 鐵時：「先讓他進來！」
- 七號：「箱內有危險物。」
- 陌生人：「箱子裡是我的名字！」
**玩家互動A：門禁抉擇**。可先協助七號掃描箱子，或協助鐵時打開側門。兩條路都能救人，但掃描路線延誤封存箱冷卻、側門路線讓機械追入；不設單一絕對正解。
**後果旗標**：`trust_seven`、`trust_tieshi`，兩者可同時低或同時高，不強迫二選一。

## 場景4｜第一次並肩戰鬥
追索機械突破公會外牆。不是「七號突然變邪惡」，也不是鐵時與七號立刻和解。
- 七號：「目標三，右側一具正在充能。」
- 鐵時：「你擋右邊，我護住那個人。」
- 七號：「你沒有指揮權。」
- 鐵時：「那你要不要自己選？」
七號停頓0.4秒，展開防暴盾。
- 七號：「……選擇接受。」
**戰鬥教程**：六人編制在此先以少數試用角色出場，不憑空加入未解鎖英雄。敵人分散索敵：近戰優先可接觸目標、遠程優先可射程內脆弱單位；七號攔截、鐵時保護封存者。攻擊須實際命中，受擊紅閃，護盾需有分層美術。
**戰後**：七號沒有說「我懂人類了」。它記錄鐵時擅自開門造成的牆體損傷；鐵時也記錄七號因等待掃描延誤的時間。

## 場景5｜白律與赫斯的第一場爭論
封存箱打開，裡面是一張只寫了「同意」的召喚登記紙。那名陌生人指著紙：「我沒有簽。」
登記局代表進入公會，要求依法收回未登記者的通行權。白律上前要求出示授權依據。赫斯是被請來旁聽的裁決者，尚無權直接代表登記局作出最終判決。
- 白律：「沒有簽名，怎麼算同意？」
- 登記員：「死亡後的召喚屬於緊急保護程序。」
- 赫斯：「緊急程序可以暫時代替同意，但必須接受審查。」
- 白律：「那審查之前，人要被關在哪裡？」
- 赫斯：「……這正是我來看的。」
- 鐵時：「你們能不能先問他想去哪？」
- 陌生人：「我想知道，為什麼我的名字會被放進箱子。」
**玩家互動B：聽證前蒐集**。可訪談七號、登記員、封存者；每人掌握一部分事實。這不是找到一份「邪惡公司證據」就通關的調查，而是建立有矛盾的證詞。
**不可逆後果**：封存者的姓名在公會公開登記後，會被追索機械定位；若不公開，則無法領取正式醫療資源。後續章節承接。

## 場景6｜公會的第一條新規則
深夜。眾人聚在修好的門前。登記局送來一份暫時協議：允許公會收留未登記者，但要求每天回報人數。
- 七號：「每天回報可以降低失蹤率。」
- 鐵時：「也能讓人更容易被找到。」
- 白律：「問題不是回不回報，是誰能看到。」
- 赫斯：「我會要求設置獨立審查。」
- 白律：「你說『會要求』，不等於他今晚有地方睡。」
七號把自己的備用通行證放到桌上。
- 七號：「此證僅能開啟側門。無法保證安全。」
- 鐵時看了它一眼：「夠了。至少今晚夠了。」
**結尾演出**：公會門外的雨停了。那張空白打卡卡片浮現一句話：「尚未下班。」
鐵時把卡片翻過來，背面仍是空白。
**章末旁白**：「死亡讓他們離開了原本的工作。卻沒有替他們決定，下一份工作該怎麼活。」
**伏筆**：有人在遠處登記局檔案室，把「未登記者」改成「待回收資產」；只看見一隻手，不指認為任何已知英雄，以免預先洗黑某個角色。

## 第一章製作驗收
- 不以表格作主要玩法；櫃檯、門禁、戰鬥、聽證都是有實景、角色動作、互動的場景。
- 鐵時與七號既非永遠敵人也非一戰變朋友；關係狀態持續到後續章節。
- 白律與赫斯初次見面在召喚後，不追認生前共同歷史。
- 登記局有合理的安全考量，但存在可被濫用的制度；不能直接定性全員反派。
- 封存者是**臨時劇情NPC**，同樣須設定原世界工作死亡原因，正式製作前補全，不得設定成只是意外傳送。
- 第一章故事的通關選項不影響玩家已持有角色或造成永久錯失英雄。
- 本稿尚未繪製分層美術、音效、戰鬥動畫或編寫程式，不能宣稱已可玩。
