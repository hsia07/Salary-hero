# 《三萬份判詞》V2：文化抹除版

狀態：取代V1的修訂初稿，尚未定稿。兩位英雄各自原世界工作死亡後才召喚。

## 一、修改文字

蘇妲為換取狐族難民名額，把『待登記』改成『不具合法身分』；清目明知缺乏聽證仍核章。兩人都知道後果，並非被單一反派操縱。

## 二、被抹去的街

織語人的街道、學校、病歷在行政系統中消失。霜婆組織口述歷史，青年織冬反對恢復舊名，因為他想獲得新的醫療身分。居民有各自意志。

## 三、錯誤的補償

蘇妲提議用狐族身分代替織語人身分，霜婆拒絕：『我們不是你的狐族。』清目提出緊急復權，卻必須先承認自己的核章違法。

## 四、雙方自證其罪

兩人分別公開交易條件與違規核章，失去職務；修正法律也無法讓已失去母語的孩子立刻找回語言。

## 五、分歧的名字

部分居民恢復舊名，部分選擇新名，另一些拒絕登記。霜婆在此版本存活並主持口述檔案，與舊V1死亡版本互斥；舊稿僅留作歷史。

玩法：玩家取得居民同意後採集街景、口述與文件，不能強制任何人公開原名。

核心損失是文化與身分被抹除，不是又死一位NPC。
