# 《薪水勇者》S1 六大副本場景與首領登場演出規格 v0.1

狀態：美術與關卡規格，非已完成資產或程式功能。優先級高於卡牌 UR/MR 沉浸式動畫。

## 核心原則
- 每個副本都有獨特的入口、一般戰鬥區（至少兩種構圖）、菁英區、魔王房入口、魔王專屬房、戰後畫面。
- 不以單張背景換色、CSS 幾何拼接或單純平移角色代替正式美術動畫。
- 所有場景以直式手機單畫面、無頁面捲動為驗收標準，戰鬥介面不遮擋主角與首領。
- 場景資產需包含：遠景、中景、地面、前景遮擋、互動物件、環境光/粒子、首領出場前後狀態。各層獨立透明素材。
- 4–7 秒首領登場動畫，首次進場播放；始終有可點擊的「跳過」；重打可設定自動跳過。動畫結束或跳過都進入同一戰鬥初始狀態，不能造成額外傷害或獎勵。
- 首領戰前可用簡短黑屏或淡出切換音樂，避免兩首配樂直接重疊。
- 動畫必須有實際動作畫面、特效與鏡頭設計，不能只有文字描述或角色晃動。

## 場景與玩法的關係
- 各副本至少一種有辨識度的環境事件（可視覺提示），不必一開始全部實裝，但不可讓六個副本只是換背景。
- 每個首領至少兩階段視覺變化：普通／危險；菁英怪可重用通用骨架，首領必須有專屬輪廓與登場動畫。
- 場景轉場、首領登場、勝利結算三者必須由遊戲狀態機控制，不靠固定等待時間硬切；跳過需安全中斷動畫。
- 劇情伏筆：第 4–6 副本開始出現前任勇者工牌，保留世界觀逐步揭露。

## 分層素材清單（每個副本）
- bg_far.png, bg_mid.png, ground.png, foreground.png
- prop_*.png（可互動道具，分離透明底）
- fx_*.png / spritesheet（環境特效，實際動畫幀）
- boss_room_far.png, boss_room_mid.png, boss_room_ground.png, boss_room_foreground.png
- boss_intro_*.png（分鏡及角色動作幀，正式演出素材）
- boss_idle/attack/hurt/skill/death（專屬動畫狀態）

## 製作順序
1. 副本 01：入口、兩種一般戰鬥背景、魔王房、首領登場與跳過機制，完整垂直切片。
2. 以 01 的狀態機、分層渲染與資產規格複製技術，不複製美術，擴展副本 02–06。
3. 完成六副本視覺差異後，再集中投入高稀有度卡牌沉浸式演出。

## 驗收
- 手機直式畫面完整顯示，無捲動，主角/敵人/重要特效不被 HUD 擋住。
- 首領動畫首次完整、重打可跳過、任意時點跳過可安全進入戰鬥。
- 每副本能看出明顯不同的世界與魔王房，不靠文字標籤辨識。
- 正式素材為獨立透明分層圖或逐幀動畫，不以概念展示圖冒充。
