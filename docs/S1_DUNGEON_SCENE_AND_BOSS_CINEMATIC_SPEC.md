4. 會議試煉場（Lv.61–80）：圓形會議競技場。
5. 伺服器塔（Lv.81–100）：伺服器尖塔與纜線。
6. 茶水休憩境（Lv.101–120）：咖啡休息區。
7. 人資審判廳（Lv.121–140）：HR 法庭。
8. 總公司・核心（Lv.141–160）：公事包晶體核心。
9. 離職深淵（活動限定）：破碎辦公橋與出口標誌。

以上名稱、等級範圍與主題來自既有場景設計 v2.0，不可擅自替換。各區首領名稱與完整關卡流程尚待核對原有設計，**不得自行宣布定案**。

## 新增美術需求（不更動既有副本）
- 每個既有副本區域製作不同的入口、一般戰鬥、菁英區、首領房、勝利後場景；區域內可有多個鏡頭構圖。
- 首領戰前 4–7 秒專屬登場演出，可隨時跳過；重打可自動跳過。
- 直式手機單畫面、無捲動；前景/中景/遠景/地面/道具/光效獨立分層，採用正式插畫和動畫素材，不使用 CSS 幾何拼接。
- 跳過動畫與正常播放必須進入相同戰鬥初始狀態，不能重複結算。
- 先將原有第一區做成可玩垂直切片，接著依原有順序擴展，不新增平行替代副本。
