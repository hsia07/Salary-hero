# 西遊後日談｜六名角色獨立背景卡 v2
**狀態：角色背景候選，非小說、非逐句劇本、未實裝。**
## 共用世界歷史（不作共同主線）
取經完成後，唐僧、悟空、八戒、悟淨各自受封。四人保留師徒情誼，但各自生活，不要求一起行動或一起死亡。哪吒、嫦月、敖璃同屬神話平行世界的天庭／龍宮人物，不是取經隊伍。每名可招募角色各自在工作中死亡，死後被召喚到《薪水勇者》的異世界。取經後數百年是**架空番外設定**，非原著續篇事實。
## 悟空（UR）｜《花果山的閒人》
- **取經後做什麼**：鬥戰勝佛受封後回花果山，最初每天教猴群耍棒，後來發現年輕猴子有自己的日子，沒人天天等他出手。
- **性格與缺點**：自負、好勝、嘴硬，遇到問題總想替所有人作主；他曾把反抗看得比後果重要。
- **真正的麻煩**：花果山猴民被徵召為結界工役，悟空接下護送工作，本想靠自己的名號讓天庭放人，卻發現護送令只是把人送進抽取神魂的結界。
- **工作死亡**：在執行護送職責時回頭破壞結界，耗盡神魂而死；不是被天庭革職就直接穿越。
- **死後召喚的遺憾**：他救了眼前的人，卻沒親眼看見花果山後來如何；異世界見到八戒與悟淨時，嘴上仍說自己不需要幫忙。
- **與其他角色的關係**：八戒是一起取經的舊師弟，彼此嘴硬但熟悉；悟淨是他信任的調停者；哪吒是天庭舊識但不是師徒。
- **遺物與技能**：工役令、金箍棒、毫毛分身；個人副本是護送與破結界，不能只打Boss。
## 八戒（SR）｜《食堂不賒帳》
- **取經後做什麼**：受封淨壇使者，先過了好一陣吃喝閒日子；後來看不慣供奉分配不均，接手天河食堂，成為整天算菜錢的食堂長。
- **性格與缺點**：愛占便宜、會偷懶、嘴上抱怨，但記得夜班仙工愛吃什麼。他曾為保住食堂，同意縮減勞役者餐量。
- **真正的麻煩**：被減餐的仙工在危險工地昏倒，他才知道省下來的不是食材，是別人的體力。
- **工作死亡**：供餐期間天火失控，他打開糧倉疏散食堂員工並以神力擋火，最後殉職。
- **死後召喚的遺憾**：還欠那位仙工一頓像樣的飯；他看到異世界食堂會先問能不能續碗。
- **與其他角色的關係**：悟空的老師兄、悟淨的老同伴；與深夜主廚茉莉在異世界才認識。
- **遺物與技能**：缺口鐵勺、九齒釘耙；戰鬥以食物補給和承傷回復呈現。
## 悟淨（SR）｜《行李有人領嗎》
- **取經後做什麼**：受封金身羅漢，不再必須挑行李，卻仍會下意識替人拿東西。他接下天界與流沙河的跨界搬運工作。
- **性格與缺點**：穩重、耐心、少話；真正的問題是從不拒絕別人，久而久之連自己想去的地方都不知道。
- **真正的麻煩**：他接到護送被放逐者渡河的差事，發現貨單上寫的是「物資」，船上的卻是活人。
- **工作死亡**：在履行護送職責時遇上失控洪流，他留在船尾穩住渡口，讓乘客先走，神魂消散。
- **死後召喚的遺憾**：他曾經答應師父「這趟回來就不再接差事」，最後沒有回來。
- **與其他角色的關係**：記得悟空與八戒吵架時誰先低頭；死後在異世界重逢，第一次明確說出「這次我要自己選」。
- **遺物與技能**：磨破的挑擔繩、降妖寶杖；技能以牽引隊友、淨化、護送為主。
## 哪吒（UR）｜《庫房禁止用火》
- **取經後做什麼**：繼續任職天庭巡檢，與悟空有舊識，並不加入取經師徒。他受命清理危險法寶與卷宗庫房。
- **性格與缺點**：脾氣快、討厭拖拉、容易先做後想。他曾燒掉藏有受害者名冊的卷宗，害證據無法追查。
- **真正的麻煩**：第二次清理時發現庫房內還有被困同僚，於是違反「先燒後查」命令。
- **工作死亡**：以蓮火護送同僚離開失控庫房，神魂耗盡而死。
- **死後召喚的遺憾**：當年被他燒毀的名冊無法恢復；他在異世界和敖璃合作追查留下的帳冊。
- **與其他角色的關係**：悟空是愛互嗆的舊識，敖璃是天庭與龍宮職務上的合作對象，非師徒。
- **遺物與技能**：燒焦卷宗、火尖槍、風火輪；高速突擊但須接觸目標。
## 嫦月（SSR）｜《月宮夜班》
- **取經後做什麼**：取經對她只是天庭年代中的一件大事。她是廣寒宮巡夜官，負責月輪法陣與夜班仙眾的安全，不強迫和悟空發展關係。
- **性格與缺點**：安靜、細心、講究秩序，卻總以為自己不說話就不會給別人添麻煩；曾把法陣異常當作小問題自行處理。
- **真正的麻煩**：月輪法陣多次異常，她為避免夜班同僚被責罰，隱瞞了部分紀錄，讓危險累積。
- **工作死亡**：夜間巡檢時月輪法陣失控，她封住裂隙讓仙眾撤離，自己殉職。
- **死後召喚的遺憾**：留在廣寒宮的值班紀錄沒有交接；她學會讓別人參與處理問題。
- **與其他角色的關係**：與搗藥仙兔小玉有月宮工作聯繫（具體是否生前相識待核）；與哪吒、悟空沒有必要的私人舊情。
- **遺物與技能**：裂開的月輪巡夜牌、冰月護盾；冰控與防護輪換。
## 敖璃（SSR）｜《龍宮的壞帳》
- **取經後做什麼**：龍宮財務官，處理海民勞役、海底工事與天庭往來帳目。取經只影響她所處世界的政治背景，不是她的人生中心。
- **性格與缺點**：精於算計、擅長談判、表面冷靜；她曾把「可延後處理」當成沒問題，讓債務越積越多。
- **真正的麻煩**：她發現一份工役契約把海民壽命當作抵押品；若公開帳冊，龍宮也可能被追責。
- **工作死亡**：她執行解封契約、釋放被抵押的海民壽命時遭反噬而死。
- **死後召喚的遺憾**：帳冊被她送出去了，但她不知道龍宮是否真的改變。
- **與其他角色的關係**：與哪吒在異世界共同追查卷宗；是否生前合作需要核定同一年代與具體事件。
- **遺物與技能**：被海水泡爛的帳冊、龍珠算盤；水法破甲與資源調度。
