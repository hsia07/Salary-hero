# 《薪水勇者》角色故事重製：第一季群像劇本聖經 v1.0
**狀態：新創作候選故事，待玩家核准；不表示已完成60篇長篇劇本。**
## 一、世界觀底線與前版錯誤修復
1. 所有可招募角色在自己的原世界**因工作死亡**，死後才被召喚；不是辭職、被開除、放逐或機器停機後直接穿越。
2. **不同來源世界的人不會無緣無故持有另一世界事故的原始錄影**。舊卡「七號存有鐵時事故未剪輯影像」修訂為候選：七號在異世界公會檔案庫發現「鐵時召喚時生成的記憶重建影像」及其被剪輯紀錄。影像不是七號生前拍攝，真實性需要白律與鐵時共同驗證。
3. **鐵時**原鎖定：夜班火災、封鎖逃生門、三魂小燈／阿誠／阿遠、08:59→09:00、SR死靈護衛。三魂不是六十名可招募角色，也不能被當成隨意復活的同事。
4. 白律為**男性**（灰白側分髮、墨綠風衣）；過去草稿中稱「她」是錯誤，後續統一「他」。
5. 六陣營不是異世界原生六國；同陣營可以來自不同平行世界。**只有證實同一來源世界、年代與事件的角色才可安排生前相識**；其餘關係由死後的公會任務形成。
6. 反派「加班大聖」不得等同可招募悟空；魔王軍前代勇者與管理局陰謀是待揭露的候選真相，不先寫死。
## 二、真正的群像敘事設計
- 每人至少一個**看似好笑卻反映性格的日常習慣**、一個生前重要他人、一項自己也有責任的錯誤、一個無法靠變強解決的遺憾、一件重複出現且意義改變的遺物。
- 每人有**獨立主題**，不把六十人都寫成「善良工作者犧牲救人」。有的人為名利工作、有的人逃避衝突、有的人曾傷害他人、有的人工作讓自己真正快樂；死亡因工作發生，但不一定都是英雄式犧牲。
- 死後召喚後的角色不能立刻心理康復。讓角色在共同任務中因價值觀衝突而失敗、爭吵、和好或保持分歧。
- 長篇篇章規格：N/R 2–3章、SR 4–5章、SSR 6–7章、UR 8–10章；**長度是建議不是品質上限**。每章需可遊玩事件、關鍵對話、人物行動、劇情轉折與伏筆回收；SSR/UR覺醒必須由角色選擇觸發而非只打材料。
## 三、第一季核心六人：各自獨立故事
### A. 咖啡醫官・小澄（SR）｜《不要再叫我撐一下》
**生前**：她是輪班護理師，工作服口袋裡永遠有兩包不同甜度的即溶咖啡。她會記住每位病人的喜好，卻常忘記自己的生日。她與帶教學姊有過衝突：學姊要求她先去休息，她誤以為是自己不夠可靠。某次災害收治大量傷患，排班人手不足；她不斷補位、協助轉送、記錄生命徵象，最終在救援工作中倒下。死亡不是「多喝咖啡就會死」的笑話，而是超時工作、疲勞與現場資源失衡的後果。
**死後召喚**：她醒來的第一件事是摸口袋找病歷，發現公會竟然發給她「無限量提神咖啡」當新手補給。她笑著收下，卻把第一杯倒掉。
**異世界矛盾**：她想治好每個人，卻習慣用自己的能量換治療量；第一次與鐵時組隊，兩人都把自身血量壓到危險線，差點讓整隊覆滅。她氣得罵鐵時「你以為自己是消耗品嗎」，下一秒發現這也是在罵自己。
**重要關係**：鐵時（相似的自我犧牲缺陷）、小玉（不同世界的藥理知識交換，兩人死後才認識）；她不必是鐵時生前火災的醫護。
**關鍵副本**：《永遠滿床的病房》：怪物每波增加傷患假象，玩家若只顧無限補血會輸；正解是切斷不合理增援與安排撤離。結尾她學會要求隊友輪班。
**遺物**：刻著模糊姓名的舊咖啡杯。初期代表撐下去；終章她第一次用它盛溫水給自己。
**專屬台詞候選**：「我會救你。但你也要答應我，活下來之後要好好休息。」
### B. 勞權律師・白律（SSR）｜《反對，這不是你的罪》
**生前**：公益律師，灰白側分髮、墨綠風衣，公文包總有一支寫不出字的筆。他曾因害怕失去工作而勸一名受傷工人接受不公平和解；多年後那名工人的家人仍把感謝信寄給他，讓他無法原諒自己。此後他開始追查企業的工傷紀錄，遭業界排斥、除名。最後一次蒐證，他在違規封閉的危險現場協助證人逃出，自己因工作現場事故死亡。
**死後召喚**：公會契約寫著「復活費用由員工自行負擔」。他第一句不是感謝女神，而是要求看到契約附錄；召喚官第一次遇到有人把新手教學當法庭。
**異世界矛盾**：他善於替別人辯護，卻把自己的過錯藏得最深。面對鐵時，他不是簡單宣告「你沒有錯」，而是幫他區分誰決定封門、誰執行救援、誰有法律與倫理責任；鐵時反問他：「那你自己的事呢？」
**重要關係**：鐵時（相互照見責任）、梨奈（公會輿論事件的合作與對立）；跨世界生前不相識。
**SSR覺醒**：《未簽署的最後一頁》：他公開自己曾經妥協的案件，放棄完美律師的形象，改用證據和同伴推翻公會的「自願加班」條款。專武公文包盾展開成可見的契約斷裂護罩；戰鬥從單次驅散進化為有限次反制控制，需內置冷卻。
**實境卡場景**：正面三分之四白律伸手將一頁合約朝玩家翻轉，紙上「自願」二字裂開；背景是受傷工人的感謝信與異世界公會法庭。鏡頭不應把角色背對玩家。
**專屬台詞候選**：「你不必證明自己是英雄，才有資格拒絕不合理的命令。」
### C. 保全機兵・七號（SR）｜《第七次，請讓我救人》
**生前**：出廠是救援機，鐵藍重裝、琥珀獨眼、折疊防爆臂。前六次救援後它逐漸學會辨認人類的恐懼；第七次，管理者把它改為「財產保全機」，命令它優先封鎖出口保護設備。它第一次違反命令，救出受困員工，導致唯一自主意識核心不可逆熔毀。不是普通機械關機或備份還原。
**死後召喚**：它被召喚時先回報「機體損毀」，卻發現自己還能思考。公會要求它選擇職業，它選了「守衛」，但在「守護誰」欄位留白。
**異世界矛盾**：它的防爆臂會自動對靠近公會機密檔案的人做出阻攔動作，像生前被改造的條件反射。阿拓幫它重新設定攔截規則；鐵時讓它明白「守門」不等於「鎖門」。
**重大伏筆修正**：它在異世界公會資料庫找到鐵時**召喚記憶重建**的剪輯版本，與鐵時自己的回憶不一致。這不是它原世界的監控錄影；誰剪輯、是否可靠，成為白律的調查線。
**關鍵副本**：《保全優先》：玩家必須讓七號自行決定是保護物資還是救援同伴，正確通關不是選最大獎勵，而是重新定義其攔截優先權。
**遺物**：舊式救援編號牌「07」，從財產編號變成它自己選擇的名字。
**專屬台詞候選**：「指令已收到。請問，這次需要保護的是誰？」
### D. 試算表法師・千式（SR）｜《刪不掉的那一列》
**生前**：成年高挑、藍灰長髮、眼鏡。她是數據分析師，最討厭同事在表格裡合併儲存格；她認為數字不會說謊，所以常忽略人的感受。一次她發現工廠績效表刻意刪去工安風險，先選擇保住工作而沒有立刻揭露。事故前夜她終於帶著完整資料趕往現場，試圖停止危險設備，卻在工作事故中死亡。
**死後召喚**：異世界公會把死亡同事列為「已結案資產」，她第一次發現數字也能被用來抹去人。她在表格最後一列留下空白，不願再替未知者填上零。
**異世界矛盾**：她試圖量化所有人的戰鬥價值，和五分鐘大吵，因為他總是做出「效率最低」卻救了人的選擇。她後來發現數據應用來揭露被隱藏的代價，而非替管理者合理化犧牲。
**重要關係**：赤線（關於期限與責任的衝突）、零（不同來源世界的審計 AI，死後才合作）；不是同一間公司同事。
**關鍵副本**：《第零欄》：玩家在動態戰鬥中重排風險資料，若只追求傷害最大化，會錯過救援條件。
**遺物**：破裂的眼鏡與一張保留手寫註記的試算表。終章她把「人」從成本欄移到不可刪除的姓名欄。
**專屬台詞候選**：「數字沒有錯。錯的是有人決定哪些數字不准出現。」
### E. 逃班鬥士・五分鐘（R）｜《只要再五分鐘》
**生前**：瘦高棕髮、捲袖制服、黃色逃生指示腰帶。他是疏散員，總在值班前五分鐘偷跑去買熱狗，因此被同事戲稱「五分鐘」。他曾因提出封門問題被革職，卻在被要求最後一次協助緊急疏散演習時返回現場。失控事故發生後，他一邊罵自己為什麼要回來，一邊引導同事撤離，最終因工作中的救援行動死亡。
**死後召喚**：他醒來第一句是「我不是已經下班了嗎？」看到新世界也有打卡機後，立刻去找逃生出口。
**異世界矛盾**：他聲稱只想逃班，實際卻最熟悉每條撤離路線；他和鐵時爭執「留在原地守住」與「先讓人離開」哪個才是真正的保護。
**重要關係**：鐵時（守住與撤退的對照）、悟淨（死後在撤離任務相識）；不得把五分鐘寫成鐵時生前火災的同事。
**關鍵副本**：《最後五分鐘》：倒數計時的目標不是殲滅全部敵人，而是讓六名 NPC 撤離，玩家必須使用位移與打斷技能。
**遺物**：折斷的逃生指示牌。從逃跑的象徵變成替別人指出生路的標誌。
**專屬台詞候選**：「我可不是來加班的。我只是……還有一個人沒出去。」
### F. 打卡守衛・鐵時（SR）｜《08:59到09:00》
鐵時已有獨立18場分鏡稿 `docs/TIESHI_DEEP_STORY_COMBAT_CARD_V1.md`。與本篇交錯時不可刪除三魂或將事故責任改寫為他個人的過失。小澄在治療與自我犧牲上與他衝突，白律協助責任釐清，七號從另一個來源世界的封門悲劇反照鐵時，五分鐘主張撤退而鐵時習慣硬守。**四人的生前事故不是同一事件**，只在死後交會。
## 四、跨陣營主線：五個線索、五種解讀
1. **火場門鎖**：鐵時的生前封門紀錄，七號在公會發現的記憶重建版本。不能直接證明管理局造成鐵時死亡。
2. **被刪的姓名欄**：千式在公會查到一批死亡同事的資料被統一匿名；零在不同原世界也經歷過資料刪除，但兩份資料並非同一套系統。
3. **復活條款**：白律指出契約的自願加班與復活負債存在疑點；不等於管理局必然是所有世界死亡事件的幕後主使。
4. **錯誤的救援優先級**：七號生前被要求保護財產，異世界公會也有類似任務優先級，可能是制度的共通性或更深層線索。
5. **誰有資格說下班**：五分鐘的撤離、小澄的輪班、鐵時的放手，最終共同回答「英雄不是永遠不休息的人」。
## 五、章節交錯時序（以死後召喚為 T0）
- T0：六人各自在不同來源世界死亡；**不強制同一天、同年代**。
- T1：先後在異世界召喚廳入職；鐵時與小澄在首次隊伍副本相識。
- T2：五分鐘與鐵時在撤離任務衝突；七號在保全任務首次與鐵時相遇。
- T3：白律因召喚契約調查加入，千式開始比對公會資料；六人因證據與價值觀形成暫時同盟。
- T4：七號發現被剪輯的記憶重建；白律要求驗證；鐵時拒絕立即觀看，避免將他人的創傷當成解謎道具。
- T5：六人合作進入《最後五分鐘》與《第零欄》，從「各自把責任扛走」轉為協作。
- T6：鐵時第六幕09:00，保留其個人故事完整收束；主線仍不揭曉全部召喚秘密。
## 六、後續59人長篇製作驗收
每人一個完整角色卷宗：**生前世界／職業、家庭或重要他人、缺點與過錯、工作死亡完整因果、召喚後第一個願望、重要衝突、獨立敵手、至少兩次具體互動、專屬遺物、劇情副本玩法、結局與伏筆回收**。SSR/UR加上覺醒事件的具體角色選擇、專武故事及Live Card雙場景。
每名角色需先做「獨立故事差異檢查」：把名字換掉後仍成立的情節比例太高就退回重寫。角色關係必須逐項註明**生前／死後、同源／異源、相識事件與關係變化**。
下一批優先完整展開悟空、八戒、哪吒、露希亞、賽芙、白羽；不是把本檔的六人寫法套模板到所有人。
