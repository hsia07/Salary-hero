# 《薪水勇者》不可覆寫的召喚世界觀硬規則 v1.0

## 核心前提（已確立，優先於所有 60 人候選設定）
**原世界因工作而死亡 → 死後被召喚到異世界 → 成為勇者／同事 → 發現異世界仍有打卡、考績、加班、復活與任務制度。**
主角「薪奴」為現代日本上班族過勞死亡。其餘候選同事可以來自不同平行世界、文明或物種，但每名可招募角色都必須經過**因工作而死亡**這個門檻，才以死後召喚者身分來到勇者世界。不能把「辭職、失業、被停機、逃亡、被流放、拒絕工作、跨界旅行」直接當成召喚原因；它們只能是死亡之前的事件。

## 世界邊界
1. **原世界**：六類角色所屬的來源世界／文化，不等於異世界內原本存在的六個國家；相同陣營可有多個平行來源世界，不強制所有人同時代。
2. **死亡**：與職務、工作事故、被迫任務、職業責任、過勞或制度壓迫有因果關係；不必全是過勞猝死，不能把死亡場面當廉價笑點。
3. **召喚**：死亡後才發生；召喚者保有部分生前記憶與人格，但可能有缺損。被召喚後的工作與制度是新生活的矛盾核心。
4. **機器人／AI**：須先定義其為有自主意識的生命個體，並明確描寫不可逆核心停機／人格實例終止；一般資料備份、單純關機、被改造不等於死亡。是否被召喚的是原人格，為可探討伏筆，不可無解地當作理所當然。
5. **冥府／亡靈**：冥府角色生前是能死亡的職員；需描寫其在冥府任職期間遭遇的**第二層死亡或魂魄消散**，才被召喚。鐵時的三魂是技能／劇情特殊存在，不算 60 名同事。
6. **神話人物**：為本作平行神話世界的原創改編，必須合理交代工作／職責與死亡；不能單憑被貶、封印、穿越就入職。神話原型人物可有本作獨立經歷，不照搬其他作品。
7. **異常生物**：同樣須有生命／人格及職業性死亡，不得因其非人外形就省略死亡與召喚。
8. **生前關係 vs 召喚後關係**：不同來源世界的角色不應在生前直接見面，除非明確設定跨界接觸；共同線索、同一封文件、相似企業標誌可在死後才被發現。
9. **時間線**：不同原世界時間流速可不同，但不可將生前事件寫成異世界召喚後才發生。角色傳記需區分「生前→死亡→召喚→新職務→羈絆→覺醒」。
10. **揭露節奏**：玩家初期只知道「工作死了還要上班」；中期追查為何被召喚、為何工作相關死亡；第一季才逐步觸及勇者／魔王制度，幕後最終答案仍待定。

## 每名角色六段履歷（正式施工前必填）
- `origin_world`：原世界及所屬文明
- `former_job`：生前具體職務與職場關係
- `work_death_event`：因工作而死亡的**明確因果事件**
- `summoning_scene`：死亡後被召喚的場景、記憶與情緒
- `new_world_arc`：召喚後在勇者世界的職務、衝突與加入隊伍原因
- `bond_timeline`：與同陣營／跨陣營角色的關係，註明是生前還是召喚後建立

**缺少 `work_death_event` 或 `summoning_scene` 的角色只能維持 `PROPOSED`，不得標記為完整角色傳記或正式核准。** 先前 60 人候選卡的 `past` 欄位大多只描述生前衝突，尚未交代死亡與召喚，必須逐一補寫。

## 鐵時不可覆寫
鐵時夜班火災因違法鎖門造成同事罹難；鐵時為救人回頭，不是事故責任人。其本人也在工作救援中身亡後被召喚，作為本作新補的**死亡與召喚銜接候選細節**；其 08:59→09:00 與三魂一盾、死靈護衛解鎖仍依個別規格，不可提前覺醒。

## 待審核的總謎團
「為什麼來自不同平行世界的工作死者會被召喚？」可以作為主線懸念，但**不能先定案是某個企業在所有世界安排死亡**；避免否定人物自身犧牲與原世界的獨立性。

本檔為世界觀一致性約束，不代表已完成 60 人的死亡場景、完整劇本或遊戲實作。
