# 《薪水勇者》S1 數值基線 v0.1 — 薪奴經驗、同事養成、全隊戰力

狀態：**待使用者核准的可測試提案**，不是現有遊戲已實作功能。編寫日期：2026-11-12。
依據：SALARY_SLAVE_XP_RULES.md、COLLEAGUE_PROGRESSION_RULES.md、SALARY_SLAVE_TEAM_POWER_RULES.md。

## 一、不可違反的已確認規則
1. 薪奴每次戰鬥勝利獲得經驗；副本通關另外給經驗。
2. 薪奴升級會提升自身及整隊戰力。
3. 同事可升級、突破、進階，消耗素材；同事實際等級永遠不超過薪奴等級。
4. 玩家負責編隊；薪奴的職業技能必須是戰鬥中實際觸發的能力，不能把玩家配置操作當作角色技能。

## 二、薪奴等級曲線（提案）
- 等級 1～100；從 Lv.L 升到 Lv.L+1 需 EXP = round(80 + 18L + 2.2L²)，L=1…99。
- EXP 為非負整數，可跨多級；滿級不再增加等級但仍正常完成結算。
- 例如：Lv.1→2 需 100；Lv.10→11 需 480；Lv.20→21 需 1320；Lv.50→51 需 6480；Lv.99→100 需 23422。
- 薪奴基礎生命 = round(1000 × (1 + 0.055 × (L-1)))；基礎攻擊 = round(100 × (1 + 0.04 × (L-1)))；基礎防禦 = round(40 × (1 + 0.03 × (L-1)))。均為提案。
- 每級賦予六位同事**基礎攻擊與基礎生命** +0.15%，以 Lv.1 為 0；全隊等級光環 = 1 + 0.0015 × (L-1)，Lv.50 = 1.0735，Lv.100 = 1.1485。
- 光環只乘同事的角色基礎屬性，不乘裝備附加數值、最終傷害、護盾與羈絆倍率；避免重複乘算與過度膨脹。
- 戰力 UI 應分列「薪奴自身」「等級光環」「同事養成」「裝備」「羈絆」來源，不可把估算戰力當成勝率。

## 三、戰鬥／副本經驗（提案）
- 基準一般怪：40 EXP；菁英：160 EXP；Boss：500 EXP；以區域倍率 stageFactor 調整，初期 1.0；四捨五入為整數。
- 副本通關：400 × stageFactor EXP；首通額外 600 × stageFactor EXP，按 dungeonId + difficulty 一次性領取。
- 勝利才發戰鬥經驗；失敗不發完整通關／首通經驗。已完成波次獎勵應按明確規則另行結算，禁止重複領取。
- 每場戰鬥獨立 battleId；副本結算 dungeonRunId；同一 ID 只可結算一次。離線掛機必須驗證有效戰鬥／時間上限。
- 例：8 一般怪、2 菁英、1 Boss、1 次通關與首通，基準區域總經驗 = 8×40+2×160+500+400+600=2140 EXP。
- 掉落與 EXP 依關卡配置，不以現實薪資計數直接換 EXP；上班掛機完成真實戰鬥才得 EXP。

## 四、同事升級與素材（提案）
- 同事有效上限 = min(薪奴等級, 已突破階段上限)。
- 初始上限 20；突破一～四分別開放 40、60、80、100。
- 升級成本（Lv.L→L+1）：經驗素材點數 round(20 + 5L + 0.5L²)，薪幣 round(30 + 8L + 0.8L²)；同事每次升級需手動或經使用者設定的合法自動養成消耗材料。
- 突破消耗（暫定）：20→40：突破章×2＋薪幣 1000；40→60：突破章×5＋職業徽記×2＋薪幣 3000；60→80：突破章×10＋職業徽記×5＋薪幣 8000；80→100：突破章×20＋職業徽記×10＋薪幣 20000。
- 進階與突破分開：進階改變技能觸發或定位，不可偷偷突破薪奴等級限制；進階材料、技能樹與覺醒數值待 S1 戰鬥模型確認。
- 升級前原子檢查素材與上限；升級成功才扣除；存檔、批次升級、託管和載入舊資料皆檢查上限。
- 薪奴升級後，同事上限提高，但**同事不會免費跟著升級**。

## 五、平衡目標與試驗
- 在同事等級與裝備不變時，薪奴升級 1 級，整隊預估戰力應單調增加；增幅不應造成傷害倍率暴增。
- 固定薪奴等級時，升級一名同事須有可量測效益；更換同職責同事不能讓整個流派完全失效。
- 以 Lv.10、20、40、60、80、100 為檢查點；同等養成對照不同薪奴主職、六人編隊、羈絆融合。
- 測試一：薪奴 Lv.37、同事突破上限 40，同事只能升至 37；薪奴升 38 後可花素材升至 38。
- 測試二：薪奴 Lv.10，六同事皆 Lv.10；薪奴升 Lv.11，六同事不自動升級，但全隊光環由 1.0135 升為 1.0150。
- 測試三：重複 battleId／dungeonRunId 不可領第二次 EXP 或首通獎勵。
- 測試四：經驗足夠連升數級時，每級光環、等級上限與戰力重新計算，不重複扣素材。
- 測試五：升級動畫須展示薪奴等級、全隊戰力增量、同事上限解鎖；採正式遊戲美術而非純表單。

## 六、實作順序
1. 將上述規則以純函式實作（XP 需求、EXP 結算、光環、同事有效上限、升級消耗）。
2. 寫自動化測試，涵蓋上限、跨級、素材不足、重複結算、存檔相容性。
3. 接入現有 V20/V21 戰鬥結算與薪奴等級狀態；不破壞既有存檔與薪資顯示。
4. 接入六人同事養成及真正的屬性計算，再進行戰鬥平衡模擬。
5. 最後接入正式美術升級特效、數值浮字、結算演出。
