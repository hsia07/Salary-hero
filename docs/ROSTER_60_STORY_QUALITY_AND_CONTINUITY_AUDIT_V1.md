# 60人故事品質／重複性／連結完整性稽核 V1
**狀態：稽核報告，非故事定稿。** 核對60人正式角色卡、60人製作規格、39人V3修訂、冥府10人、異常10人、世界宿敵V2。稽核不是把沒有證據的缺陷當成已確定矛盾。

## 量化結果
- 名冊60/60；6陣營各10人，ID沒有缺漏。
- 卡片關係120條、製作規格關係120條；目標ID均有效（**0條懸空**）。
- 角色卡有**52條未被反向列出的單向連結**。這不等於52個劇情錯誤：單戀、仇恨、師徒本可單向；但現有資料未標註單向理由，屬資料建模與敘事驗證缺口。
- 60/60召喚開場共用「死後召喚廳醒來→公會要求簽勇者雇用契約」模板；只有姓名與原世界替換，**60段召喚演出尚未個別化**。
- 60人工作死亡欄均存在且敘述死亡或不可逆消亡；不得把簡單關鍵字檢查不命中的「遇難」「核心熔毀」誤判成沒有死亡。
- 冥府／異常新稿各10段，每段約一個短故事卡，不是完整分場劇本；**60人都有背景卡 ≠ 60人完整劇本**。
- 六名已撰寫宿敵線相關角色：薇菈、璃音、蘇妲、清目、白律、赫斯；薔薇、灰牙有宿敵提案與角色卡，但完整雙人分場劇本尚待寫。

## 品質風險
### P0 世界觀／連續性
1. **召喚開場與主線互斥**：角色規格的60人都在「召喚廳醒來並被要求簽契約」，但第一章鐵時是在公會前台才接受詢問。可解釋為召喚廳→公會轉送，但**需要補過場**，否則玩家會以為是兩種互斥的初次醒來地點。
2. **薇菈／璃音事件時間**：兩人原世界均在工作時死亡；召喚後璃音與阿書建立近親般感情、薇菈介入商盟債務交易，都需要有足夠時間跨度，不能安排成到達當晚即發生失名之夜。
3. **宿敵罪責歸屬**：清目與蘇妲、赫斯與白律的重大過失已寫入分場，但角色名冊仍多以正面英雄身分描述，必須在「召喚後」欄增列罪責與不和解旗標；不能改寫他們原世界殉職的動機來合理化新世界罪行。
4. **冥府角色的二次死亡**：原世界是冥府行政平行世界，不是召喚世界的同一個冥府；必須明示原冥府魂體死亡後才召喚，避免與「召喚世界的人死後都回同一冥府」混淆。
5. **薔薇與灰牙**：生前兩人各自因護人殉職，召喚後灰牙卻再次接受追捕失名者的工作；**這是可寫的道德反覆，但必須有清楚的動機、代價與自我辯解**，不能只為製造宿敵而突然性格倒退。
6. **阿拓設定**：原規格稱召喚後追查「祕密復活裝置」，新稿又強調召喚不是復活；須定義裝置的真實用途，不能憑字面承諾真能復活死者。
### P1 重複性
1. **原世界死亡事件**：多數以「發現剝削／違規→救人或保護紀錄→工作殉職」為主線。死亡類型有變化，但**道德抉擇的結構仍重複**。不是每人都需要高尚犧牲；但既定死亡不可擅改，應從動機、過失、旁觀者視角與召喚後行動深化。
2. **角色結尾**：冥府與異常20人反覆使用「仍有某個小習慣／仍有缺點」作不完美結尾。形式比內容更一致，應改成不同後果：失去關係、被追訴、永遠不知真相、達成目標卻失去喜愛的工作、拒絕任務、主動背叛等。
3. **制度型衝突過密**：清目、蘇妲、墨言、白律、赫斯、璃音、薇菈都與文書／法令／姓名資料直接相關；應讓他們在不同類型場景中表現獨特性，不要全靠法庭和檔案室。
4. **宿敵事件過度同構**：四組血仇都以「一位具名NPC死亡→雙方互相指責」推動，這是**嚴重的故事同質化**，不能只換職業和死者名字。建議保留1–2組具體死亡血仇，其餘改成滅城、背叛、奪權、不可逆失能、被迫互相追殺、長期欺騙等不同損失。
5. **女性／弱勢NPC工具化風險**：阿書、霜婆、阿澪、南笙都可能被寫成為主角宿敵服務的犧牲品。每人需要自己要完成的目標、至少一場獨立於主角的主動選擇，以及對世界造成的影響。
### P1 連結資料品質
1. 角色卡120條與規格120條都可解析，**但有效ID不等於關係故事成立**；需逐條核對兩人初次相識、先後時間、動機、關係類型、事件章節與不可逆變化。
2. 52條單向關係須區分**刻意單向**（例如仇恨、暗戀、秘密關注）與**漏寫反向**（雙方明確互動卻只列一側）；不能自動雙向化。
3. 新增宿敵關係尚未全部寫回兩份60人JSON的結構化連結；目前靠分散文件，遊戲程式無法可靠讀取關係階段。
4. 新世界三大機構的勢力歸屬與各英雄個人立場仍欠事件時間表；「同陣營」是出身，不是政治同盟。
### P2 玩法／美術
每人有玩法提案，但多為一兩句；欠具體目標、失敗狀態、三種以上角色動畫、分層資產清單、戰鬥連動與章節觸發條件。尚無正式美術或可玩劇情實裝，不可宣稱完成。

## 修改優先順序與驗收
**P0**：建立統一世界時間線（原世界工作死亡→召喚廳→公會→關係建立→失名之夜→各宿敵事件），修正上述六項潛在矛盾；未核對前不鎖劇情。
**P1a**：重設四組宿敵的損失類型，至少兩組不得以具名NPC死亡作唯一核心；保留已寫初稿作對照，經核准後改寫。
**P1b**：將52條單向關係逐條標註 intentional_one_way / missing_reverse / unresolved，並新增初遇章節、事件、狀態變化；不能僅把links加滿。
**P1c**：60人召喚場景各自獨立，保留原世界工作死亡因果，20人短背景擴成可演出的完整劇本。
**P2**：再製作正式美術分層、動畫與遊玩整合；只有在實際完成後才可標記完成。

**現況：60/60有背景卡；0/60完整劇本經連續性與重複性驗收後鎖定。** 名冊與ID參照是完整的，敘事關係網與故事差異性還沒有達到高品質長期營運RPG標準。
