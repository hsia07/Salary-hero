## 正式品質門檻

1. **一項功能至少有一張獨立正式場景原畫／美術演出**；不准把完整 UI 圖片貼成不可操作的假遊戲頁。
2. 角色、武器與特效分層：攻擊、施法、受擊、勝利、失敗必須各有真正不同的姿態與時序，而非只做水平位移或晃動。
3. 每次真實玩法事件都可引發對應、可觀察的美術效果；不可把按鈕裝飾動畫冒充真實交易。
4. 每項畫面可以手機直式、較窄 320px 螢幕使用；首頁不捲動，子功能的獨立面板可以捲動。
5. 保留舊存檔、舊角色、薪資計算；所有 UI 改造的操作必須呼叫原本已驗證的遊戲規則。
6. **通過程式與真手機截圖／操作檢查後，才能標示視覺初步驗收。** 即使全綠，玩家美術核准前也不能稱為正式完成。
