# 正式角色造型鎖定 — 社畜勇者・夏（不可覆寫）

最後確認：2026-11-09。以下是經使用者再次明確重申的硬性美術標準。

## 主角必須一眼看出「鬍子拉碴、疲憊、邋遢的上班族大叔」

- **人物年齡感：** 成年、頹廢、微胖或疲倦的社畜大叔；明顯的下巴、嘴周及雙頰短鬍渣，帶生活壓力感。不是白淨年輕少年。
- **表情：** 深棕色蓬亂頭髮，沉重黑眼圈、藍灰色半垂疲倦眼睛；常打呵欠、茫然、流口水、崩潰，不做充滿熱血的年少英雄表情。
- **服裝：** 皺巴巴的白襯衫、鬆開的紅領帶、深色辦公長褲、黑鞋、識別證；紅色披風看起來像隨便披上的辦公室毯子，不能換成華麗騎士披風。
- **辨識道具：** 咖啡、筆電、公事包；主要攻擊拿筆電、公事包、報表等辦公用品，**不以長劍或傳統騎士武器作為正式主角預設武器**。
- **美術風格：** 沿用 V18 使用者認可的精緻日系奇幻／暖金與深藍紫光影，但角色本身必須是頹廢社畜大叔。高品質場景與滑稽社畜角色的反差才是核心。
- **裝備升級：** 稀有度增加可以添加炫光與裝備細節，但**任何稀有套裝仍需保留鬍渣、黑眼圈、鬆領帶及員工識別證等辨識要素**。

## 禁止

1. 不得重新畫成「棕髮美少年、明亮大眼、光滑臉頰、紅披風金甲長劍勇者」。
2. 不得將合成遊戲截圖、全套素材海報裁切成原生精靈或背景並標成完成。
3. 不得把解析度、透明度等工程檢查通過誤當作美術驗收通過。
4. 不得在 GitHub 文件、圖片或遊戲裡顯示未經驗證的「已完成」「已提交」數量／Commit。
