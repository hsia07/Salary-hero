# 《薪水勇者 Salary Hero》角色 A 正式美術規格 V1.0
狀態：**外型設計規範已核定，正式角色素材尚待驗收**。更新：2026-11-09。

> 本版為最新版，取代以前「初始主角過度乾淨」「髮色棕」「油膩鬍渣大叔」「熱血少年劍士」等彼此矛盾的描述。未經明確同意不得自行改成上述設定。

## 唯一正式初始主角 A：「平凡社畜・{playerName}」

- **年齡與性格：** 25～35 歲外貌的成年日本上班族；略顯成熟的大叔感，但不能老態、不能少年。看起來聰明、慵懶、幽默，有點心累，**微邋遢但帥**。
- **氣質參考：** 借鑑《文豪野犬》太宰治那種慵懶、不羈、略帶神祕的成熟感，**不是直接複製該角色的服裝、髮型、五官或標誌配件**；需成為《薪水勇者》的原創主角。
- **輪廓：** 明顯纖瘦，長腿窄肩或自然肩寬，不可健美、不可以胖或娃娃般圓滾滾。
- **頭髮：** 純黑到藍黑色短中髮、前額有垂落的髮束，蓬鬆、略微凌亂、帥氣但沒有精心整理。**禁止棕髮與栗色髮**。
- **臉部：** 偏瘦尖的成人臉、細緻五官、半垂的疲倦眼、淡淡黑眼圈、**嘴周與下巴有輕微短鬍渣**。鬍渣必須可見但稀疏，不能髒亂蓄鬍或厚重落腮鬍；依然好看。
- **神情：** 無奈微笑、懶洋洋、熬夜後的淡漠、偶爾耍帥。不能幼兒式大眼、白皙乾淨童顏，不能可愛玩偶比例。
- **服裝：** 微皺的奶白色長袖上班襯衫、微鬆的暗紅領帶、深灰／黑色修身西裝褲、皮鞋、自然垂掛的員工識別證；袖子可輕微捲起，少量布料皺摺。不是正式重甲。
- **道具：** 舊公事包、咖啡杯、文件夾、筆電、充滿辦公室幽默的武器。起始姿勢以公事包為辨識道具，後期裝備需要真正能改外觀。
- **畫風：** 高品質日系奇幻 RPG 角色美術，與使用者認可的 V18 繁複、溫暖金光與藍紫場景一致。富表現力的材質、柔和精緻的層次光影與漂亮輪廓；不能是簡陋 SVG 幾何圖拼接、簡筆風或扁平貼圖。
- **比例：** 原創半 Q 版遊戲角色，身體仍可讀出纖瘦成熟成人感，建議頭身比約 1:3.5～1:4.5，不強求固定值，以實際設計美術品質優先。
- **命名：** 不再固定「夏」或任何名字，介面統一顯示 `平凡社畜・{playerName}`，由玩家初次進入自行輸入。

### 不可偏離的辨識錨點（每張動作都必須保留）

`黑色略亂短中髮`、`纖瘦成年男性`、`半垂疲倦眼`、`淡淡鬍渣`、`微皺白襯衫`、`暗紅鬆領帶`、`員工證`、`微邋遢但帥`。

### 動作與鏡頭基準

1. 全身 **idle**：自然微駝、輕靠一邊站立，手提公事包，輕微呼吸和眨眼動畫。
2. **walk**：真實腳步循環、手臂與公事包不同步擺動，符合腳底接地位置。
3. **attack**：公事包甩擊／辦公用品魔法，獨立動作與特效，不將斬擊畫死在主角圖中。
4. **hurt**：被擊中後後仰、衣服和頭髮跟著動。
5. **victory**：疲憊又得意的輕笑、拖著公事包抬手，不能變成熱血金甲騎士。
6. **sleep**：趴桌睡著或站著打瞌睡，應配合場景與動畫分層。

畫面方向預設遊戲側視 3/4，人物站姿的腳底基準線固定；睡桌可另外做與場景相容的姿勢而非強塞進站立框。

## B — 後期限定造型：「爆肝加班・頹廢社畜」

- 同一個人的進階頹廢版本，黑髮更亂、鬍渣更重、黑眼圈更深、領帶更鬆，披著像毯子的紅披風。
- **B 是活動或抽獎取得的造型，不是開局角色。** 且不能用 B 的明顯鬍渣、破衣服取代 A 的「輕微鬍渣但帥」。
- B 也要獨立繪製一套符合 A 同樣鏡頭、尺寸、光影的精靈；不能從展示圖亂裁。

## 技術資產標準和製作順序

1. **先驗收 A 的「一張獨立全身基本立繪」**。圖片本身不可有遊戲 UI、海報標題、人物之外的戰鬥背景。
2. PNG/WebP 實際輸出尺寸以 512×512 為基本候選規格，可保留更高解析度母稿（例如 1024×1024），但必須登記來源尺寸、透明像素及人物邊界，頭腳四邊不裁切。
3. 每個動作為獨立透明檔案，採統一主角尺寸、重心、錨點與光源方向。逐格動畫必須保持一致的臉、髮束、員工證、鬍渣及服裝。
4. 前期候選放 `art/v19/candidates/characters/starter/`；只有通過美術人工驗收、真實像素與透明度檢查、裁切與載入測試後才放正式 `runtime`。
5. 擴充流程：先將主角 A 形象驗證過關，再建立第一批敵人、辦公室場景與武器的**獨立素材**，同時規劃不同體型與輪廓的多樣性；不要再拿單張合成遊戲畫面當成可互動 RPG 的資產。
6. `v19/app.mjs` 仍在載入以前遭否決的扁平候選角色 SVG。**這屬於需要修正的缺失，不可稱為完成**。
7. 技術驗收項目：檔案可讀回、實際解碼尺寸、alpha 最小最大值、內容 bbox 與四周留白、角色沒有截斷、場景下的角色比例及 iOS Safari 動態測試。

## 正式驗收要過的主觀門檻

- 一眼就知道是瘦黑髮、微邋遢、有精神疲憊感卻帥氣的成年人。
- 穿著日系上班族服飾，並且與「薪水勇者」這款華麗職場奇幻 RPG 的光影融為一體。
- 不是太宰治的複製品，不是 Q 版年輕棕髮學生，也不是破破爛爛的邋遢油膩大叔。
- 使用者未核可的候選稿不得放到正式角色槽位，任何產出不得誤標已完成或已整合遊戲。
