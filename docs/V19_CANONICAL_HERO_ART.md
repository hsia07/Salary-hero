# 《薪水勇者 Salary Hero》初始主角 A 正式美術硬規格 V2
狀態：**使用者核定角色外型，尚未產出獲核准的正式獨立透明角色素材**。最後確認：2026-11-09。

> 核心一句：**有點邋遢的、偏瘦的、黑短髮日本上班族大叔。** 這是唯一初始主角外型依據。若先前文件或圖片與此版矛盾，以本版為準。

## A｜平凡社畜・{playerName}（開局固定外觀）

- **年齡感：35～45 歲左右。** 一眼看得出是疲憊的日本男性上班族大叔，不是 20 多歲的白淨美少年、娃娃臉或熱血奇幻騎士。
- **身材：明顯偏瘦，瘦長四肢、偏窄肩膀。** 不能是胖大叔、粗壯肌肉型或過度圓潤的 Q 版孩子。
- **髮型：黑色短髮，可以略蓬、稍亂，沒有精心梳理。** 禁止棕髮、淺髮及典型動漫少年飄逸髮型。
- **臉與表情：略瘦的成熟成人面孔、半垂眼皮、熬夜黑眼圈、嘴周與下巴看得出的短鬍渣／鬍影。** 疲倦、略厭世、有點慵懶與幽默；可偶爾無奈微笑。不能刮得乾淨到像少年，也不能滿臉濃密落腮鬍。
- **邋遢程度：有點邋遢，不能太乾淨，但也不要骯髒、破爛、濃重油膩或流浪漢感。** 關鍵是「工作摧殘過的普通社畜大叔」，不是特務、明星或帥氣金甲勇者。
- **服裝：微皺的白／奶白色長袖襯衫、鬆一點的暗紅領帶、深灰或黑色修身西裝褲、黑皮鞋、員工識別證。** 可以捲一點袖口。不可擅自加入盔甲、長劍、花俏正式騎士披風。
- **道具：舊公事包、咖啡、筆電、報表。** 初期武器是職場用品，不是傳統刀劍。
- **美術：精緻日系奇幻 RPG／電影感的遊戲角色品質，暖金與藍紫環境光，有真正的臉部刻畫、衣物材質、光影和穩定角色輪廓。** 畫風精緻不代表角色要變少年或華麗騎士。
- **玩家名稱：** `平凡社畜・{playerName}`，名字讓玩家自己取，不寫死。
- **遊戲角色必須是 Q 版：** 遊戲內戰鬥、探索、裝備和待機，均使用有成熟大叔特徵的精緻 Q 版獨立精靈，初期以約 **2.5～3.2 頭身**做美術起點（依審圖調整，不能胖圓成幼童），側視 3/4、腳底錨點一致。先前 512×1024 長身形透明立繪**只作人物造型與肖像參考**，不能直接縮放、擠壓、旋轉來冒充 Q 版遊戲動作。

### 必須同時存在的辨識錨點

`35–45 歲日本大叔感`、`偏瘦`、`黑色短髮略亂`、`可見短鬍渣`、`疲憊半垂眼與黑眼圈`、`有點邋遢但不髒`、`微皺白襯衫`、`鬆暗紅領帶`、`深色西裝褲`、`員工識別證`、`舊公事包`。

### 一律否決

1. 帥氣少年勇者、年輕黑髮動漫主角、光滑臉蛋的初入職場青年。
2. 肥胖或肌肉型大叔、過度骯髒與破爛、濃鬍渣覆蓋整張臉。
3. 金甲、長劍、奇幻騎士或披風成為預設初始造型。
4. 全部角色都以展示海報／遊戲截圖代替獨立可動精靈。
5. 平面幾何 SVG、Emoji 貼圖即宣稱為通過正式美術驗收。


## 遊戲內 Q 版與長身形立繪的角色分工（使用者追加核定）

| 交付種類 | 身體比例 | 實際用途 | 判定 |
|---|---|---|---|
| 已確認的高身形大叔參考圖 | 較寫實、瘦長 | 鎖定五官、鬍渣、髮型、服裝、年齡、角色印象；可做肖像基準 | **只能當參考** |
| **Q 版遊戲主角** | 約 2.5～3.2 頭身起步，身形保留偏瘦感 | 遊戲內所有戰鬥、探索、掛機和換裝，需新繪不同姿勢 | **必須製作並經實機驗收** |
| 表情肖像 | 可精緻成人比例或頭像半身 | 角色介面、對話、圖鑑 | 不可替代遊戲中的動作精靈 |

Q 版**不是**換成白淨小學生或頭特大、身體胖圓的低齡玩偶。每張縮至實際手機戰鬥顯示大小，仍需看出約 35～45 歲的日本上班族大叔、黑亂短髮、短鬍渣、半垂疲憊眼、微皺白襯衫、鬆暗紅領帶、員工證與偏瘦輪廓。其餘敵人、NPC、機器人、外星人也要採同級精細的 Q 版場景角色比例（特殊巨型首領另有明確尺寸例外）。

### 逐動作必須有獨立繪製的姿勢

- **idle**：雙腳穩定、疲憊微駝、獨立呼吸／眨眼影格；不能只讓整張立繪上下晃。
- **walk**：至少四個可辨識步態影格，腳步交替、手臂與公事包相對擺動。
- **attack**：起手、重心前傾、揮動公事包、擊中及收勢的不同肢體影格；武器與斬擊特效分離。
- **hurt**：手臂縮回、肩膀聳起、表情改變、軀幹後仰，至少一張不同身體姿勢的畫稿。
- **victory**：舒一口氣、疲憊得意地舉杯或提起公事包，至少一張與 idle 完全不同的手臂／表情畫稿。
- **sleep**：垂頭打盹或趴桌睡覺，需實際改動頭、手臂與軀幹位置。
- 所有動作保留同一張臉的特徵、衣服、員工證、腳底基準和統一光源，避免每張都長得像不同人。

**硬性退件：** 只使用單張已核可的大叔全身立繪做平移／旋轉／縮放／閃白；背景存在殘留紫邊或畫筆殘影；有 UI 或文字；幀與幀之間除了整體幾何變換外沒有真實肢體差異；Q 版變回年輕光滑臉的少年。

## B｜後期解鎖：「爆肝加班・頹廢社畜」

A 的**更嚴重過勞版**。相同瘦黑髮日本大叔，可更深黑眼圈、更凌亂頭髮、更明顯鬍渣、領帶更鬆、紅披毯。但 A 本身已是**有點邋遢、帶短鬍渣的社畜大叔**，不能把 A 畫成乾淨年輕人，再把所有成年疲態都塞給 B。B 不會自動成為開局角色；須經活動／遊戲抽獎取得，且美術素材獨立製作。

## 下一階段實作與驗收

1. 先製作 **一張 A 的全身獨立透明角色立繪**。無 UI、無場景、無敵人、無標題，不能用展示圖裁切。
2. 對照本文件逐條檢查年齡感、瘦身形、黑髮、鬍渣、疲憊神情及辦公服裝。**使用者核准外觀**後，才能進入正式製作。
3. 再製作相同角色的待機／走路／公事包攻擊／受傷／勝利／睡覺動作，保持同臉、同服裝與腳底位置，並製作獨立武器和特效層。
4. 每張圖都檢查真實輸出尺寸（基本候選 512×512 或更大母稿）、透明 alpha、留白、裁切、角色一致性、手機實際顯示與動畫表現；再上傳 GitHub 正式 runtime。
5. `art/v19/candidates/hero/*.svg` 目前是已遭否決的扁平工程替身，`v19/app.mjs` 仍引用它們。**絕不可把這些素材視為正式主角。**
6. 其他男女角色、機器人、外星人、怪物、敵人、場景、武器，等到這個首批正式美術品質樣板通過才批量擴充。
