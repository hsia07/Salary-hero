## 二、獨立動畫素材（不可用圖片平移／搖晃冒充逐格）

| 動作 | 最低姿勢／影格規劃 | 必須看出的改變 |
|---|---|---|
| idle 待機 | 至少 4 個實際畫出細微變化的影格 | 呼吸時肩與領帶有差異，眨眼／疲倦 |
| walk 走路 | 至少 6 幀循環 | 雙腿交替跨步、手臂與公事包獨立擺動 |
| attack 攻擊 | 至少 5 幀 | 起手、蓄力、甩公事包、擊中、收勢；軀幹和雙臂姿勢不同 |
| hurt 受傷 | 至少 3 幀 | 明確被擊中後仰、肩臂縮起、五官變化 |
| victory 勝利 | 至少 4 幀 | 疲憊地舉公事包／鬆口氣／無奈得意，不等於 idle 左右晃 |
| sleep 睡覺 | 至少 4 幀 | 垂頭打盹或趴桌，全身姿勢和 idle 明顯不同 |
| defeat 倒地（建議） | 至少 4 幀 | 重心下降到倒地，身體真實轉換 |

以上是第一批動畫工作目標，不表示檔案已製作；每幀可用獨立 PNG/WebP 或等尺寸 spritesheet，需記錄切片表、每幀時長和錨點。

## 三、真正素材 QA（每幀逐一檢查）

- [ ] 來源圖**真實像素**和目標輸出解碼尺寸正確；以 512×512 每幀透明畫布作第一批候選（像素密度可在遊戲需求上調）。
- [ ] alpha 最小為 0、最大可達 255；沒有含背景、UI 字體、紫色去背毛邊、殘留其他物件。
- [ ] 人物頭髮、鞋子、手、識別證和公事包均位於留白邊界內，不裁切；透明 bbox 與地面錨點記錄在素材資料檔。
- [ ] 相鄰幀的角色臉型、身材、衣服、色板和光源一致；逐格真的改變肢體，不只是整張圖片的 affine transform。
- [ ] 武器與攻擊特效分成獨立圖層，真正跟著動作，按裝備更換時外觀也確實改變。
- [ ] 手機 390px 畫面截圖與錄影，確認沒有模糊、跳幀、浮空、比例變形、邊緣紫殘影或過多 UI 遮蔽。
- [ ] 還原同一存檔，角色正常動作、敵人受傷與掉寶，不因缺圖使遊戲無法啟動。
- [ ] 藝術負責人／使用者確認後才把候選素材升入正式 `art/v19/runtime/`，並修改遊戲載入路徑。
