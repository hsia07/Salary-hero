# 薪水勇者 V20 P0.6｜戰利品畫廊：以真正遊戲資料驅動的動態藝術

日期：2026-11-11。**已整合一批獨立道具插畫，非整體美術驗收通過。**

## 已實作
- 七個原創 SVG 道具圖示，獨立存放在 `art/v20/runtime/items/`：厭世公事包、魔法筆電、黃金離職通知書、下班聖劍、古典寶箱、物資禮盒、週末寶箱。絕對不可把這些圖示當成整個場景的替代品。
- `#v20-loot-item-art` 的圖像與 `#v20-loot-item-label` 文字由 `v20LootVisual(state)` 根據正式遊戲 `pendingDrops` 中**真的第一件待領取物品**選擇；四種物品使用固定白名單，未知或舊存檔退回通用圖案，不從使用者輸入產生網址。
- 不碰掉寶機率、數量、角色戰力、薪資或存檔。四種稀有度的裝飾燈效只依照實際待領取物品改變。
- 真正新增待領取道具時，僅對預覽卡播放一次約 0.76 秒非阻塞的發光動態。網頁首開不會假裝收到掉寶。
- 既有 `#claim`、`#chest`、`#weekend-chest` 動態文字仍由 `app.mjs` 更新，只透過 CSS 的 `::before` 繪製獨立原畫，因此不會被動態 `textContent` 擦掉圖示。
- 320px、375px、390px 手機版面保留「一頁不捲動」，小螢幕縮小圖示，保留數字與可點擊區域。
