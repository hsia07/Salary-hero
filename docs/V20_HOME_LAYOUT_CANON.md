## 必須保持的角色與玩法

- 主角仍是**現在這版疲倦厭世的 Q 版日本大叔**：亂髮、黑眼圈、鬍渣、皺襯衫、鬆垮領帶、公事包、略瘦；**不可擅自換成熱血少年／帥氣少年主角**。戰鬥要有明顯的攻擊動作，但角色個性不變。
- 參考圖主要用於**華麗手遊介面、構圖、光照、金紫色系與遊戲資訊排布**，**不是複製參考圖的人物**。
- 所有薪資、貨幣、關卡、敵人、掉寶、裝備、寵物及寶箱數值都連到現有遊戲狀態；畫面不是烤死 UI 的靜態圖片。
- 真實薪資以每月 NT$40,000、台灣週一至週五 08:00–17:00 計算，與遊戲貨幣完全分離。新首頁不得動既有角色存檔。
- 常規玩法首頁禁用垂直與水平捲動；較長的裝備列表、技能、冒險等詳細內容只能在獨立浮窗內捲動。

### 第③區：真正連動的四波進度

- 當前關卡 `wave` 是單一遊戲真實數據。
- `(wave-1) % 4` 表示本輪已完成波數；第 4 格可能顯示真正的 Boss 狀態。不得拿手動遞增假進度裝飾。
- 「寶箱」直接呼叫已存在的 `#chest` 原始開箱流程。**不能額外執行一次開箱或發兩次獎勵**。
- 點擊關卡標題是現有模式選擇功能；非裝飾性按鈕。

### 第④區：真正活著的戰鬥

- 左側：自動戰鬥、倍速、手動攻擊、治療，都保留原本引擎事件與限制。
- 中央：原核准厭世社畜與已有正式怪物圖集，Canvas 繼續播放真正攻擊、受擊與戰鬥技能特效。**不能拉伸比例造成主角變形**。
- 右側：原裝備背包快捷、待領取掉落、普通寶箱、週末寶箱，都依現有數量狀態禁用／啟用；不偽造展示道具。
- 寵物小頭像顯示目前真正 `petLevel`，點擊原寵物養成浮窗。不能展示不存在的真人隊友或四人隊伍。
- 既有流派技能條、訊息列與血條清楚可見，不能重疊在角色上。
