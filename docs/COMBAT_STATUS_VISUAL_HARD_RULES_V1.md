# 戰鬥狀態真實美術硬規則 v1.0
每個增益／減益都必須出現在**角色本體的動作、材質或獨立分層特效**，圖示與浮字僅輔助。每種狀態需有 apply、tick、refresh、expire、cleanse 五種事件；戰鬥數值與視覺事件同步，不可只在畫面顯示狀態但未實際改變攻速／血量／目標。角色眼睛、武器接觸、血條不得被遮蔽。

同來源狀態刷新不乘算；同類增益取最高；DoT至多3層，Boss百分比傷害另有限制；護盾來源各自計算，同源刷新。視覺優先順序：控制→持續傷害→護盾→增益，同時最多2個主特效＋2個局部特效；其他輪播圖示，不能把身體特效完全取消。機器人流血／中毒以冷卻液／腐蝕呈現。每狀態要有形狀、動作節奏、輔助圖示，不可只靠顏色。每角色每狀態都須手機尺寸 QA。高畫質目標60FPS，低階30FPS，降粒子不降本體辨識；禁止以幾何 CSS 圈圈取代正式美術。
