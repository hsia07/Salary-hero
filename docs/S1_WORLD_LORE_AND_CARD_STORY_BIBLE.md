# 《薪水勇者》S1 世界觀與卡牌敘事聖經 v0.1
狀態：企劃基準，非已實作內容。保留既有主角：瘦、邋遢、厭世、Q 版日本中年社畜。所有故事及角色名可隨正式審核修訂。

## 一句話概念
「傳說過勞死的社畜會被召喚到異世界，成為拯救世界的勇者——可是這裡怎麼也要打卡？」

## 世界觀真相（三層揭露，禁止序章劇透）
1. **玩家初見**：女神宣稱勇者能自由冒險。勇者公會卻有每日委託、績效排名、任務打卡、復活後補班。玩家先笑。
2. **中期疑點**：曾經的勇者出現在魔王軍；怪物掉落舊員工證；公會的討伐報告日期比魔王出現日期還早。玩家開始懷疑。
3. **第一季終章**：魔王軍部分高層其實是反抗過公會的前勇者；公會為了維持勇者經濟體系，操縱魔王更替。女神是否知情保留第二季懸念。不要把所有魔王軍塑造成好人，反派仍須有真實威脅和不同動機。

## 遊戲核心主題
- 搞笑先行，偶爾溫柔，但不把現實過勞死亡當成廉價笑點；笑點主要對準荒謬制度、主管話術和異世界行政流程。
- 玩家長期目標：讓所有勇者有權準時下班。
- 不應把真實玩家上班時數轉化為「不工作就無法進度」的強迫機制；薪資即時增長維持既有規則。

## 序章《歡迎入職，勇者先生》
鏡頭 1：深夜辦公室，主角最後記得的是電腦跳出「可以再改一版嗎？」；鏡頭切黑。避免寫實呈現死亡過程。
鏡頭 2：異世界聖殿，女神宣告「你已經不必再上班了！」
鏡頭 3：公會職員遞上《勇者委任契約》：「每日工時自由安排，最低八小時。」
鏡頭 4：主角：「等一下，這不就是換地方上班嗎？」
鏡頭 5：職員：「當然不是。我們這裡提供死亡復活福利。」
鏡頭 6：主角：「……那有特休嗎？」
鏡頭 7：職員微笑：「請先通過試用期。」
開放玩家首次戰鬥：怪物「失控公文史萊姆」，擊敗後掉落「未簽核的請假單」。
結尾伏筆：公會倉庫一張沾灰的勇者證，上面寫「離職申請：駁回」。

## 第一季六個主線篇章（劇情進度不綁定真實薪資）
1. **異世界新人訓練**：打卡機盾牌、第一場戰鬥、勇者公會。
2. **無盡的試用期**：怪物竟然會使用績效評估表；開啟轉職與隊伍。
3. **星期一的詛咒**：週一地獄活動接入主線，出現第一位菁英主管。
4. **消失的離職單**：探索廢棄勇者宿舍，發現前任勇者的生活痕跡。
5. **魔王軍的人事部**：第一次看見魔王軍成員佩戴舊公會徽章。
6. **準時下班革命**：對抗公會中層，揭露部分真相；第一季結尾留下女神伏筆。

## 卡牌角色敘事標準
每個可招募角色均有：
- **生前檔案**：職務、荒謬職場事件、代表台詞；不得把死亡細節當笑點。
- **異世界檔案**：召喚後的職業、武器由何種辦公用品變化而來、與公會的關係。
- **羈絆**：至少兩段與其他角色互動；角色對話必須帶出個性，不只提供數值。
- **N/R 卡**：角色日常和反差笑點。
- **SR/SSR 卡**：職業高光時刻，卡牌構圖有前中後景，支持視差。
- **UR 卡**：獨立短篇故事和長按演出。
- **MR 卡**：完整微型場景、沉浸式長按動畫及故事反轉；必須保留正常靜態欣賞模式。
稀有度是卡面製作規格與收藏性，不應直接等同角色強度。

## 第一批七人角色故事鉤子
- **薪奴／終焉加班者**：生前最擅長回覆「收到」，異世界最強技能是把所有命令設成「已讀不回」。
- **打卡守衛／全勤聖盾**：拿打卡機當盾，曾為守護出勤紀錄獨自對抗颱風；真正恐懼的是系統漏打卡。
- **逃班鬥士／最後五分鐘**：能看見所有建築的逃生出口，唯獨公會永遠找不到出口。
- **截止日刺客／紅字終結者**：武器是裁紙刀，所有敵人頭上都有倒數計時；她自己的截止日永遠是「昨天」。
- **試算表法師／禁忌函數師**：能用公式改寫現實，唯獨算不出自己還剩多少特休。
- **咖啡醫官／第三杯奇蹟**：治癒隊友的方法是把咖啡當生命藥水；其實最想研究無咖啡因睡眠魔法。
- **機械工程師／影印機造物主**：發明能自動完成所有文書工作的機兵，卻因機兵效率太高，被交辦更多工作。

## 卡牌藝術製作規範
- 戰鬥 Q 版與卡牌高解析立繪為同一角色設定，分開繪製；不可放大低解析戰鬥圖冒充卡面。
- 每張卡片需分層：角色前景（頭、髮、軀幹、左右臂、武器、表情）、場景前中後景、遮擋物、箔膜/反光遮罩、光效、粒子、字幕/卡框。
- 卡牌可左右滑動產生視差，避免只把整張平面圖片旋轉；UR/MR 長按才播放獨立角色與場景動畫。
- 優先製作薪奴與打卡守衛兩位的完整視覺規格：戰鬥待機/攻擊/受擊/技能，以及 N→MR 卡面分層與故事板。
- 禁止以 CSS 幾何拼接、單張圖整體晃動、文字表單代替正式角色美術。
- 以直式手機單畫面為主要驗收環境，長按不得妨礙基本觸控操作，支援減少動態效果。
