# 機械工程師・阿拓｜個人背景與召喚後故事 v1
**狀態：角色完整背景初稿／四幕可玩故事構想，尚未實裝。** 阿拓屬辦公室陣營第十人，不是機械生命；他是人類工程師。不得改動工作死亡：修復遭管理階層強制啟動的自動化產線，為保護現場工人而殉職。

## 第一幕｜被省下來的人
阿拓在原世界替工廠設計自動化改造。他相信效率提升後，同事可以少加班；投產後，主管卻以「既然機器會做，三個人可以做五個人的工作」為由縮減人力。阿拓拿到績效獎金，卻看見師傅老秦被調去危險的夜間保養班。
老秦：「機器不是壞人。把人當機器用的才是。」
阿拓：「我會把維修停機權寫進系統。」
老秦：「誰有權把它關掉？」

## 第二幕｜被刪掉的停止鍵
主管要求移除產線停機確認，說每停一分鐘就損失巨額訂單。阿拓在更新前猶豫，最後只把停止鍵藏進二級維修頁面，沒有公開反對。
一次夜間故障中，老秦按不到停止鍵。阿拓衝回產線，親自進入危險區，將被困工人推出安全線；強制啟動的設備再次運轉，阿拓在**工作中的搶修救援**殉職。不是失業後傳送，也不是在召喚世界死亡。
**遊玩呈現**：玩家在原世界回憶段落操作維修機構與緊急停止路線；結局固定為阿拓死亡，但可以救出不同數量的背景工人，不能用操作改成阿拓沒死。

## 第三幕｜不能再按一次
阿拓在召喚世界醒來，被安排修理公會的召喚與復原設備。看見「祕密復活裝置」時，他第一反應不是興奮，而是檢查安全停止機制。
七號：「本裝置沒有人工中止鍵。」
阿拓：「那就不是復活裝置。那是另一條會吞人的產線。」
七號：「你有證據？」
阿拓：「沒有。我有一個死人不會再有的機會。」
阿拓拆下設備的供能模組，導致公會短暫停電；他的懷疑後來證實部分正確，但也耽誤了其他人的醫療設備。
**衝突**：七號重視程序，阿拓重視可中止性；伊芙要求完整備份，阿拓擔心備份會讓強制啟動再次發生。兩人不是生前同事。

## 第四幕｜留一個人能按的按鈕
阿拓與七號共同修好設備，增設多方授權停機機制。公會拒絕立即採用，因為停機會影響供能效率。
老秦的聲音只出現在阿拓回憶裡：「誰有權把它關掉？」
阿拓：「至少不是只有主管。」
**結尾**：他仍喜歡機械，也仍為自己設計的效率感到驕傲；但每台新機器都必須有任何受影響者能提出停機申請的管道。
**玩法**：真實機械拼裝、能量路徑、緊急停機與護衛戰；專武修復系統與召喚器件需要正式分層美術，不能用文字表單替代。
**驗收**：原世界工作死亡固定；召喚後與七號、伊芙才相識；所謂復活裝置不得直接推翻「召喚不等於復活」的世界觀鐵律，其真實用途留待世界主線揭露。
