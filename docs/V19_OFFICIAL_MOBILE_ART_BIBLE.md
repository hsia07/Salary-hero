# 《薪水勇者》正式手機手遊美術標準 — 不能再偏離

狀態：**以用戶已核准的參考圖片為唯一首要視覺準則**。更新：2026-11-11。此規範高於任何工程階段的幾何 placeholder 或一般 UI 設計模板。

## 正式參考及目標

- **唯一首頁美術母圖**：`art/v18/portrait-home-master.webp`（1024 × 1536），參考其中的金色浮雕《薪水勇者》字樣、暖金色深紫色 RPG 資源框、晚霞藍紫色魔法辦公室、植物與花瓣、羊皮紙薪資牌、柔和高光、戰鬥光弧與八個大型立體功能圖示。
- 輔助概念圖：`art/v18/home-scene-concept.webp`。只用於場景題材與手繪氣氛，不得把橫式版型套進手機。
- **版面硬規則**：手機直式一屏，首頁永不垂直捲動，8 個底部功能入口；依可視 `100dvh` 分配頂部狀態、互動據點、即時戰鬥、底部主選單。長篇內容只能在自己的 dialog 畫面內捲動。參考程式：`v19/portrait-one-screen.css`。

## 核心畫風與材質

- **幻想日系手繪 Q 版 2D RPG，立體高質感**；不是扁平剪影、工程 SVG 幾何堆疊、表單或一般網站主題。
- 背景：皇家藍紫色魔法窗景、夕陽粉紫霞光、會亮的暖金色吊燈、復古木質辦公桌、厚紙書冊與飄落紙張、精緻葉片和少量花朵。深色陰影要有辨識度，不能留下大片純黑色空洞。
- UI 材質：有厚度的**金色雕花金屬邊、微微玫瑰色磨損、玻璃或寶石高光、羊皮紙、深紫色皮革與玫瑰木**。所有主要按鈕都有描邊、內側高光、深色側邊和按下回饋；文字必須清楚。
- 色票為參考目標、非精確像素測量：深紫夜 `#20172F`、莓紫木色 `#513149`、暖金 `#F4C775`、古銅 `#E8A65F`、暖乳白 `#FFF0CE`、花瓣粉 `#B36E7F`、魔法藍 `#6CA2D9`、星光薰衣草 `#A996DC`。相較前版，降低黑色背景與灰紫色平面面板比例、提高暖金光與故事感。
- **正式薪資牌**：淺米色羊皮紙、金邊、褐色字，「今日薪資」顯眼，薪資按照 40,000 元月薪與台灣週一至週五 08–17 的真實時間更新。絕不為視覺而使用假金額。
- **正式戰鬥場景**：角色與怪物都是獨立逐格圖集，由遊戲引擎控制攻擊、受傷、紅閃、掉寶與結算。不得拿一張包含已畫好的角色／UI 的靜態截圖當整個遊戲背景。
- **人物美術**：主角維持先前核准的**偏瘦、略邋遢、有鬍渣、鬆散領帶、辦公包的日本中年社畜大叔**，Q 版但不幼化；目前老舊像素版角色和手繪參考的完成度仍有差距，之後要以相同辨識度重繪。
- 怪物與時裝：不可直接換成擺動／晃動幾何模型。普通怪已核准圖集沿用，菁英與 Boss 需另繪。正式換裝要求服裝跟著逐格姿勢有實質不同的畫面，不只是簡單貼紙。

## 可互動且有生命的主畫面

- 主角：真正 idle／攻擊／受傷逐格動畫；主城可點擊查看角色。
- 貓、咖啡、時鐘、薪資牌、冒險標籤：獨立可點區域，觸控無重疊；貓、蒸氣、光影、葉片和場景有細緻循環動畫。
- 戰場：主角和敵人逐格動畫、受擊變紅、傷害跳字、流派連攜、可調速度、自動／手動切換、掉寶。禁止用一張假「正在打怪」的繪圖冒充運作。
- 底部 8 圖示：首頁、角色、冒險、裝備、鍛造、寵物、公會、商店。每格要有真實動作或清楚標示未開放；同一套原畫風格，不能混用五種 emoji、線框與平面幾何。
- 禁止：空白黑窗、三排功能列、額外 QA 工程選單長期占位、超出可視畫面的功能按鈕、關鍵數據被裝飾藤蔓擋住、細節視窗打開卻不響應、純 UI 樣板風。

## 驗收

- 測試 `scripts/qa-v19-portrait-home-mobile.py` 應在 390×844、375×667、320×568 三種手機 viewport 驗證主畫面沒有上下左右捲動，八個可點圖示、薪資、角色、寵物、鍛造、戰鬥與存檔不中斷。
- 要以真手機截圖對照母圖確認：**UI 是否有金屬體積與暖金燈光、背景是否有豐富城市夜景、角色是否仍是核准 Q 版社畜、按鈕是否真的可點、薪資牌是否清楚、是否存在大量暗色空白或幾何假裝飾**。
- 樣式檔不能單獨當作美術完成的證據；所有正式美術要搭配源素材、頁面整合和實際瀏覽器視覺驗收。
