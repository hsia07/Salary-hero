# 《薪水勇者》同事養成規則

狀態：使用者於 2026-11-12 確認核心規則；數值及素材細節為待核准提案。

## 已確認的硬規則
- 「同事」可升級、進階，養成需要消耗素材。
- **任何同事的實際等級不得超過「薪奴」目前等級。**
- 同事的突破／進階若解鎖更高的等級上限，也不得繞過薪奴等級限制。
- 介面應顯示有效上限 `min(同事突破階段上限, 薪奴等級)`；達到上限時禁止繼續消耗升級素材。

## 待核准的設計建議
- 升級：經驗素材與薪幣，提升基礎屬性。
- 突破：突破材料與薪幣，提升該同事的階段等級上限。
- 進階：職業材料及專屬材料，改變或強化技能機制。
- 技能升級：技能書與薪幣。
- 覺醒：稀有素材，解鎖角色專屬戰鬥機制。
- 建議等級階段：20／40／60／80／100，尚未定案。

## 施工驗收
1. 薪奴 Lv.37、同事已突破 Lv.40 時，同事最多只能 Lv.37。
2. 薪奴升到 Lv.38 後，同事可繼續升級至 Lv.38，仍須消耗素材。
3. 同事突破、進階、讀取舊存檔、批次升級及自動託管均不可繞過限制。
4. 素材不足或達到上限時，禁止扣除素材。
5. 新增介面與特效須遵循正式美術規範，不能只做表單。
