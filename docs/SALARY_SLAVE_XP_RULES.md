# 《薪水勇者》薪奴經驗值與升級規則

狀態：2026-11-12 使用者確認經驗來源方向；倍率與曲線為待核准提案。

## 已確認
- 「薪奴」透過每次戰鬥獲得經驗值（EXP）。
- 副本通關另外獲得經驗值。
- 薪奴等級限制同事的最高實際等級，見 `docs/COLLEAGUE_PROGRESSION_RULES.md`。

## 待核准建議
- 一般怪提供基礎戰鬥 EXP；菁英 3–5 倍、Boss 10–20 倍（暫定）。
- 副本通關獎勵 EXP 與擊殺 EXP 分開結算，可同時領取。
- 首次通關可獲得一次性額外 EXP；無限之塔層數通關與奇遇戰鬥也可獲得 EXP。
- 經驗來源與獎勵應顯示於戰鬥／副本結算動畫。
- 不應只因現實時間流逝或薪資計數增加而無條件提升薪奴等級；掛機實際完成戰鬥時可獲得 EXP。
- 應防止重複結算、離線刷經驗異常、失敗領取完整通關獎勵、重複領首次通關獎勵。

## 建議驗收
1. 一般戰鬥勝利：薪奴獲得 EXP，正確處理升級與溢出 EXP。
2. 副本通關：戰鬥 EXP 與通關 EXP 分開顯示並正確加總。
3. 首通獎勵僅能領一次；失敗不領通關獎勵。
4. 薪奴升級後，同事有效等級上限同步提高，但同事不會免費自動升級。
5. 正式美術、特效、動態結算頁面，不以純表單替代。
