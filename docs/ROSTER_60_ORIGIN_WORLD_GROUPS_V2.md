# 60名角色｜依生前世界重新分組 V2

**正式分組索引：12組×5人＝60人，無重複、無遺漏。** 取代舊版按故事關係混組的 G01–G11；此文件只定義生前世界分組，**不直接改寫任何角色的既有死亡事件或個人故事**。

同一組＝相同「原世界類型」；尚不代表五人都住在同一城市、年代或彼此認識。之後逐組編寫時，可指定具體共同宇宙與生前交集，也可以五人完全不認識。死後進入共同召喚世界的跨組友情、戀愛、婚姻與仇敵，全部允許且不改組。

## 關係時間線規則
1. 生前關係必須證明兩人屬於同一具體子宇宙、同時代且有相遇機會；同一世界類型不夠。
2. 不要求同組所有人認識。各角色可以有自己的家庭、愛人、同事及未列入60人的NPC。
3. 死後關係不受分組限制，跨組情侶、宿敵、朋友都不需要搬組。
4. 已提出的薇菈×璃音生前摯友、薩洛×妮亞生前前任、蘇妲×清目生前戀人都仍是待審故事方案；三組各自仍在相同世界類型中，沒有拆開。
5. 敖璃只出現在W07神話職務世界，不再放進薇菈璃音的生前組；若死後與她們有交集，另行寫出實際相遇事件。
6. 前一版G01五人故事屬**跨世界劇情初稿**，不再代表正式分組；相關故事內容可在後續重寫時選用，不能因分組錯誤強制保留不合理交集。
7. 每組逐人驗收完整故事、獨特主題、不可逆選擇及結局；跨組驗收避免60篇換皮重複。
