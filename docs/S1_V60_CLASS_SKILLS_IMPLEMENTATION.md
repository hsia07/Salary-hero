# 《薪水勇者》V6.0｜七人職業專屬主動技初版（實際遊戲）

狀態：已推送 GitHub 的**可玩測試版本**。本文是數值與驗收基準，並非全套正式養成完成。
對應：`boss-v5-dungeon-runtime.js`、`v19/s1-hero-active-skills.mjs`、`v19/s1-party-ai.mjs`。

## 與過去「純裝飾」的差別

1. **打卡守衛｜打卡護衛**：選擇守衛以外最脆弱的存活隊友（目前依 100HP 標準與既有盾值），生命比例低於 70% 時優先施放；或 Boss 怒氣高於 75 時提前啟動。接下來 5.2 秒，該隊友受到的原始傷害 30% 轉由打卡守衛承受。守衛受自己的防禦／護盾計算影響；守衛死亡就停止轉移。冷卻 11.8 秒。獨立「打卡鐘盾牌＋守護羽翼」兩層美術在守衛與受保護者身上呈現。
2. **試算表法師｜矩陣散射**：有 2 名以上敵人時可啟用，瞄準敵人較密集的中心，首名目標傷害倍率 0.68，另外最近至多 2 名為 0.37（倍率乘上原本 21 基礎傷害 ×角色攻擊比例）。每個目標**獨立扣血、受擊、死亡**，已倒下的怪不再承傷。法陣先在角色與怪物身上展開，經 460ms 前搖才按順序結算；冷卻 9.9 秒。兩層美術為「魔法試算表＋矩陣爆裂」。
3. **截止日刺客｜背刺稽核**：優先選敵方遠程／法術／控制／支援類，再參考殘血與精英減權；傷害等於 24 基礎值 × 攻擊比例 × 1.48。直接使用近戰衝刺、接觸才扣血的引擎；武器與殘影為獨立兩層素材。冷卻 10.7 秒。**目前是突襲目標選擇＋衝刺，尚未完成真正繞到背面的逐格身位切換**。
4. **咖啡醫官｜下班醒腦咖啡**：依狀態優先權清除一名存活隊友身上一層異常：`stun` 暈眩 → `paycut` 治療下降 → `slow` 減速。冷卻 13.7 秒。刪除的是**實際狀態引擎中的效果**，不只是關閉圖示；咖啡杯＋淨化星光兩層附著在施法者與隊友身上。

其他角色仍使用 V5.9 的職責：逃班鬥士近戰追擊，機械工程師為全隊提供 6.5% 最大 HP 護盾，薪奴在每波勝利保護最低生命比例隊員獲得 10% 最大 HP 護盾。

## 已接入的防禦素質

目前 V5 沙盒每人**仍以 100 HP 作為當前生命百分比基準**；角色原設計 HP（150/118/88/106/92/116/125）尚未全量接入，不可稱完整 HP 屬性完成。

現已使用角色基準 DEF 算式：
`受到傷害係數 = clamp(200 / (100 + DEF), 0.75, 1.16)`。

例如 DEF 155 的打卡守衛，受到普通原始攻擊的約 78.4%；DEF 75 的刺客則約承受 114.3%。所有角色的 Buff、Debuff、護盾及分攤統一走實際傷害函式；魔王／副本既有倍率**不可重複乘兩次**。
