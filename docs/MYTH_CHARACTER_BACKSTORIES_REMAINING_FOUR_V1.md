# 神話陣營獨立背景故事｜第二批四人 v1
狀態：**角色背景候選稿，非小說、非完整覺醒劇本、未實裝。** 本批完成神話陣營剩餘四人的個人背景。與《西遊記》有關的世界歷史只作背景，不強迫與師徒同行。

## 搗藥仙兔・小玉（R）｜《三更的藥香》
**出身與生活**：小玉在廣寒宮藥房長大。別人只知道玉兔搗藥，她卻最喜歡把各種失敗藥丸壓成不同形狀，偷偷給輪夜班的小仙當糖吃。她有一本用藥渣畫的小冊子，記錄每個人睡不著的原因。她不覺得自己是大人物，最大的願望是有一天能開一間不必半夜營業的小藥鋪。
**性格缺陷**：心軟、怕讓人失望；只要有人說「就拜託你了」，她就不敢拒絕。她把每次疲倦都歸咎於自己手腳太慢，也常把藥方改得更甜，讓不肯吃藥的人願意入口，卻曾因沒有充分說明副作用而害一位仙童過敏。
**改變她的事**：月宮為趕製夜班提神藥，開始用尚未通過試驗的禁方。小玉發現新藥會讓人短暫精神百倍，之後卻失去痛覺，連受傷都不知道。她起初不敢向藥房主管反映，只把一小袋樣品藏進搗藥杵中。
**工作死亡**：一次配藥事故造成同僚中毒。她依照自己研究的逆方救治眾人，最後為阻止禁藥繼續擴散，以自身承受藥性反噬，仙魂消散。**不是因被迫加班本身死亡，而是工作現場的禁藥救援。**
**死後召喚**：她醒來後第一句話不是問自己在哪裡，而是問「藥罐洗乾淨了嗎？」她以為自己只睡了一會兒，直到看見自己的搗藥杵缺了一角。
**與其他人**：嫦月是月宮巡夜官，可在生前透過藥房與巡夜職務認識，但親疏待劇本確定。她不必與悟空或八戒有私人交情。
**故事玩法**：藥房調製／辨識副作用、救援中毒隊友、對抗會讓治療變成傷害的禁藥怪。
**專武**：月宮搗藥杵；藥渣冊是劇情物件，不是武器。
**故事收束**：她在異世界終於有機會拒絕一張急單，卻發現真正困難的是說完「今天不接」之後不立刻道歉。

## 天庭監察・清目（SR）｜《第三份報告》
**出身與生活**：清目做了幾百年的監察官，習慣在奏章旁寫小字。他的第一份報告寫得過於尖銳，被退回；第二份把所有指控都改成委婉語氣，順利通過，卻什麼也沒改變。自那以後，他開始把真正的調查結果另寫一份，鎖在抽屜最底層。
**性格缺陷**：精明、多疑、愛留後手；他擅長查別人的錯，卻不敢在最重要的時候署自己的名字。他曾因害怕失去官位，讓一位提出證據的小吏獨自承擔責任。
**改變他的事**：他奉命查核一座能預測「天庭績效」的天機爐。帳上所有數字都漂亮，爐邊工匠卻一個接一個失蹤。他發現績效預測其實把工匠的壽命當成燃料。
**工作死亡**：他依法查封天機爐，現場發生爐爆。他把帶路的證人推出封鎖範圍，自己承受爆炸而死。這不是一場預先安排好的殉道，而是他第一次在公文之外，真正承擔了署名的後果。
**死後召喚**：公會請他填入職調查表。他先要求看前一位填表者的下場，然後把表格翻到背面，開始檢查印刷廠與批准機關。
**與其他人**：哪吒不喜歡他查半天不動手；清目則認為哪吒總把證據一起燒掉。兩人可能在原世界因職務相遇，但具體共同案件待定。
**故事玩法**：現場勘驗、比對三份內容不同的報告、在證人保護戰中保住證據。
**專武**：監察法鏡（本作原創候選，外觀待核）；第三份報告是劇情物件。
**故事收束**：最後一份報告沒有藏在抽屜裡，而是寫上自己的名字，公開放到所有人都能看到的地方。

## 雲端信使・霓霓（R）｜《收件人不詳》
**出身與生活**：霓霓是雲路信使，飛得不算最快，卻認得天庭最難找的後門。她會偷偷收藏收件人寫錯的信封，覺得有些名字明明只差一筆，人生卻可能因此走岔。她最大的夢想是存夠錢，買一朵只載自己、不載公文的雲。
**性格缺陷**：嘴甜、機靈、怕麻煩，遇到危險時第一反應是繞路。她曾為了準時交差，把一封看似不重要的求助信放到隔天，結果寄信者當晚就失去工作與住所。
**改變她的事**：天庭開始攔截一批辭呈與求救信。霓霓發現收件人其實並非不存在，而是被從天界地址簿上刪掉。她不擅長打架，只能記住一條又一條不在地圖上的小路。
**工作死亡**：在天庭風暴中，她仍執行送出被攔截求救信的職務，為了不暴露收件人的藏身處引開追兵，最後在風暴中殉職。
**死後召喚**：她看見召喚公會的郵件堆積如山，立刻轉身想走；但櫃檯上有一封寄給她自己的信，署名是她生前最後一位收件人。
**與其他人**：與白羽的跨世界聯繫發生在死後召喚後；不可寫成生前同事。
**故事玩法**：雲路穿梭、躲避追擊、辨識偽造地址與選擇安全送達路線。
**專武**：雲梭信使杖（本作原創候選）；未寄出的信是劇情物件。
**故事收束**：她終於買到自己的小雲，卻選擇偶爾替真正需要的人送信。這次不是因為有人命令她。

## 九尾審稿官・蘇妲（SSR）｜《退稿》
**出身與生活**：蘇妲是狐族出身的天庭審稿官。她審核的不是詩，而是天庭對外公布的詔書、戰報與史書節錄。她對文字極挑剔，連飯館菜單都會拿朱筆改錯字。她最擅長讓一句明明很殘忍的命令，讀起來像是體恤眾生。
**性格缺陷**：優雅、尖刻、極會自保；她相信文字本身沒有善惡，責任只在下命令的人。直到一份經她潤飾的詔書導致狐族村落被當成叛亂者清剿，她才發現自己不是旁觀者。
**改變她的事**：上級要求她發布一份新的征討令，並附上能強迫讀者服從的詛咒。她試過刪字、換句、拖延審核，卻發現詛咒會在詔書正式發布時自行補全。
**工作死亡**：她在審稿職務中拒絕發布致命假命令，改以九尾靈力將詛咒與詔書一起銷毀，靈力耗盡而死。她不是因為「寫出真相就自動犧牲」，而是面對一份具體會殺人的文書。
**死後召喚**：她發現異世界公會的英雄介紹把她寫成「魅惑眾生的九尾妖女」。她沒有生氣，只拿起筆，把「眾生」兩字劃掉，改成「編輯部」。
**與其他人**：與清目在異世界可能交換被刪改的報告；與悟空沒有必要的愛恨糾葛。角色採本作原創狐族文官設定，**不等同《封神演義》的妲己**。
**故事玩法**：調查真假詔書、辨識被替換的關鍵字、對抗會修改戰場指令的詛咒Boss。
**專武**：九尾法筆（原創法器），朱筆與詔書殘頁是劇情遺物；正式外觀待核。
**SSR覺醒三章**：
1. 《原稿》：公會發現一份與她生前清剿令同樣措辭的命令，要求她替它潤色。
2. 《校對》：玩家在副本中找出會改寫隊友行動的詛咒字句；蘇妲必須保留證據而非直接燒毀。
3. 《退稿》：她當眾拒絕署名，公開所有修訂紀錄，並與詛咒化身交戰。覺醒後九尾法筆能**標出敵方偽裝與被篡改的技能指令**，而非單純提升傷害。
**覺醒專武外觀**：法筆由單一墨色筆鋒進化為九道可分層活動的狐火筆勢，筆身仍保留筆的清晰輪廓；技能特效是真實的筆劃落下、字形封印、敵方偽裝破除，不可只用一張字圖淡入淡出。
**故事收束**：她仍然會挑別人的錯字，但再也不替殺人的命令找漂亮說法。
