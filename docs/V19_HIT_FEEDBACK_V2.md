# V19 主角進階受擊 V2｜實裝與驗收

日期：2026-11-09。目標：保留已認可的高品質 Q 版瘦日本社畜大叔，強化實際戰鬥時的受擊感；不是再製作只有 UI 的概念圖。

## 已提交的程式

- `v19/hurt-effects.mjs`：純函式、無隨機抖動的受擊 VFX 時序與位置，總長 598ms，支援減少動態效果偏好。
- `v19/app.mjs`：實際戰鬥受到敵人反擊損 HP 時，先紅白閃、角色 Hit Stop 48ms，再短震 112ms 內衰退；角色附近顯示紅橘色火花，接既有五個不同肢體姿勢。使用離屏 Canvas 的 `source-atop` 給**角色本體**著色，並非整張背景或 UI 變紅。
- `v19/engine.mjs`：反擊時紀錄實際受到的傷害 `last.retaliationDamage`。即使重傷 HP 歸零、原引擎立即復活回滿，也保留 `respawned` 訊號給 VFX；**不改變既有戰鬥數值、復活規則、金幣、薪資或存檔**。
- `v19/hurt-timing.mjs`：受擊判定支援實際反擊傷害（含瞬間復活），但首領勝利、治療、沒有扣 HP 時不播放。
- `v19/play.html?art=chibi-v2`：測試模式中的「💥 預覽紅閃＋停頓＋震動＋火花（不扣血）」可**直接點擊**，即使尚未上傳五姿勢 WebP。若已載入 `hurt_5pose_384.webp`，則會同時切換五個真實受傷姿勢。

## 精確時間表（遊戲時鐘）

| 時間 | 效果 |
|---|---|
| 0–20ms | 白粉色短閃 + 停住第一受傷姿勢 |
| 20–48ms | 轉紅，持續 Hit Stop |
| 48–76ms | 開始短震與紅色閃光衰減 |
| 76–156ms | 局部紅色餘光淡出；震動在 160ms 前結束 |
| 20–175ms | 僅在人物附近的白芯紅橘色火花逐漸消失 |
| 48–598ms | 逐格播放既有 550ms 的五個不同姿勢，然後回到待機 |

- 短震最多 12px 水平、4.8px 垂直；沒有全螢幕模糊、畫面變紅或長時間搖晃。
- 打擊停頓只凍結**主角動作姿勢**，不凍結真實時間薪資計數與遊戲 UI。
- `prefers-reduced-motion` 將震動歸零，降低閃光與火花強度。
- 1x/2x 都以戰鬥時鐘計算自動受傷；「預覽」維持現實 598ms，且絕不觸發 `transition` 或扣 HP。
- 受擊顯示遵循已確認的角色設定；新的動作圖片仍是候選，正式美術核准後才升正式 runtime。
