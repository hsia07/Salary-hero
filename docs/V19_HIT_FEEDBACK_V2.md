# V19 受擊特效 V2｜紅閃、停頓、震動與真正五姿勢受傷

更新：2026-11-09。

最初只提交程式而未提交高品質二進位圖，所以使用者實際看見舊 128px 攻擊、無受傷人物動畫。本次已確認並修復此根本問題。

- **遊戲預設生效：** `v19/play.html`（不需額外參數）。
- **攻擊素材：** `art/v19/candidates/characters/starter/chibi/attack-v2-7pose-512.png`，7×512px。
- **受傷素材：** `art/v19/candidates/characters/starter/chibi/hurt-v1-5pose-384.webp`，5×384px。
- **受擊判定：** 僅當敵人實際反擊扣 HP 才自動播放；致命傷害雖自動回滿仍被記錄，治療、勝利、未受擊不觸發。
- **特效節奏：** 0–20ms 白閃、20–76ms 紅閃；前 48ms 角色 hit-stop；48–160ms 短震（水平不超過 12px，垂直不超過 4.8px）；20–175ms 橘紅局部火花；48–598ms 五姿勢受傷。
- **無障礙：** `prefers-reduced-motion` 停止震動、減少閃光強度。
- **驗收功能：** 遊戲畫面內有高清載入狀態及一鍵受傷測試，不扣 HP。Safari 快取透過入口 JavaScript 版本號清除。
- **測試：** 邏輯、靜態載入路徑、圖片大小與透明邊界已檢查；GitHub Pages 與 Safari 實機結果尚未由此環境確認。候選素材並未假稱為正式核准美術。
