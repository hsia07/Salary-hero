# Salary Hero V19 — 自訂暱稱、角色造型概念與敵人擴充

## 本輪變更（2026-11-09）

### 玩家命名
首次在 V19 進入遊戲且尚未命名時，會顯示命名視窗。遊戲內固定角色稱號為：

**平凡社畜・{玩家輸入遊戲名稱}**

- 玩家自己輸入遊戲名，不固定寫「夏」。
- 暱稱支援一般 Unicode 字元與 Emoji；取前 12 個 Unicode 碼點，去除控制字元及首尾空白。
- 名稱儲存在 `salary-hero-v19-save-1` 的 `playerName`，同樣的存檔內保留裝備、金幣、關卡、收藏等既有資料。
- 可在「角色」頁修改名稱；不因此重置關卡、薪資或遊戲資產。
- 為避免輸入 HTML 被解析，玩家名稱在對話框內容經過 HTML 跳脫；一般 HUD 使用 `textContent`。
- 薪資（NT$）仍依台灣時間週一到週五 08:00–17:00、月薪 40,000 元獨立計算，遊戲命名、戰鬥、金幣與外觀皆不可修改實際薪資推估。

### 16 種角色造型概念

在 `v19/roster.mjs`：男性上班族、女性事務員、頹廢加班族、會計魔女、銀髮主管、打卡機器人、仿生秘書、外星實習生、銀河客服員、史萊姆、骷髏會計師、幽靈、吸血鬼、獸人、龍族、蘑菇工讀生，共 16 個方向。

- **起始預設仍是 A（瘦、黑短髮、乾淨但疲憊的日本上班族）。**
- B（鬍子拉碴的「爆肝加班・頹廢社畜」）保留為後期解鎖造型方向。
- 在「角色 → 角色造型參考」可瀏覽／收藏喜歡的概念；收藏清單會跟著遊戲存檔。
- **只有資料清單與概念圖示。尚未有通過人工美術與手機載入驗收的 16 組正式角色動畫，不能說已完成換裝。**
- 稀有裝備與造型日後必須有不同透明圖層與動畫，不得再用整張畫面圖片冒充角色。

### 24 種真正不同的敵人資料

在 `v19/roster.mjs`：16 種一般敵人、8 種首領，包含文件精怪、咖啡擬態獸、家具魔像、幽靈、植物怪、外星工蜂、機器人等，並有 8 種職場主題首領。

- `enemyFor(wave)` 確定性輪替，**每四關一場首領戰**。
- 三種特殊機制：`guard` 實際減傷 25%；`leech` 受擊後自我回復 HP；`rage` 增加反擊傷害，非純改名。
- 倒下的物種 ID 會存入 `defeatedTypes`；圖鑑在擊敗後顯示真名與能力，未擊敗前顯示剪影。
- 戰鬥場景會變更敵人名稱、種類、特性、圖示和狀態；原本已備有的報表小怪與印表機使用獨立 SVG。
- **其他新怪目前使用暫用 Emoji 視覺，不宣稱正式怪物動畫已製作或通過美術驗收。** 後續按首領／一般怪物分批生成、檢查尺寸、透明度、裁切與手機實測，再替換暫用圖示。

### 風險與交付範圍

`v19/play.html` 是可玩工程試驗版本，GitHub 主入口目前仍保留 V18 既有精緻首頁，**尚未完成兩者的正式畫面整合**。目前沒有全新 512×512 正式角色、敵人動畫圖檔，因此不改寫 V18 的 13 張正式素材缺口數量。

技術驗證：`v19/engine.test.mjs` 覆蓋命名、持久化、敵人輪替、BOSS、特殊能力、收藏、圖鑑及薪資計算；GitHub Actions 在工程檔變更時會執行語法和邏輯測試。瀏覽器視覺、iOS Safari 動畫和正式美術仍需實機驗收，不可標為「已通過」。
