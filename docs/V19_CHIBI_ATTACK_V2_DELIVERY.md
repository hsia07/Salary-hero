## 動畫節奏／技術規格

七姿勢時長（毫秒）：`[115, 135, 95, 60, 145, 100, 155]`，總長 `805ms`；命中動作起始時間約 `405ms`。以 Q 版角色固定的腳底位置播放，不用單張圖片整體位移、拉伸或交叉溶解。角色進遊戲時要由約 384～512px 高解析來源縮小顯示，不再將 128px 影格放大到 306px。特殊攻擊另由 Canvas 繪製碰撞/命中特效。

本機實際像素 QA：七張 PNG 均為 512×512、具有 RGBA 和透明外緣、人物與公事包均沒有碰到畫布邊界；相鄰影格像素不相同且腳底對齊。**這不保證美術已達正式品質**。原始七姿勢來自生成的白底動作表，使用影像分離製作透明素材，髮絲細邊和白襯衫可能仍有少量白色殘邊，需人體審圖。

本機 Chromium/Playwright 的 `127.0.0.1` 與 `file://` 導覽受到環境管理員阻擋；但改用**內嵌 PNG 的自包含 HTML**透過 `page.set_content` 實際執行了 390px、DPR 2 的 Chromium 行動裝置模擬。成功確認 3584×512 PNG 真實解碼、七姿勢播放（500ms 進入第 5 格命中、1000ms 完成第 7 格收勢）、逐格切換、沒有橫向溢出或 JavaScript 錯誤，並實際擷取預覽畫面。**這是離線動畫驗收頁的瀏覽器測試，不是 GitHub Pages 上的完整 V19 遊戲或 iPhone Safari 實機驗收。** GitHub Actions 尚未取得成功結果。
