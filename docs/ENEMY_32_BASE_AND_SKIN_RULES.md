# 《薪水勇者》敵人製作與量產規則（已確定）

## 核心決策：先把 32 隻做成基礎母型，之後大量量產普通怪換皮

本規則是使用者在 2026-11-10 明確決定的長期開發方向。**不是改成 32 隻長得一樣。**
《薪水勇者》首先保留現有 `v19/roster.mjs` 32 個固定原型 ID、名稱與階級，
待每隻基礎怪美術逐一完成後，再對「普通怪」開啟低成本變體量產。

| 原型類別 | 既定數量 | 首批母型製作 | 後續新增同類敵人 |
|---|---:|---|---|
| 普通敵人 | 16 | 每隻都要有完整、個性化的 Q 版外觀與真正攻擊／受擊／死亡動畫 | **可以共享對應普通怪母型的動畫與骨架，透過新皮膚、配色、臉部、裝備、裝飾與粒子效果製作多種變體** |
| 菁英敵人 | 8 | 每隻專屬造型與動作、職位辨識度、特殊招式 | **不採普通換皮量產**；新菁英應有新造型與獨特技能表現 |
| Boss | 8 | 每隻完整原創形象、特別登場及招式、死亡演出 | **不採普通換皮量產**；新 Boss 必須是獨立有記憶點的首領 |

## 普通怪變體量產：一組動畫、多款正式皮膚

- 每款變體保留 `baseTypeId`（原本的普通怪 ID），繼承已驗收的 `idle/attack/hurt/defeat` 動作及命中時序。
- 變體有自己的 `variantId`、名稱、戰鬥數值、特性、地區、掉落與圖鑑資料。新增內容不得覆寫基礎 32 種的 ID。
- 能直接共用同一組動畫的是「骨架／比例與攻擊方式相容」的普通怪：例如同一種紙妖可有火焰公文紙妖、冰凍請假條紙妖、毒霧考績紙妖。
- 視覺修改建議：配色遮罩、眼睛與表情、服裝與徽章、武器前景部件、光效、擊中特效。至少要能從縮圖一眼辨認差異；**禁止只做純色方塊、剪影佔位、全身縮放或抖動假動畫**。
- 若變體武器或體型大改，已不符合原母型動作，就改用其他相容母型或補專屬畫格，不可強行套用。
- 相同母型的皮膚應共用資源快取與圖集。換皮不應複製整套大尺寸 PNG/WebP 或讓手機重複下載。
- 變體應有獨立 ID 的圖鑑/收藏項，若改動遭遇產生邏輯，必須保留舊存檔讀取與 16/8/8 四關節奏。
- **菁英與 Boss 是獨立美術製作，不是把普通怪放大、上色、加光圈。**

## 製作品質最低門檻

1. 延續已確定的高品質 Q 版日式 RPG，角色輪廓與細節要有手繪感，不能回到介面幾何拼接。
2. 基礎敵人必須具有獨立角色外觀，攻擊時有真正的身體／四肢／武器姿勢變化，不用整張圖片平移、模糊或抖動頂替。
3. 受擊先有明確紅閃，並搭配該物種的獨立受擊姿勢。死亡有完整畫格，避免直接消失。
4. 「已定義」不等於「已畫完」；「候選」不等於「正式通過」。所有正式美術需在手機遊戲中實際驗收後才能計入完成數。
5. 變體量產需等該母型已驗收正式素材，再逐步開放，不能拿佔位幾何物體換色冒充怪物。
