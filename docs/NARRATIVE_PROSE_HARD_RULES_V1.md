# 《薪水勇者》正式劇情文字寫作硬規則 V1

**效力**：所有六個生前世界、60 名角色背景故事、主線、未來覺醒、專武故事及角色專屬副本的敘事正文。**狀態**：正式寫作規範；不代表既有故事已符合，需逐章改寫驗收。

## 參考方向
參考優秀網路小說的場景化敘事、節奏、懸念、人物聲音與連載鉤子。學習寫作技法，不複製任何現存作品的句子、情節或人物。後續研究公開網路小說與寫作評論時，須記錄可借鑑的技法，不得聲稱未查證的作品內容。

## 正文硬規則
1. **小說正文不是設定書**：每章由可觀察的場景、行動、具體物件與有後果的選擇構成；禁止用「他從小……後來……最後……」概述取代情節。企劃書與小說正文分檔。
2. **先演出再解釋**：透過動作、對話、環境和衝突讓讀者理解角色；避免旁白替讀者下結論或說教。
3. **自然人物聲音**：每人有自己的詞彙、語速、習慣、避談話題；允許答非所問、打斷、誤解、口是心非與無法和解。不能讓十人用同一種哲理口吻說話。
4. **避免 AI 套式**：禁止反覆出現「不是……而是……」「那一刻他終於明白」「真正的……是……」「沒有人知道……」「他不知道的是……」等機械對稱、總結式金句；尤其不得每章末尾都加人生寓意。
5. **節奏有呼吸**：包含生活細節、笑點、尷尬、瑣碎小事與沉默；不能每場都重大揭密、吵架或死亡。
6. **衝突必須由人物欲望生成**：每場至少有一位人物想得到具體事物，另一人阻礙或代價使其改變策略；不得靠作者安排人物突然犯蠢。
7. **情緒靠累積**：悲劇前先讓讀者相信人物的日常與未來；死亡不可成為廉價催淚工具，避免十次重複英雄殉職。
8. **資訊控制**：伏筆要可回溯、有公平線索；不在序章提前揭露整個謎底，不靠全知旁白製造假懸念。
9. **文字有個性**：視角、句長、感官重點隨角色和場景改變；不用整齊劃一的段落長度與重複排比。
10. **結尾有敘事推力**：以人物新決定、關係變化、未解的具體問題或反常細節收尾；不以道德總結收尾。
11. **稀有度反映劇情規模**：SSR、UR 必須有更複雜的轉折與選擇，但不能用誇張形容詞、悲慘堆疊或神化人物取代戲劇。
12. **故事優先於美術**：待人物與場景定稿，才反推卡牌、立繪、分層動畫、專武與副本場景；視覺設計應有可指認的正文依據。

## 逐章驗收
- 能否刪掉人物標籤與解說，仍透過言行認出說話者？
- 是否有至少一個真正演出的完整場景，包含地點、時間、行動、阻力與後果？
- 是否存在可刪除的抽象總結、重複金句、過度對稱段落？
- 人物是否有不完全正確、卻合乎其性格的選擇？
- 讀者是否因為發生了什麼而想看下一章，而非因旁白說「命運即將改變」？
- 是否與既定生前關係、稀有度、死亡事件及時間線一致？

## 實施
《沒有寄出的事故報告》V1 人物傳記和 V2 故事藍圖均屬**素材與規劃**，不是合格小說正文。下一步先將白律、鐵時、梨奈與其餘角色交錯寫成逐場小說章節，逐章套用上述規則；任何章節未通過驗收，不標記「正式定稿」。
