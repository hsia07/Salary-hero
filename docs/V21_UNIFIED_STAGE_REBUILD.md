# 《薪水勇者》V21 主畫面架構重製（第一版）

日期：2026-11-11
目標：移除上下兩個縮小的遊戲舞台，保留單畫面、所有真實遊戲系統與既有素材。**這是可玩的布局重製，正式美術仍需玩家確認。**

## 核心改動

- `v19/play.html`：原本的主城薪資牌（使用同一個 `#today` / `#pay-month`）移至固定的 `#v21-salary-bar`，不複製任何數值元素。
- 新增「辦公室／冒險戰鬥」切換鈕；`#town-stage`、`#battle-deck` 在 CSS Grid 同一列呈現，預設戰鬥；辦公室模式仍顯示貓、咖啡、主角、時計與奇遇等原本可點擊角色物件。
- **切換只是視圖**：在辦公室顯示時，戰鬥仍由原本的 `app.mjs` 計時、自動決策、戰鬥結果、掉寶、薪資計算與存檔控制；不暫停 Canvas 引擎，也不重建／重設遊戲狀態。
- 畫面頂端保留資源，下面固定薪資，場景切換，再下面一條關卡進度（辦公室改為顯示冒險狀態）。場景佔剩餘主要區域。
- 戰場的 `#auto`、`#speed`、`#attack`、`#heal` 變成較小的上方快捷列，全部原始按鈕與事件／可及性保留。右側戰利品改成單顆可展開按鈕，內含原本 `#claim`、`#chest`、`#weekend-chest` 和裝備預覽。
- 主要導覽為：首頁、冒險、角色、裝備、更多。後四個鍛造、寵物、公會、商店使用「更多」可展開列，全部仍是原本 `data-panel` 開頁邏輯。
- `v19/v21-unified-stage.mjs` 僅管理視圖及菜單狀態，從既有 `getState()` 顯示背景自動冒險／關卡／待領取提示，不寫入 `localStorage`，不生成額外獎勵。
- `v19/v21-unified-stage.css` 嚴格控制手機直式一畫面；短螢幕 320×568、375×667、390×844；主角、敵人、場景圖、戰鬥動畫未修改。

## 不改動

- 已核准的瘦、疲倦、略邋遢 Q 版日本社畜主角；全部怪物與背景原畫；正式的薪資計算／40,000 月薪設定；存檔鍵與資料格式；自動冒險、掉寶、鍛造、裝備、寵物與公會的規則。

## 驗收

`node --test v19/v21-unified-stage.test.mjs`，以及 GitHub Action 手機 QA 驗證切換、真實薪資、5 個主導航＋4 個更多入口、無捲動、戰鬥仍可用。其他怪物的訓練模式維持獨立路由、不應受正式首頁布局影響。

## 下一步

以使用者實機截圖繼續改善新單一大舞台構圖（人物比例、視野留白、操作快捷列位置、場景切換轉場），避免在視覺驗收前堆疊裝飾。
