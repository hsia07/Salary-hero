# 《薪水勇者》戰鬥 AI／角色素質／治療護盾規格 V1（V5.9）

> **2026-11-12：決議**　手機 9:16 單畫面七人編隊（前排 4＋後排 3）。角色不再全員優先精英或最低血量；醫官與保護者有真正的支援技能。本文分「已在 V5.9 實作的測試規則」與「後續正式養成需完成的內容」。不得把角色面板基準數字冒充已完成正式屬性引擎。

## 2. 站位與視覺比例

- 當前七名角色：**打卡守衛、逃班鬥士、截止日刺客、咖啡醫官、試算表法師、機械工程師、薪奴**。
- **前排 4**：打卡守衛／逃班鬥士／截止日刺客／薪奴；**後排 3**：咖啡醫官／試算表法師／機械工程師。職業定位可與站位不完全一致，編隊解鎖後可調整。
- V5.9 擴充隊伍區域、增加立繪在原槽位內的占比，仍保持 9:16 不可捲動、七人名字／血條／狀態能辨識。若再加大，必須做**鏡頭演出式放大**，不硬把四名前排的寬度超過可放下的上限。
- 命中及支援技能要有可見角色行動，並有接觸時機與結算數值一致性；每種 Buff／Debuff 最終都必須有獨立透明美術、掛點、施加、循環與解除動畫。

### 不再所有隊員打一隻怪

- 每名隊員在**自己的行動時**依照角色職能、目標距離、剩餘 HP 比率、敵人類型、同隊已送出的攻擊彈道計算優先分數。
- 團隊已經有攻擊飛向某一敵人時，其他隊員通常傾向別隻（除非刺客確實要完成斬殺）。
- 純 Boss 波只有一名 Boss 時，大家攻擊 Boss 當然合理；有召喚物時恢復職業分流。
- 強制集火是**未來特定角色技能／指揮天賦**，不能是所有角色的固定預設。
- **下一階段**追加仇恨／挑釁／敵方危險射線、法師真正 AoE 與坦克護衛攔截；V5.9 目前完成的主要是角色選敵、支援目標與傷害結算。

## 4. 已實作 V5.9 的三個支援機制（測試數值）

| 技能 | 擁有者／觸發 | 目標與數值 | CD／持續 | 反制方式 |
|---|---|---|---|---|
| **咖啡急救** | 咖啡醫官；隊友有效 HP 低於門檻 | 治療選中隊員的最大 HP **9.5%**；若有「薪水延遲入帳」，實際治療降低 | CD **7.6 秒**戰鬥時間 | D33 薪水延遲入帳／D16 沉默（沉默整合待正式版） |
| **全隊緊急護盾** | 機械工程師；至少兩人 HP 低於 80%，或 Boss 怒氣高於 65 | 每個存活隊員各獲得**自己最大 HP 的 6.5%**護盾 | CD **13.8 秒**，盾持續 8 秒 | D08 破盾／暴擊穿透等需正式整合 |
| **勝利加班補償** | 薪奴被動；清完任一非最終波 | 給**目前生命比例最低的存活隊員**，相當於**該目標最大 HP 10%**的護盾 | 每清完一波一次，盾最多保留 12 秒戰鬥時間 | 破盾／高傷技能、跨波逐步消耗 |

**護盾公式**：
`盾值 = 目標最大生命值 × 技能倍率`。
`承受傷害時：先扣可用盾值，再扣目標 HP`。
`單體現存護盾總量 ≤ 該目標最大生命值 25%`，同名護盾不無限累積。

- 治療目標優先使用剩餘生命值百分比，且不幫死亡角色回血；勝利加盾則刻意只看**真正 HP 百分比**，不受已存在護盾影響。
- 受控制的補師不能施法。技能計時用戰鬥時間，暫停停錶；×2／×3 倍速也會影響冷卻時間流速。
- **沒有任何角色施法就不能平白給全隊回血**。過關恢復 12% 是副本**波次規則**，與補師的戰鬥技能不同，且不復活死亡角色。

## 5. 分層美術要求

目前加入五個**獨立透明插圖圖層**（初版 VFX，不等於 72 種最終正式美術已完成）：

1. `art/s1/support-vfx/heal-cup.svg`：咖啡醫官施法的咖啡杯與蒸汽。
2. `art/s1/support-vfx/heal-petals.svg`：治療的獨立花瓣／綠光流動。
3. `art/s1/support-vfx/shield-glass.svg`：每位隊員身上透明的護盾結界。
4. `art/s1/support-vfx/shield-runes.svg`：獨立符文環繞層。
5. `art/s1/support-vfx/shield-impact.svg`：護盾擋下攻擊或產生「勝利補償」時的碰撞閃光。

所有圖層必須跟隨**真正受影響的角色**移動，死亡或到期後消失，並在有限尺寸內呈現，避免遮蓋七人隊形與敵方血條。最終正式版還需要由同一美術產線重畫更高精度的受傷／施法逐格角色動作，不能只靠 CSS 變形來宣稱正式動畫完工。

## 6. 後續工程優先順序

1. **P0**：V5.9 行為 AI＋目標預約＋真正奶媽＋全隊盾＋勝利救援盾；手機 320／390 px 站位及 Boss 全程驗收。
2. **P1**：正式 RPG 屬性結算（每人的 HP／ATK／DEF／ASPD／CRIT／HIT／RES）、技能藍條、職業速度、冷卻、裝備進一步與 72 狀態引擎整合。
3. **P2**：坦克「護衛攔截」、刺客「突後排」、法師多敵「範圍魔法」、醫官「低血自動淨化」；讓攻擊方式本身真正不同。
4. **P3**：戰前編隊與獨立策略預設：智慧／集火／保命／速攻；戰中只可查看角色資訊，不可改隊伍。每職業至少 1 個可辨識正式動畫，最後批量模擬 1000+ 場調整回合時間與存活率。

**絕不把三層混成一種：** 副本全域倍率 → 單一敵人 AI／技能 → 我方每名角色 AI／技能。以上所有數值是 V1 可調參起點，不是抄別作比例。
