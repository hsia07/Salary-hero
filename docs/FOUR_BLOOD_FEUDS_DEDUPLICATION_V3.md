# 四組宿敵去同質化改寫規格 V3
**狀態：正式修稿方向，待逐場劇本改寫。** 過去四組都以「一位具名NPC死於制度事故」作主軸，造成重複。不能靠更換死者姓名解決。既有V1劇本保留作對照，不冒稱已改完。

## A 薇菈 × 璃音｜保留阿書之死：無法定價的背叛
**核心傷害**：私密姓名被販賣、璃音視如家人的阿書死亡。**獨特性**：不是審判誰有罪，而是有人用他人的生存權做交換，導致個人關係徹底毀滅。薇菈不靠捐錢洗白；璃音也須承擔拒交備份的責任。
**不可互換演出**：玩家持有阿書自選姓名的借書卡，選擇是否公開以救更多人，公開會再次侵犯阿書隱私。
**長期後果**：兩人同隊時仍能互相救命，卻無法互相信任；阿書不復活。

## B 蘇妲 × 清目｜改為「文字抹除一整個族群的存在」：文化與身分滅絕
**取代單一NPC死亡作核心**：三萬份判詞不只是拘留令；它使一個有歷史、語言與居所的召喚族群被法律定義成「未曾存在」。收容站霜婆可以仍是重要當事人，但**不再以她死亡當主要情感支點**。需修訂既有《三萬份判詞》V1場景以免互相矛盾。
**個人血仇**：蘇妲曾為求保住狐族的一部分而同意刪除其他人的歷史；清目明知證據不足仍核章。雙方爭的是誰有權決定哪些人可以被歷史記住。
**不可互換演出**：玩家在城內看見被法律抹去的街道、碑文與居民戶籍，地圖與NPC對話隨公文生效而改變；復原法律也無法找回被迫改名的下一代記憶。
**長期後果**：一部分居民不願恢復舊姓名，蘇妲與清目都不能替他們決定。

## C 白律 × 赫斯｜保留南笙之死，但核心改為「司法背叛」
**核心傷害**：兩位原本一起救人的法律工作者，在最需要對方時分別簽署互相矛盾的命令；南笙的死亡是結果，**真正的宿敵起點是對方明知風險卻把自己當作可犧牲的程序**。
**不可互換演出**：雙視角法庭，玩家要親手提交自己角色不利的證據；勝訴可能使一群人失去短期保護。
**長期後果**：兩人仍會合作推翻非法拘押，但不再讓對方單獨代理案件。

## D 薔薇 × 灰牙｜改為「追捕造成不可逆的身分背叛」：家園與信任被毀
**取代單一NPC死亡作核心**：夜車追捕使薔薇秘密保護的夜班聚落位置曝光，居民被強制遷離，族群被迫分散；阿澪可以在混亂中失蹤或留下永久傷殘，**不要再用死亡作唯一證明仇恨的工具**。需要正式改寫V2《失名之夜》提案中阿澪死亡的描述，未核准前不得同時把兩種版本當正史。
**灰牙的動機缺口**：他生前為拒絕獵殺而死，召喚後卻接受追捕。必須寫出他為何認為這次是「保護」而非「獵殺」——例如他相信追捕隊在阻止商盟販運，且收到被刻意截斷的情報；但在得知真相後仍選擇繼續執行一段時間，確保有不可推卸的責任。
**不可互換演出**：玩家同時操作夜車疏散、氣味誤導與藏身聚落搬遷；追捕隊會記住玩家使用過的路線。
**長期後果**：薔薇不只恨灰牙，她要建立不依賴登記局的夜班自治區；灰牙失去追捕者資格且不能以退職換得赦免。

## 世界觀防重複驗收
1. 四組宿敵的主要損失類型分別是**親密背叛／文化抹除／司法背叛／家園瓦解**。
2. 不能把所有NPC寫成「為了讓主角悲傷而死」；每個重要NPC須有自主目標、至少一個獨立決定、可見的世界後果。
3. 任何既有死亡事件的更動都只限**召喚後的非招募NPC提案**，絕不可改動60名英雄原世界工作死亡事實。
4. 這份規格**不是已同步修改舊劇本**；下輪必須實際改寫《三萬份判詞》《最後一班夜車》，並更新世界主線與角色JSON。
