# 《薪水勇者》世界觀與正式版製作藍圖 V1.0

狀態：工作規劃草案（2026-11-13）。已核准事項與待確認事項必須分開；本文件不表示功能或美術已完成。

## 已確立的核心方向
- 核心世界觀：現實世界因工作過勞而死的社畜，死後被召喚到異世界成為勇者，卻發現拯救世界同樣要打卡、考績、加班。
- 敘事調性：前期社畜黑色幽默，中期角色悲劇與秘密，後期挑戰勇者制度。
- 玩家主角稱「薪奴」，外觀沿用目前遊戲已核准的 Q 版厭世、微邋遢日本上班族造型，禁止擅自重畫。
- 可招募角色稱「同事」，六人編制介面稱「同事編制」，招募稱「徵才」，收藏稱「員工名冊」；依 docs/CHARACTER_NAMING_CANON.md。
- 手機直式、主頁不捲動、上班掛機下班可玩。薪資 NT$40,000/月，週一至週五 08:00–17:00 計算，午休照計。現實薪資與遊戲貨幣分開。
- 正式角色美術須有真實分層素材與完整攻擊、受擊、施法等逐格/骨架動作；不可用幾何 UI 或純平移代替。

## 世界架構（規劃）
1. 勇者管理局：召喚、派遣、績效、復活與任務制度的權力中心。
2. 勇者公會：玩家日常據點；徵才、養成、編制、裝備、傳記、活動。
3. 魔王領域：魔族、機兵、異常生物及可能存在的前代勇者。
4. 主要懸念：為何死亡社畜被召喚？復活代價為何？魔王與勇者制度是否相互依存？

注意：「魔王軍由反抗制度的前代勇者組成」「管理局是幕後黑手」是候選伏筆，尚未定案，不可提前作為既定真相。

## 主線五篇（暫定）
1. 死後第一天上班：薪奴死亡、召喚、入職、初戰。
2. 這些同事不太正常：徵才、角色間關係、過勞生前記憶。
3. 無限加班的王國：異常任務、魔王軍與勇者相似的技能。
4. 前任勇者的離職申請：調查前代勇者與復活制度。
5. 向世界提出辭呈：對勇者制度做出抉擇，導向後續篇章。

## 角色系統
首批戰鬥原型：薪奴、打卡守衛、逃班鬥士、截止日刺客、咖啡醫官、試算表法師、機械工程師。
只有薪奴外觀已核准。其他角色姓名、外觀、性別、故事、數值、技能皆為設計草案，不可標記為已完成。
每名角色的設計卡必須包含：
- 生前職業、過勞事件、遺憾、異世界召喚與加入原因、性格、日常互動、角色關係、秘密；
- 稀有度、職業、定位、陣營／羈絆、基礎屬性與成長曲線；
- 普攻、被動、主動、必殺、AI 目標選擇與施法條件；
- 三條候選轉職／流派、專武、覺醒、裝備外觀變化；
- 立繪、Q 版戰鬥圖、分層清單、動作幀、VFX、傳記副本與獎勵。

## 戰鬥設計
- 借鑑直式自動戰鬥遊戲的站位、技能連鎖、角色差異與養成節奏，不複製既有角色或技能。
- 各職業採不同 AI：坦克攔截與嘲諷、戰士追擊、刺客優先後排高威脅目標、醫官按有效生命比例治療、法師選群體目標、工程師按風險施放護盾或召喚。
- 「背刺」暫定為戰術突襲標籤，不依賴尚未實作的敵人朝向判定；演出必須實際接觸目標。
- 明確定義 HP、ATK、DEF、攻速、暴擊、技能倍率、護盾、治療、控制抗性；不得長期停留在所有角色 100 HP 的原型。
- 目前七人同場是原型；「六名同事＋獨立薪奴」是候選正式編制，尚待確認。

## 角色傳記副本
- N/R：短篇故事與特殊委託；SR：建議 3 章；SSR：5 章；UR：7 章，章數可依內容調整。
- 一邊戰鬥一邊敘事：戰鬥環境、敵人機制、角色回憶、台詞、Boss 階段與最後一擊共同推動劇情。
- 首通保證專武設計圖／核心進度，重刷取得專屬素材；重要養成避免完全依賴低機率掉落。
- 首通完整劇情；重刷可自動、快速挑戰、略過已看演出。
- 專武必須改變玩法與武器外觀，而非只有數值加成。

## 長期玩法
主線遠征、菁英／Boss、無限之塔、每日異常副本、每週主題、角色傳記、專武養成、羈絆與融合、轉職、圖鑑、季節活動。
避免所有活動只換怪物顏色與提高數值；至少在 Boss 機制、地形、隊伍限制或技能互動中提供變化。

## 實作優先序與驗收
P0：核對現有 runtime 與素材；建立可執行角色數值表與 AI 規格，補回歸測試。
P1：完成一名同事（建議打卡守衛）的角色故事、完整數值、立繪驗收、分層戰鬥圖與真實攻擊／受擊／技能動畫，接入戰鬥。
P2：完成六名同事的角色設計卡與戰鬥定位，驗證站位、選敵、補血、護盾與技能連鎖。
P3：角色傳記副本垂直切片（首章戰鬥中敘事、專屬 Boss、首通獎勵、可重刷素材）。
P4：擴展到完整傳記、專武、覺醒、轉職、羈絆融合及長期活動。

完成定義：可在真實手機直式畫面操作、素材已進 repo、動畫有實質動作、玩法可測試、回歸測試通過、版本已推送；僅文件或概念圖不算功能完成。
