# 60 名角色｜故事驅動正式美術重製標準 V1

**狀態：製作規格；尚未生成、替換或整合正式美術。**

## 核心規則
先完成並驗收每位角色生前的獨特人生故事，再鎖定美術設計。禁止依職業、種族、稀有度套模板換色。六個世界各有自己的材質、文化、建築、服裝語言，但同世界的十名角色仍需個別辨識度；不得讓所有人穿同款制服。

## 每名角色必備美術交付物
1. **角色美術聖經**：生前世界與社會階層、性格、重要人際關係、人生轉折、核心傷痕、具象徵性的物件、禁忌元素、配色與材質來源。
2. **造型探索**：至少三套有敘事理由的方向（不只是換色），包含正／側／背面、臉部特徵、輪廓剪影、表情與配件。
3. **正式全身立繪**：清晰、高品質、手機端可辨識的 Q 版比例與正式立繪版；人物設計一致。
4. **角色卡牌**：卡面構圖需對應其人生最具代表性的具體場景，包含人物、場景、敘事符號與稀有度視覺層級；不得用單一特效背景冒充卡面故事。
5. **戰鬥用分層素材**：身體／頭髮／衣襬／手臂／武器／表情／特效等依角色實際動作需求分層，透明背景；待機、行走、近戰接觸／遠程施法、受擊紅閃、技能、必殺、勝利、倒地各有真實動作關鍵幀，不以整張圖搖晃、縮放、模糊或幾何拼接替代。
6. **技能與專武設計**：能力、武器、攻擊軌跡、特效和聲音來自故事設定，非純粹強弱等級。
7. **手機畫面適配**：手機直式、單屏無捲動，卡牌／立繪／戰鬥小人三種比例一致；不得只交靜態示意圖而宣稱完成可互動遊戲。

## SSR／UR 額外硬規格
- SSR：生前原始造型、核心人生事件卡牌、覺醒造型、專屬武器及專屬副本關鍵場景概念，須共享一套故事符號與視覺語言。
- UR：在 SSR 基礎上，額外製作傳奇時期與關鍵真相翻轉的視覺版本、可辨識的專屬武器演化，以及獨有副本首領／場景／動畫語言。**不得僅加金邊、翅膀、發光特效就稱為 UR**。
- 覺醒美術應回應生前未竟命題；不提前寫死死後人物交集。

## 施工順序與驗收
故事長篇定稿 → 角色美術聖經 → 三方向概念審圖 → 正式全身立繪與卡面 → 分層戰鬥素材 → 動畫與技能 → 遊戲內整合與手機實測。
每階段檢查：角色是否一眼可辨、服裝／武器是否有故事來源、卡面是否呈現具體事件、分層素材是否可做實質動作、同世界十人及六世界是否避免換皮。
原有美術在新稿驗收前不自動刪除；不得把文件更新說成美術已經完成。
