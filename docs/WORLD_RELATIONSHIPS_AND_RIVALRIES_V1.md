# 《薪水勇者》跨角色恩怨與勢力世界觀 v1
狀態：**世界觀關係網第一版提案，尚未變成遊戲劇本／動畫／程式。** 已核對60人角色表中的出身世界與候選關係；**不追認任何角色生前認識其他平行世界的人**。下列「召喚後」事件是新增的共同世界劇情，不能反向改寫各人的死亡原因。角色有敵對關係不代表不能同隊；戰鬥同隊的劇情解釋為有條件的短期合作。
## 不可更動的世界觀
- 角色原本來自近現代職場、機械、星際、神話、冥府、異常生命等不同平行世界，在原世界因工作死亡，死後才被召喚到共同異世界。
- 同陣營≠同國籍、同時代、同一間公司、同一個人事組織；即使同類世界，生前認識也必須有證據，否則標示未確認。
- 主角與角色可相識、結盟、交惡，但不把角色改成「生前就在召喚世界活動」。
- 鐵時既定火災、三魂一盾、08:59→09:00不變；經典神話武器與既定死亡事件不變。
- 六大陣營是**角色來源分類**，不等於六個必須互相開戰的政治國家。
## 共同世界：三個核心勢力（新提案）
### 1. 下班公會（可玩主據點）
由被召喚者建立的互助網，提供住處、委託與組隊；不全是好人，資源不足時也會偏袒熱門英雄。玩家可在公會內接觸不同派系。
### 2. 召喚登記局（程序派）
掌握召喚記錄、身份核驗與戰場通行權，主張先確保秩序才能保護被召喚者；並非全部官員都是壞人。其合法性、資料準確性與強制登記是主要爭議。
### 3. 契約商盟（交易派）
以裝備、醫療、通行、委託為交換籌碼，支持自願契約但存在利用弱者的灰色業務；不是所有商人都是敵人，商盟內部有改革派與投機派。
以上是召喚世界的新機構，**不是各角色生前的公司或天庭／冥府組織**。

## 關係必須隨時間變化
每組至少設四個狀態：初識→事件衝突→不可逆後果→新平衡。**新平衡不必和解**，可能保持敵對、互相尊重、有限合作、背叛或刻意迴避。
同一個人允許有多條關係線：例如赫斯與白律是法律宿敵，與悟空是程序衝突；不把每人簡化成只有一個死對頭。
## 可玩的世界級主線：〈誰有權替亡者簽字〉
**第一幕／登記**：登記局要求所有被召喚者簽署隊伍與醫療授權；部分角色拒絕，玩家調查規則如何形成。
**第二幕／交易**：契約商盟提出提供稀有專武材料，代價是取得部分召喚資料；薇菈、伊芙、白律各有不同立場。
**第三幕／例外**：公會災害發生，門禁、供能、資訊公開三條規則互相衝突；鐵時、七號、賽芙、露希亞面臨不同選擇。
**第四幕／聽證**：赫斯主持公開審理，悟空質疑程序；沒有一條選項能讓所有角色都滿意。
**第五幕／分歧**：登記局分裂為強制派與自願派，商盟分裂為投機派與改革派；玩家保留已取得角色，不因劇情立場被強制刪角。
**第六幕／停戰而非大團圓**：共同危機使敵對者暫時合作，但部分恩怨持續進入角色個人覺醒章。
## 戰鬥與長期內容
- 6人陣容可跨敵對關係組隊；戰前觸發特定對話或短演出，不禁止玩家組隊。
- 「宿敵」可解鎖雙人試煉、支線分歧、專武回憶戰與特殊勝利台詞，**不直接做成必帶的強力數值羈絆**，避免強迫配隊。
- 關係解鎖需有可玩事件與動畫，而非只有圖鑑表格。敵對者不必打完副本就變好友。
- 所有角色的生前共同歷史都需另行查證；本稿所列10組均為召喚後關係，沒有偷加跨世界生前認識。
