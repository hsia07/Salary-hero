# 鐵時 V6.6｜傷害攔截優先序與結束狀態

修正 V6.5 潛在問題：同一目標受到傷害時，「最後一道門」全隊攔截與「打卡護衛」單體攔截不能串接兩次，否則守衛承傷比例會超出預期。

## 優先序
1. 09:00 覺醒必殺保護期內：所有存活隊友（鐵時以外）受傷時，原始傷害 30% 轉給鐵時，剩下 70% 留給原目標。
2. 覺醒必殺保護期間，普通「打卡護衛」攔截暫停；必殺結束後才可恢復原單體攔截（若其原持續時間尚未到期）。
3. 轉移傷害透過鐵時自己的防禦與護盾結算，不觸發遞迴。
4. 鐵時死亡、換波、勝利、失敗、技能到期時立即停止保護；時鐘顯示回 08:59。
5. 中期故事覺醒仍由開發模式模擬；尚未接正式傳記進度與持久化存檔。

## 待驗收
- 實際戰鬥中記錄 100 原始傷害→30 轉移、70 原目標，並檢查護盾與防禦結算。
- 測試同時存在打卡護衛與最後一道門時，僅執行一次攔截。
- 測試跨波、死亡、勝利、失敗、暫停、倍速。
- 正式角色美術、盾牌分層、必殺逐幀動畫仍未完成。
