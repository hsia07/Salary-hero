# 《薪水勇者》V19.1 — 三階怪物系統與圖鑑美術規範

狀態：**戰鬥規則與圖鑑已實作；32 種正式獨立怪物精靈尚未完成。** 2026-11-09

## 四波循環
- 第 1 波普通；第 2 波普通；第 3 波菁英；第 4 波 Boss。往後無限重複。
- 所有敵人擁有 `tier`、`typeId`、生命、攻擊、特性與獨立名稱。舊 V19 存檔保留原波數、進度與生命，不重置。
- 普通：基礎 HP、金幣與經驗；能有防禦、狂暴或吸血特性。
- 菁英：有更高 HP/攻擊、專屬菁英名單與戰場光環。每第 3 次反擊強化；戰勝額外 +1 寶石，必定掉一件裝備。
- Boss：更高 HP/攻擊與較大的舞台表現，每第 4 次反擊強化；戰勝取得寶箱、寶石、造型券並回滿生命。Boss 的 HP 隨層數成長始終高於前一關菁英。
- 戰場標頭、敵人生命條、特技蓄力與怪物圖鑑按等級區分。

## 硬性美術品質規範（仍待施工）
1. 三階不能只有放大、換色、加光圈；**每一種怪物必須擁有專屬的清晰 Q 版辨識輪廓、頭部、四肢或特色結構**。
2. 以高品質、非模糊的透明角色圖為正式輸出。每種至少具備 idle / attack / hurt / defeat 的真實姿勢差異；菁英與 Boss 再做特殊技能與登場。
3. 物件透視、視角和比例須與瘦瘦邋遢日本大叔主角及戰場背景一致；腳要落在同一地平面；不允許隔空攻擊或背向目標。
4. 正式怪物不以 Emoji、幾何形體、通用剪影或相同一張素材換色充數。目前部分仍是畫布程式候選外觀、舊 SVG 或 Emoji 徽記，**不得宣稱已完成正式 32 種美術**。
5. 圖鑑的「未擊敗剪影」應使用該種怪物的真正外型遮罩，不是固定黑方塊。每種怪物有真實獨立辨識度及圖鑑解鎖動畫。
6. 圖檔需真實提交 GitHub、在手機瀏覽器實際播放驗收；不得只提交虛假的 loader 路徑或未部署素材。
