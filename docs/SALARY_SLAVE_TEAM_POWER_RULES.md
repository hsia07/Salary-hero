# 《薪水勇者》薪奴升級與全隊戰力

狀態：2026-11-12 使用者確認「薪奴升級可以提升整體戰力」；具體數值為待核准提案。

## 已確認
- 薪奴每次升級應提升整體隊伍戰力，不只是自身戰力。
- 薪奴升級來源包含戰鬥 EXP 及副本通關 EXP，詳見 `docs/SALARY_SLAVE_XP_RULES.md`。
- 同事的實際等級不得超過薪奴等級，詳見 `docs/COLLEAGUE_PROGRESSION_RULES.md`。

## 待核准的建議機制
1. 薪奴自身生命、攻擊、防禦隨等級成長。
2. 薪奴等級提供全隊少量、穩定的基礎屬性增益；不應壓過六位同事的養成、轉職、羈絆與裝備。
3. 薪奴升級提高同事有效等級上限，但同事仍須花素材升級，不能免費同步提升等級。
4. 顯示整隊戰力提升的動畫與具體來源，避免把預估戰力誤認為實際戰鬥保證。

## 待測試
- 薪奴單次升級對全隊戰力的實際影響幅度。
- 薪奴等級增益與同事技能倍率、裝備、羈絆的疊加方式。
- 高等級下數值膨脹、低等級新手體驗及重複收益問題。
