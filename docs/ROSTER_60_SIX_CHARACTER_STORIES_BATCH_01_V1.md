# 六名角色正式長篇劇情第一批｜生前關係與死後重逢 V1

**狀態：第一批六篇可演出劇情初稿；尚未最終定稿／遊戲實裝。** 這次正式採用三組生前關係：薩洛與妮亞曾是戀人；薇菈與璃音曾是摯友；蘇妲與清目曾有秘密戀情。三組均屬相同類型原世界，但**此文件首次指定同一子宇宙與可交集的年代**，不是因為同陣營就自動認識。各自原世界工作死亡事件保留。

## 共同時間基準
- **P期**：原世界共同人生，事件可跨數年。不同子宇宙彼此獨立。
- **D期**：每位英雄在原世界工作死亡；順序不必相同。不能在原世界死亡後仍有普通現世活動。
- **R期**：各自召喚到共同世界。重逢可以有時間差。
- **N期**：失名之夜及其後果；所有薇菈璃音新世界罪責仍在此時發生。
- **C期**：三萬份判詞文化抹除；蘇妲清目新世界再次共犯，與原世界戀情無關。

# 01 星艦領班・薩洛《最後一塊生日蛋糕》
**故事類型：婚姻未成的愛情／領導權與羞恥。** 與妮亞共享「鏡灣星港子宇宙」，生前曾交往七年，但沒有結婚。薩洛是貨艙領班，妮亞是另一艘難民艦的領航員；不是同一艘船同時殉職。

### 第一幕：一塊不合規格的蛋糕（P-7年）
鏡灣星港貨運船員的生日被視為無薪休息。薩洛偷偷用貨艙冷卻槽保存一塊奶油蛋糕，為妮亞補過生日。妮亞不高興的不是蛋糕融化，而是他為此冒著被扣證的風險。
妮亞：「我不是要你證明你能違反規則。」
薩洛：「我只是想讓今天有點不一樣。」
妮亞：「那你陪我把它吃完，不要再去巡艙。」
他第一次真正坐下來吃蛋糕。

### 第二幕：被丟下的行李（P-3年）
貨船收到優先運送高價設備的命令，薩洛為維持船員薪資，把難民的私人物品列為可丟棄貨物。妮亞看到一名小女孩的空行李箱，才知道薩洛在報表裡把它算成「無主物資」。妮亞沒有立刻分手；她陪他去找那名女孩，卻發現箱子已被焚毀。
妮亞：「你不是不知道裡面裝著誰的家。」
薩洛：「如果不丟，船員就會失業。」
妮亞：「你總能找到一個人，讓他替你的選擇付錢。」
這是兩人關係第一次真正破裂。薩洛不被寫成純粹好人，妮亞也不是永遠正確的道德裁判。

### 第三幕：沒有寄出的結婚申請（P-1年）
薩洛準備申請伴侶艙位，卻遲遲不敢交給妮亞。他想先恢復被扣押的航行證，妮亞則已經接受難民艦的工作。兩人分開，不是因為不愛，而是薩洛要求所有人等他證明自己「值得」。
薩洛把未寄出的申請鎖進貨艙抽屜。

### 第四幕：裂縫（D）
薩洛在危險航道工作時，貨艙破裂。他不再把船員當作可以交換的重量，親自封堵裂縫，保住船員而殉職。**固定工作死因不變**。他並不知道妮亞稍後也會在另一艘難民艦工作中死亡。

### 第五幕：另一張航行證（R）
召喚後薩洛被任命為公會補給隊長。妮亞比他晚抵達共同世界。他以為重逢能讓過去重新開始，妮亞卻先問：「你還會把別人的行李當作貨物嗎？」
玩家操作貨艙配重，必須丟掉某些珍貴物品才能救人。這次薩洛主動丟棄的是自己保存的伴侶艙位申請。
結尾不是復合。妮亞願意與他共同護航，但拒絕再讓愛情替他的領導決策背書。
**不可逆後果**：他失去艦長資格；兩人保留愛與距離，後續是否重新交往需另一段完整故事才能決定。

# 02 星圖領航・妮亞《不在地圖上的家》
**故事類型：移民公路電影／選擇自己的方向。** 與薩洛同子宇宙，卻有獨立於戀情的難民航線人生。

### 第一幕：空白座標（P）
妮亞從小替母親畫星圖。母親總在圖上標出沒有官方名稱的小站，說：「有人住的地方就不是空白。」妮亞把這句話當作職業信念，但她也常用它否定別人的現實恐懼。

### 第二幕：不肯下船的人（P）
難民艦載著拒絕離開故鄉的老人「雲伯」。妮亞為了保護全船，想強行把他帶走；雲伯反問她：「你救了我的命，就有權決定我住哪裡嗎？」
妮亞第一次學到救援與自由可能衝突。她留下小艇與通訊設備，讓雲伯自己決定是否登船。

### 第三幕：分手之後（P）
她與薩洛分開後仍會在航線圖上看見他負責的港口。她從未刪掉他的航線，卻也不再把兩人的未來畫成同一條線。

### 第四幕：錯誤的捷徑（D）
她拒絕把難民艦引進陷阱，於緊急改道中承受致命航行衝擊，**工作死亡事實不變**。她最後看見的不是薩洛，而是乘客親手標出的新航線。

### 第五幕：星圖之外（R）
召喚世界的星港要求她畫出通往魔王領域的安全路線。她知道路線，但不願把沿途居民變成軍事地圖上的「空白障礙」。玩家要逐一徵求航道居民同意，並承擔繞路的風險。
薩洛提出由他代替她承擔責任。妮亞說：「這次不用替我決定。我會自己署名。」
**獨立結局**：她完成一張允許居民自行刪除住址的星圖；即使薩洛不在隊伍裡，這段故事也成立。

# 03 銀河掮客・薇菈《一個人值多少》
**故事類型：友情背叛／商業犯罪／無法清償的債。** 與璃音共享「七環資料城子宇宙」，生前是共同創辦資料庇護所的好友，非戀人。

### 第一幕：零元契約（P）
薇菈年輕時最擅長談價錢，璃音最擅長保存被刪除的姓名。兩人為逃亡勞工成立「無價室」，規定第一條：**任何人的真名都不能成為抵押品**。
薇菈：「連房租都付不起，你還想寫禁止收費？」
璃音：「房租可以討價還價，名字不行。」
薇菈笑著簽名。那時她真的相信這條規定。

### 第二幕：缺口（P）
庇護所欠下巨額醫療債，薇菈偷偷把匿名化的流動統計賣給商會。她認為沒有出賣姓名；璃音卻發現統計能反推某些人的藏身處。兩人為是否銷毀資料爭吵，薇菈離開無價室。
這不是後來失名之夜的同一筆交易，而是薇菈第一次學會替自己的妥協找理由。

### 第三幕：最後一次拒絕（D）
薇菈成為契約仲介後，拒絕把勞工當商品出售。她在爆裂轉運站護送被販運勞工逃離時遇難。**固定死因不變**。她的勇敢不能抵消先前造成的傷害。

### 第四幕：重逢（R）
她先抵達召喚世界，開設新的仲介所；璃音後來出現。兩人重逢時沒有擁抱。
璃音：「你還記得第一條嗎？」
薇菈：「記得。我只是發現規則也要有人付錢。」
璃音：「那就不要再拿別人的名字付款。」

### 第五幕：失名之夜（N）
薇菈再次以名冊索引換取三十名召喚工人的醫療費，明知存在封鎖風險。阿書死於封鎖圖書館；璃音刺傷薇菈。這一次的罪行發生在**召喚後**，不與生前交易混同。
玩家在交易前能提出不同籌資方案，但不能用選項抹除已定的阿書悲劇；分支影響其他倖存者。
**結尾**：薇菈建立公開賠償基金，但璃音拒絕替她背書。薇菈終於承認有些債不是錢能還的。

# 04 群星檔案官・璃音《借書卡背面》
**故事類型：失去親人／隱私與記憶／友情破裂。**

### 第一幕：無價室的兩把鑰匙（P）
璃音與薇菈共管庇護所，一人保管實體姓名簿，一人掌管緊急開門權。璃音害怕資料外洩，逐漸把任何求助都當成潛在威脅；她並不是完美的守護者。

### 第二幕：最後一本書（D）
原世界的圖書館核心失控，璃音留守封存被抹去者姓名而殉職。她在死亡前沒有機會向薇菈道別。**工作死亡事實不變**。

### 第三幕：阿書（R）
召喚世界裡，年輕的阿書來借書，卻不願說出登記姓名。他只在卡片背面寫：「我希望大家叫我阿書。」璃音讓他自己選擇，從此每週替他留一本書。兩人的親近不是一句「視如家人」就成立，而是由多年日常累積。

### 第四幕：鎖住的圖書館（N）
失名之夜封鎖發生，阿書回圖書館搶救其他人的自選姓名卡。璃音知道另一道出口，卻因害怕名冊外洩而遲疑開啟。阿書死亡；薇菈的交易與璃音的遲疑共同構成悲劇，但責任不相同。
璃音：「我不是不想開門。我是怕開門之後，所有人又會被找到。」
她刺傷薇菈，卻沒有因此獲得任何解脫。

### 第五幕：公開還是保留（N之後）
玩家整理阿書的借書卡：公開可協助其他失名者證明身分，卻會違背阿書不願曝光的意願。璃音最終決定只公開阿書曾明確同意的內容。
**獨立結局**：她建立由當事人自行決定公開範圍的檔案室。她不原諒薇菈，也不再把所有資料都鎖在自己手中。

# 05 九尾審稿官・蘇妲《情書的最後一個字》
**故事類型：秘密戀情／語言與權力／失去愛人的方式。** 與清目共享「天庭第九卷子宇宙」。兩人生前秘密相戀三年；此設定**取代舊稿『死後才相識』**，其餘死亡事實不變。

### 第一幕：退回的情書（P）
蘇妲負責審核天庭詔書，清目是稽核官。兩人第一次交談，是清目退回她寫的公文，理由只有一個：「『應當』與『可以』不是同一件事。」
蘇妲故意在下一份公文寫下「我可以想你」，清目在旁邊批註「可以，不代表應當」。
這成為兩人秘密戀情的開端。

### 第二幕：不能公開的名字（P）
天庭禁止審稿官與監察官有利益關係。蘇妲不願公開戀情，清目則不願繼續把她寫成「無關人士」。兩人因一份狐族遷徙文書爭執，清目要求依法退件，蘇妲認為依法退件會讓族人失去住所。
他們沒有誰完全正確；愛情不能替政治選擇背書。

### 第三幕：最後一次修改（D）
蘇妲拒絕發布致命假命令，為銷毀被詛咒的詔書耗盡九尾靈力而死。清目當時在另一處查封天機爐，沒有親眼見到她死亡。
蘇妲最後留下的不是告白，而是一張退回的公文：「可以，不代表應當。」

### 第四幕：再見時是敵人（R）
蘇妲先被召喚，清目後來抵達。她以為死亡能讓兩人擺脫天庭禁令；清目卻仍認為兩人必須迴避同一份公文。
蘇妲：「我們都死過一次了，你還怕別人知道？」
清目：「我怕的不是別人知道。我怕我又會替你簽字。」

### 第五幕：三萬份判詞（C）
在召喚世界，蘇妲為換取狐族難民名額改寫織語人身分條款，清目明知缺乏聽證仍核章。兩人重演生前的價值衝突，這次造成文化抹除。霜婆與織冬各自代表不同居民選擇。
**結尾**：兩人公開罪責，失去職務。蘇妲仍愛清目，卻拒絕再與他共享任何需要共同簽署的權力。
這不是「相愛所以和解」，而是「相愛也不能再共事」。

# 06 天庭監察・清目《沒有署名的證人》
**故事類型：法律驚悚／失職與自我審判。**

### 第一幕：一個無名證人（P）
清目受理一名不願透露姓名的工役者檢舉。依法，匿名證詞不能單獨定罪；清目因此延後調查。證人後來失蹤，他才知道程序也會成為加害者的時間優勢。
他開始在每份稽核書旁寫上「還有誰在等」。

### 第二幕：他愛的人（P）
清目與蘇妲秘密交往，但始終不肯替她違規。真正讓兩人分裂的不是缺乏愛，而是他把「沒有違規」當成唯一的道德標準。
他曾想公開戀情，蘇妲卻要求再等一個月。那一個月永遠沒有結束。

### 第三幕：天機爐（D）
他查封違法天機爐，護住證人，承受爐爆而殉職。**固定工作死因不變**。他不知道蘇妲已經先死，也沒有在原世界與她重逢。

### 第四幕：新世界的簽章（R／C）
召喚後清目發現蘇妲仍在修改公文。他想證明自己已不再是只會按規則辦事的人，於是反而簽下缺少聽證附件的法令。他的錯不是太守規矩，而是為了擺脫過去，故意忽略規矩。
玩家要從不同居民口述中找出法令造成的損害；任何單一證人都不能代表整個族群。

### 第五幕：自己審自己（C之後）
清目公開簽章紀錄並主動要求迴避後續審判，因為他無權擔任自己案件的法官。
蘇妲問：「你這次終於肯承認錯了？」
清目：「我承認錯，不代表我有權要求你留下。」
**獨立結局**：他成立民間證人保護網，不再握有官方裁決權。蘇妲是否愛他，不能決定他是否有罪。

## 連續性修正與版本優先權
1. **薩洛×妮亞**：正式候選改為生前七年戀人、已分手；原關係草案中「召喚後初次雇傭才相識」須廢止，改為重逢。
2. **薇菈×璃音**：正式候選改為生前無價室摯友；召喚後才發生阿書死亡與失名之夜，舊「死後才初遇」敘述失效。
3. **蘇妲×清目**：正式候選改為生前秘密戀人；《三萬份判詞》V2的文化抹除事件仍保留，但其「死後才相識」句子失效。
4. **鐵時三魂小燈、阿誠、阿遠及08:59→09:00**完全不變；本批不更動。
5. 六人均保留原世界工作死亡事件；未聲稱六人是同一個跨陣營宇宙。
6. 本文件優先於早期關係草案中相矛盾的**初遇設定**，但屬待驗收劇本；不能直接視為全角色定稿。
7. 重要NPC（雲伯、阿書、霜婆、織冬）都必須有不依附主角的願望與決定。
8. 本批六人的核心類型分別是領導羞恥、移民自由、商業共犯、記憶隱私、秘密愛情、法律自審；不可將六篇縮寫成同一段「救人犧牲」。
