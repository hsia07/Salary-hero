# 角色 01：打卡守衛・鐵時｜08:59 故事定稿 V1.2

狀態：使用者已確認 08:59 為鐵時核心故事設定。此文件取代 CHARACTER_01_TIESHI_V1.md 中《23:59 的火場》的舊敘事設定；不取代其尚待平衡的技能數值，也不代表遊戲已實裝。

## 故事核心
- 角色：鐵時，生前 32 歲夜班保全，班表 00:00–09:00。
- 當天 08:59，距離退勤只剩一分鐘，鐵時因公司違規封鎖安全門引發的火災而返回救援。他救出數名受困同事，但沒能救出最後一人，自己也罹難。
- 企業紀錄僅顯示「08:59，未完成退勤程序」，冷漠制度與生命價值形成黑色幽默。
- 異世界勇者管理局把他生前的防火盾轉化為神器「終夜打卡盾」。盾上的 08:59 是未完成的退勤記憶，不是現實時間，因此永遠停在 08:59。
- 他的心結不是「不夠努力」，而是錯誤地替公司安全管理失職背負所有責任。故事終點是學會與同伴共同承擔，拒絕把任何人的生命當作績效指標。

## 三章角色傳記《08:59，尚未下班》
### 第一章：最後一分鐘
- 08:58，玩家操作鐵時與同事處理一場「例行安全檢查」；公會/公司文件不斷要求優先處理出勤表。
- 08:59 火警響起，門被違規上鎖。戰鬥目標從「擊敗敵人」改為「護送同事逃出」，守護/攔截行為可推進救援進度。
- 首領「封門的安全主任」操控防火門，玩家需以盾擊解除封鎖。揭露鐵時最後一分鐘的選擇。
### 第二章：尚未退勤
- 勇者管理局以「救援成功率」重演火場，Boss「績效審查官」將生命最低的隊友標記為不合格。
- 玩家需用嘲諷、護盾、攔截而非純輸出破解處刑；劇情揭露公司封門與未完成打卡的紀錄。
- 鐵時意識到管理局與舊公司一樣，把人的生命轉換成報表。
### 第三章：九點整
- Boss「午夜封鎖者」讓鐵時陷入「一個人必須扛下所有傷害」的幻覺。
- 第一階段若鐵時單獨承傷，敵人會逐漸變強；第二階段必須輪流守護、治療、共同抵擋，才會打開弱點。
- 終戰結束，盾牌第一次從 08:59 跳到 09:00。薪奴或同事說：「辛苦了。你可以下班了。」
- 鐵時回應：「……這次，我們一起走。」
- 不讓死者奇蹟復活；尊重火災受難者，也不把救援失敗描寫成鐵時個人能力不足。

## 時鐘演出硬規則
1. 普通立繪、卡牌、戰鬥、專武圖示：一律顯示 **08:59**。
2. 角色傳記第三章結局，時鐘第一次跳至 **09:00**。
3. 完成傳記後，特殊覺醒必殺動畫可短暫顯示 **09:00**，演出結束回復 **08:59**；不是日常時間變更。
4. 任何 AI 生成圖若出現 23:59、08:58、09:59 或其他錯誤數字，不可直接作為正式素材，必須人工修正並驗收。
5. 遊戲實際 UI 數字以可程式控制的獨立數位顯示圖層實作，避免 AI 圖中文字不準。

## 角色美術硬規則
- 正式立繪：正常成人比例，視覺約 170–185 cm、7–8 頭身；鐵時應修長健壯，不能被畫成矮胖 Q 版。
- 戰鬥才使用 Q 版，必須與立繪有相同髮型、臉部特徵、服裝剪影、盾牌。
- 去 AI 感：清晰輪廓、乾淨色塊、無雜點、無破碎線條、無不合理裝備堆疊、無多餘肢體、無含混文字。
- 風格：異世界上班族、華麗但有梗。以保全制服、識別證、打卡裝置、防火盾與奇幻護甲結合；幽默指向職場制度。
- 製作順序：獨立角色立繪 → 一致三視圖 → 獨立盾牌圖層（含可替換數字）→ 戰鬥 Q 版逐動作分層動畫 → 卡牌景深/箔光分層。
- 概念圖不是透明分層素材；不得宣稱已完成正式動畫。

## 專武敘事與機制
- 「終夜打卡盾」是保護他人、反抗制度的象徵；其 +0/+10/+20 機制仍按 SR 專武規則設計。
- 09:00 不是單純升星就解鎖；必須通過第三章傳記，與技能覺醒演出掛鉤。
- 同事職業固定：鐵時始終是坦克；不倒門衛、鐘擺處刑者、鋼鐵監工為同職業內技能覺醒配置，非轉職。只有薪奴可自由轉職。
