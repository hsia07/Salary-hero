# 《薪水勇者》六人陣容、羈絆融合與平衡施工規格 v1.0
## 不變的核心
- 60名候選角色稀有度為N3/R15/SR23/SSR12/UR7；鐵時SR特殊死靈護衛覺醒保留。
- 原世界工作死亡→死後召喚。六陣營是來源世界文化及死後組織歸屬，不能硬改為原生異世界六國。
- 本版**設計文件**，未修改遊戲runtime。主角是否占六人編制需對現有程式確認。
## 一、六人隊伍職能與空間
採「2前排＋2中排＋2後排」作為**可調站位**，不是強迫兩坦兩補。角色有碰撞半徑、移動速度、技能範圍、射程與攻擊前搖；近戰要靠近並接觸，遠程有彈道。坦克可在一定角度攔截前往後排的攻擊，刺客須尋找可到達路徑，不能隔空瞬移無成本斬殺。
**目標分配公式候選**：分數=威脅權重35%＋可達性30%＋職業偏好20%＋剩餘生命弱點15%；每個單位每1.5秒或目標死亡重新評估，允許目標鎖定0.6秒防止抖動。嘲諷強制改變目標但受免疫限制。近戰選不到路徑時先攻擊可接觸敵人。治療按缺血比例與預估溢補分配。
## 二、羈絆不只湊同陣營
- **人物羈絆**：完成雙人任務解鎖聯動，兩人同隊獲得一個「戰術動作」，不是全隊常駐大量屬性；一隊最多裝備2個人物羈絆動作。
- **來源共鳴**：同陣營2人啟動低量效果（如HP+2%），4人啟動非數值機制（如首次控制抵抗），6人啟動陣營敘事專技但不提供巨大數值倍乘。跨陣營隊伍同樣能透過人物羈絆與融合競爭。
- **羈絆融合**：完成兩組羈絆故事後解鎖一個「羈絆核心」；可安裝在**非原羈絆角色**身上，得到約60%原機制，不能複製終極技能、無敵、復活或首領硬控；同隊最多1枚融合核心，與原羈絆效果不疊加。
- **雙核心共鳴**：在後期進階副本獲得材料後可將兩種不同羈絆核心融合成新機制，例如「護盾×淨化」成為破盾時清除1層可淨化負面（內置CD12秒），「標記×追擊」成為第一次擊破標記後最近友軍補刀（CD10秒）。此系統是**候選設計**，不可先把未核准的羈絆融合寫入正式存檔。

## 四、職業克制與不讓UR碾壓
- 坦克剋高頻小傷，怕百分比DoT與破盾；刺客剋孤立後排，怕攔截、嘲諷；術式剋密集敵群，怕分散與沉默；治療剋持續消耗，怕禁療；召喚剋單點，怕範圍清場；情報／控制剋慢速蓄力，怕控制抗性。
- N/R也必須有不可取代的低成本機制：例如豆豆供能、五分鐘干擾、小玉搗藥、噗嚕承傷、滴答延遲。不能僅是抽到高稀有就全員淘汰。
- SSR/UR更複雜的戰術與演出不等於無條件更高的每秒傷害；UR最多提供「強力但有明確反制」的獨特能力。UR覺醒需付出冷卻、條件、位置或能量成本。
## 五、數值系統尚需補齊的實作項
目前成長資料只有職業模板與里程碑。下一階段必須補齊每名角色：攻擊動作時間（前搖／命中／收招）、移速、射程、碰撞半徑、受擊硬直、技能係數、元素相剋、能量回復、暴擊、命中與抗性、護盾效率、治療效率、控制抗性、DoT來源與上限、技能冷卻、Boss抗控、裝備副詞條與專武精煉。**不得把目前候選值說成已平衡。**
## 六、驗收規格
1. 建立固定種子戰鬥模擬器，至少10,000場：同等總培養資源、同等裝備品質、不同稀有度與六人組合；測PVE通關率、平均戰鬥時間、承傷分布、治療溢補、轉火次數、控制覆蓋率、角色出場率。
2. 以同戰力可替換位置的隊伍為比較基準，若特定角色提升勝率>8個百分點且沒有代價，或低稀有度在所有副本被全面替代，必須回調。
3. 必須測試「全隊集火同一敵人」「攻擊隔空」「奶媽無法救最低血量」「護盾無顯示」「燃燒只有icon」「SSR/UR Live Card單圖平移」六種反例。
4. 戰鬥美術依 `docs/COMBAT_STATUS_VISUAL_HARD_RULES_V1.md`，每種狀態有角色本體特效、命中／結束動作；低階手機30FPS目標，正常60FPS目標。
## 七、施工優先
P0 鐵時+小澄+白律+七號+千式+五分鐘六人垂直切片（真實動作／技能／狀態／AI）；P1 另外六大流派各至少一個核心角色與1個可反制首領；P2 全60人技能唯一性與成長數值；P3 SSR12／UR7的覺醒專武實境卡。每一步需真實素材、可玩的戰鬥與測試，不得用UI表格冒充完成。
