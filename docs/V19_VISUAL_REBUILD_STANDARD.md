# 《薪水勇者》V19 正式美術重製基準
最後更新：2026-11-09。**美術優先於擴充玩法**。V18 的 `art/v18/portrait-home-master.webp` 為官方品質參考，但它是含 UI 與角色的整張概念畫，**不得直接當作獨立遊戲素材**。

## 結論

V19 目前仍有大量工程 SVG 與 Emoji 精靈，雖然戰鬥與資料能動，但**尚未達成正式美術品質**。本次新增多層夜景辦公室 SVG、櫻花金飾透明前景、獨立公事包武器與華麗金紫 UI，目的在先打通正確渲染與驗收管線，不代表高精緻插畫已全部完成。請勿為了增加關卡或抽獎再次延期美術工作。

## 美術視覺標準

- 精緻日系奇幻 RPG，細膩且清楚的 Q 版人物、溫暖金橙高光、深紫藍環境光、材質細節、適量魔法流光；角色與敵人要有完整輪廓，不可以只是符號或幾何圖形。
- 背景場景不是 UI 海報。背景絕不嵌入血條、按鈕、薪資數字、角色或敵人；各個遊戲元素自行渲染與更新。
- **初始主角**：瘦、黑短髮、乾淨但疲憊的日本上班族，白襯衫、紅領帶、深色西褲、員工識別證、手持公事包。不可自動變成少年金甲勇者，也不是鬍子拉碴的大叔。
- **其他可收藏造型**：男性、女性、怪物、機器人、外星人、獸人等可有不同骨架與演出，但使用同一套精緻美術規格；取得條件暫緩增加，既有資料保留即可。
- **敵人**：已建立 24 種不同敵人資料。正式版本每種要有真正不同的角色外觀、攻擊動作、受傷、倒下及技能特效，不能只替換 Emoji 或名稱。
- **武器與裝備**：角色手中持有的武器外觀必須依裝備狀態變化，效果、光效與受擊互動都需要實際動畫。
- **場景**：辦公室走廊、夜景辦公室、地獄星期一、週五迎接週末、無限之塔等分階段製作；至少分遠景／中景／前景，必要時加獨立燈光層，不能靠一張 UI 海報假裝遊戲。

## 第一個正式垂直切片（唯一的美術 P0）

1. 初始主角完整透明立繪（待機、揮公事包、受傷、勝利、趴桌睡覺），同一人物、同一比例。
2. 一隻正式辦公室怪物（最初可以是影印機）、攻擊／受傷／死亡，不得只用 Emoji。
3. 一個正式的夜景辦公室、獨立背景、前景、燈光；和 V18 參考圖並排比較。
4. 一把完成的獨立公事包武器與擊中效果。玩家實際點擊後武器要跟著角色動作。
5. 在可遊玩 V19 手機頁實際測試。完成**四類實際動作並通過品質驗收**後再批次生產其他角色、怪物與場景。

## 品質與工程驗收

| 對象 | 技術驗收 | 美術驗收 |
|---|---|---|
| 場景 | 720×620 邏輯座標，2× 高解析畫布 1440×1240；分離圖層，不能嵌 UI | V18 同級光影、精細材質、色彩、深度 |
| 角色 | 每種姿勢獨立透明素材，建議 512×512 主角原圖；不裁切、腳底對位 | 初始瘦黑髮日本上班族辨識一致，動作不崩 |
| 敵人 | 各類型獨立檔案、具可測血量及攻擊／傷害狀態 | 有不同剪影、層次、光影，不只是 Emoji 換字 |
| 武器 | 透明獨立圖層與角色動畫位置同步 | 每件裝備識別度足夠、稀有度有真實外觀差異 |
| 手機 | 390px 寬度無橫向溢出；能命名、攻擊、開衣櫃；實際圖片 HTTP 200 | iPhone 視覺比對 V18 參考，手感與動畫自然 |

技術自動測試：
- `scripts/qa-v19-layered-art.py` 對獨立場景、前景、武器檢查 XML、輸出尺寸、alpha、裁切及程式引用。
- `scripts/qa-v19-mobile-smoke.py` 透過 390px 窄螢幕的 Chromium 測試遊戲啟動、獨立素材載入、2× 畫布、戰鬥狀態、角色介面，並輸出實際畫面截圖。
- `.github/workflows/v19-art-runtime-ci.yml` 設定自動執行。**本文件建立時尚未取得該工作流程的成功證明，不能標為實機通過。**
- 正式藝術品還需要**人工視覺驗收**；機械地通過解析度／透明度只是必要條件，不是美術品質保證。

當前 `art/v19/runtime/ART_REGISTRY.json` 將所有已提交的分層工程美術與尚未完成的角色、敵人候選素材分開列出。
