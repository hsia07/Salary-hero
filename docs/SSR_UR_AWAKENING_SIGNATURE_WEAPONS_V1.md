# SSR／UR 覺醒故事與專屬武器總規 v1

狀態：**19名角色的候選企劃，不是正式完整劇本、最終平衡數值、正式美術或已實裝功能。**

## 系統規則
- SSR（12人）：個人背景六幕之後解鎖「覺醒三章」：舊錯重現→玩家可操作的困局／Boss→角色作出與過去不同的選擇；解鎖覺醒立繪、專屬演出、技能分支。不得僅用材料升星觸發劇情。
- UR（7人）：在個人六幕後開啟「覺醒五章」，新增一個能改變角色命運的副本、角色專屬Boss與至少兩位相關角色的互動；UR的稀有度不代表一定要犧牲或變成神。
- 專武：全60人都有；SSR/UR專武必須有來源遺物、外觀成長（基礎／突破／覺醒）、戰鬥機制改變與獨立分層動畫。專武0–4階；升階提供功能改善，不把覺醒主線鎖在抽到重複武器上。
- 取得：完成角色個人篇取得專武基底；完成覺醒篇取得覺醒型態；後續透過專屬副本素材升階，重複抽卡只能加速、不得獨占關鍵故事。
- 每一章必須有實際可玩事件，非純文字選單。角色可以有失敗、矛盾、幽默，不能所有人都以犧牲拯救世界收尾。
- 競技與平衡：覺醒是機制選項，不是純數值碾壓；治療、盾、控制、位移、嘲諷與多目標必須有明確反制；倍率、冷卻、觸發上限尚待模擬。

## 實裝驗收
1. 每人獨立劇本、對白、敵方機制與結局分鏡；SSR至少三章、UR至少五章。
2. 專武基底、進階、覺醒各一套**真正的分層角色／武器美術**，包含待機、移動、施放、命中、受擊與勝利的必要部件，禁止CSS幾何拼貼。
3. 裝備後角色實際換武器模型、技能動作和命中特效；UI面板與圖鑑僅為輔助。
4. 六人隊伍測試：分散選敵、奶媽與護盾、首領機制、技能施放與冷卻、專武交互；不通過不能標為完成。
5. 保留鐵時SR特殊覺醒與三魂一盾、08:59→09:00；SSR/UR規則不抹掉此例外。

## 風險與後續
- 19名覺醒稱號與武器名稱均為**候選**；寫完整劇本時再逐人打磨，避免一眼看出公式化命名。
- 未驗證每位角色的既有專武設定是否同名；若衝突，需先做名冊比對，再更新唯一來源。
- 本文件不代表專武已寫入角色JSON或遊戲runtime。
