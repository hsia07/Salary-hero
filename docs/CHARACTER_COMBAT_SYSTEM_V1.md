# 《薪水勇者》正式編制與角色戰鬥設計 V1

狀態：2026-11-13 使用者已同意「薪奴＋六名同事」的核心架構；本文中的技能數值、羈絆名稱與角色細節為第一輪設計值，尚待實戰平衡與角色美術驗收。

## 已核准編制
- 薪奴為獨立第七名參戰者，不占六名同事欄位，保留遊戲內已定案的外觀。
- 薪奴親自戰鬥，擁有個人攻擊、可轉職技能、全隊指揮技及一個羈絆適應效果。
- 六名同事可調整站位，擁有各自的職業、出身羈絆、戰術羈絆、技能、數值、轉職、專武、故事及分層動畫。
- 角色池正式版 60 名為目前規劃目標，首輪 18 名用來驗證核心流派，後續可持續擴充；尚非已完成數量。

## 六大基礎職業與戰鬥 AI
| 職業 | 選敵／行為 | 機制 |
|---|---|---|
| 坦克 | 優先攔截近身威脅與保護低有效生命隊友 | 嘲諷、護盾、減傷、反擊 |
| 戰士 | 優先可接近且威脅高的目標 | 連擊、吸血、破甲 |
| 刺客 | 突襲敵方後排輸出、治療與控制單位 | 突進、戰術背刺、斬殺、撤離 |
| 法師 | 選擇可覆蓋最多敵人的施法目標 | 範圍傷害、控制、異常 |
| 輔助 | 根據生命百分比、盾量、控制狀態、受攻擊風險選友軍 | 治療、護盾、淨化、增益 |
| 召喚師 | 依戰況配置砲台、機兵、召喚物 | 召喚、強化、干擾 |

戰術背刺是攻擊標籤，不依賴敵人背向判定。突進必須有實際接近、命中、受擊與返回/留位動畫。Boss 可對打斷有抗性，不應免疫所有刺客輸出。

## 薪奴初始轉職（待數值驗證）
1. 爆肝隊長：輸出／爆發。指揮技「全員趕工」，暫定全隊攻速 +18%、技能傷害 +12%，持續 6 秒；代價是薪奴承傷 +10%。
2. 摸魚軍師：控制／技能循環。指揮技「主管不在」，暫定敵方攻速 -15%，並為隊友回復少量技能能量；代價是薪奴個人傷害 -12%。
3. 後勤主管：生存／支援。指揮技「今天準時下班」，暫定全隊獲得各自最大 HP 10% 護盾並清除一個可淨化減益；代價是薪奴個人爆發倍率降低。
- 每場只裝備一條轉職、一個指揮技、一個羈絆適應；指揮技可自動託管或手動施放。
- 指揮技消耗能量；不得無冷卻連續施放。暫定每場能量上限 100、技能消耗 100，能量由攻擊／承傷／時間積累，具體速率待測。
- 羈絆適應不得無條件補滿任意羈絆門檻，建議僅可對一個已擁有至少兩名同事的羈絆增加一層有效計數，且不能單獨啟動最高階效果。

## 同事初始角色定位（美術與故事尚未定案）
| ID | 暫用名稱 | 職業 | 戰術核心 | 初始稀有度 |
|---|---|---|---|---|
| guard | 打卡守衛 | 坦克 | 攔截、嘲諷、護盾 | SR |
| fighter | 逃班鬥士 | 戰士 | 連擊、攻速、吸血 | R |
| assassin | 截止日刺客 | 刺客 | 後排突襲、斬殺、殘影 | SSR |
| medic | 咖啡醫官 | 輔助 | 急救、群體治療、淨化 | SR |
| mage | 試算表法師 | 法師 | 群傷、減速、控制 | SR |
| engineer | 機械工程師 | 召喚師／輔助 | 砲台、群體護盾、機兵 | SR |

以上沿用既有 runtime 原型 ID，避免破壞存檔。只有薪奴現有美術已核准；其他角色的性別、名字、服裝、專武、個人故事都未定案。

## 羈絆設計
- 每名同事初始有一個「出身羈絆」與一個「戰術羈絆」。
- 出身反映角色現實生前的職業/事件、召喚來源或異世界身分；戰術羈絆反映護盾、夜班、暗影、奧術、召喚、治療等戰鬥互動。
- 基礎門檻候選為 2/4/6 人，但需依實際六人編制與羈絆數量驗證，不能每個羈絆都固定相同門檻。
- 後期「異常契約」允許有限的額外羈絆；「融合羈絆」改變戰鬥規則而不僅是百分比加成。
- 羈絆設計需避免單一最優隊伍；新角色要創造可替代的流派，而非純數值膨脹。

## 完整角色資料模型
每名角色：ID、稀有度、職業、兩類羈絆、定位、攻擊方式與射程、HP/ATK/DEF/攻速/暴擊等成長曲線、普攻、被動、主動、必殺、AI 選敵/施法規則、轉職路線、專武、裝備變化、生前背景、死亡與召喚事件、同事關係、傳記副本、立繪與逐動作分層素材。

## 製作及驗收順序
1. 保持現有薪奴外觀，先將現有 7 人原型資料與正式角色 schema 對齊，保留舊存檔兼容。
2. 製作打卡守衛第一份完整角色設計卡：背景、數值成長、技能公式、AI、羈絆、轉職、專武、傳記第一章。
3. 產出經驗收的正式立繪、分層 Q 版戰鬥圖及待機/移動/攻擊/受擊/技能/死亡/勝利動畫。
4. 接入實際戰鬥，驗證攔截、嘲諷、技能冷卻、目標選擇與動畫命中。
5. 擴展其他同事與 18 人戰術驗證池，再逐步擴展到正式版 60 人目標。
