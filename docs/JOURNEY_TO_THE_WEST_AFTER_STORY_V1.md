# 西遊番外篇｜《經取回來以後》世界觀重製 v1
狀態：候選主線設定，待玩家確認。此檔優先於舊版「悟空與八戒死後才相識」的**候選**設定，但尚未改動正式角色資料庫、戰鬥或遊戲程式。
## 故事定位
本作採《西遊記》取經成功後數百年的**架空番外／平行後日談**，不是聲稱吳承恩原著有此後續。師徒四人完成取經並受封，**保留共同經歷與原有師徒關係**。悟空、八戒、悟淨及唐僧原本彼此認識，不可再寫成死後公會初次見面。
## 起點：取經專案尚未結案
天庭宣布「經已取回，但九九八十一難的核銷、妖怪處置與人員安置未結案」。荒誕笑點是神佛體系的官僚程序，但主線不是只有嘲笑上班：沿途被視為「已處理」的人與妖，正被新工役制度重新徵用。取經的功德成為管理階層的績效，曾經被救的人卻沒有名字。
## 師徒群像
- **悟空**：已取得封號，仍不喜歡受人支配；最難接受的不是命令，而是曾經帶領猴民反抗時讓弱者付出代價。保留金箍棒、毫毛、筋斗雲、火眼金睛。過去取經與後日談的猴民工役事件可共存。
- **八戒**：受封後接管天河食堂，貪吃偷懶仍在，卻記得每個夜班工役的飯量；對師兄嘴上不服，實際上仍願意在最糟時候端一碗飯給他。生前死亡仍是天河食堂供餐天火事故。
- **悟淨**：從挑行李轉為天河／忘川等跨界貨運搬運官；過去常做調停者，後日談開始練習表達自己的選擇。**其原版工作死亡事件待核對後才能寫死**。
- **唐僧**：保留慈悲、守戒與對弟子的信任，與悟空對「遵守制度是否等於守護眾生」產生分歧；是否成為60人可招募角色**尚未決定**，先列為關鍵NPC，不擅自增加第61人。
- **哪吒、敖璃、嫦月等**：可因天庭卷宗、龍宮帳冊或其他職務介入；不可自動寫成四師徒之一或共享所有過去。
## 六幕故事骨架
1. **《散夥飯》**：取經後多年，八戒請大家吃飯，悟空遲到，悟淨帶來整車未結案卷宗，唐僧收到天庭催辦文。
2. **《八十一難，缺一張收據》**：四人查核沿途妖怪與居民的補償名冊，發現部分人被列為「無須安置」。
3. **《成佛也要打卡》**：悟空被要求擔任工役結界護送者，八戒食堂配給縮水，悟淨運送的箱子裡裝的不是經卷。
4. **《師父，這回不聽你的》**：唐僧要求依正式程序申訴，悟空認為等不及；兩人爭執，但不把唐僧寫成愚蠢或反派。
5. **《花果山的名冊》**：悟空接到護送受役猴民的工作命令，發現結界抽取神魂；他以護送職責破除結界，**神魂耗盡死亡**。同時八戒、悟淨與其他神話角色須各自發生既有設定中的**獨立工作死亡**，不能一筆帶過或改成全員一起穿越。
6. **《第二次集合》**：悟空等人死後先後被召喚至《薪水勇者》異世界，舊師徒重逢，發現這裡也有取經式績效管理。唐僧的去向保留懸念，不預設他也死亡或被召喚。
## 工作死亡與召喚規則
**所有可招募的西遊角色均必須先在原世界因工作死亡，再死後召喚。** 悟空原本工役結界死亡、八戒天河食堂火災、哪吒卷宗庫房救援死亡維持；悟淨依其原定死亡設定核對後銜接。唐僧作為未列入60人的NPC不受可招募角色的死亡硬規則約束。
