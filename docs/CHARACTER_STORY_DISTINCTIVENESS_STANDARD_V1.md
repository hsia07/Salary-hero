# 60 人角色故事去模板化硬規則 v1
**正式故事品質標準；適用已完成39人初稿與尚未撰寫21人。不是已完成重寫。**
## 核心問題
已完成背景初稿普遍使用「發現組織違法→違抗命令→救同事→犧牲→召喚後說一句漂亮話」的結構。這是**必須修正的同質化風險**，不得把職業、道具、反派名稱換掉就算獨特。
## 不可變更的世界觀
60人皆在原世界**因工作而死亡**，死後召喚；但「因工作死亡」不等於「每個人都英勇救人」。可以是錯誤判斷、技術事故、疾病、意外、被背叛、選擇承擔風險、執念或職責衝突；須保留各角色既定的具體死亡事件，若要改死亡方式必須另提修訂並經確認。鐵時既定三魂一盾及08:59→09:00不可改。經典神話武器不可改；專武美術升級標準照舊。
## 七維差異檢查
每人故事建立唯一「七維指紋」：
1. **核心慾望**：他究竟想要什麼，最好不是籠統的自由或正義。
2. **致命缺點**：錯在哪裡？其缺點是否真正造成不可挽回的後果。
3. **故事類型**：職場黑色喜劇、密室推理、冒險、懸疑、愛情、家庭、政治、競技、恐怖、生活、法庭、旅途、災難、悲喜劇等。
4. **衝突來源**：自己、親友、對手、誤會、自然、意外、傳統、制度、價值選擇；避免全員同一個壞公司。
5. **故事結構**：倒敘、一天、跨數年、雙視角、調查、競賽、旅途、無可靠敘事者、單一場景、碎片拼圖；不是人人六幕同順序。
6. **死亡情緒**：驚愕、荒謬、遺憾、悔恨、平靜、悲壯、諷刺、懸疑；保留已定死亡事實，但不必每次都演出英雄式告別。
7. **召喚後延續**：帶著什麼問題或執念？不能只用一句雞湯結尾。
## 驗收與退稿
- 每人寫一句**無法輕易換給其他角色**的故事鉤子，若能替換姓名仍成立，退稿。
- 同陣營相鄰三人，不得同時採用「發現黑幕、反抗、犧牲」作主要劇情。
- 每人至少一位有自己目標的配角；至少一個無法用技能解決的個人選擇；至少一個具體物件在開頭與結尾有不同意義。
- 不得把覺醒故事一律寫成「找到舊證據→對抗舊上司→原諒自己」；SSR/UR各自要有獨特遊戲機制、敘事節奏和關係變化。
- 對話不靠角色輪流說大道理；要有插話、誤解、日常習慣、真正的幽默和難堪的沉默。
- 工作死亡是**世界觀入場條件**，不是每篇故事必須拿來做高潮的唯一事件。部分角色可在前半段死亡，後半段講異世界生活。
- 避免機械式「三幕覺醒」「五幕覺醒」強迫相同節奏；章數是內容量下限，敘事可以拆成短事件、長副本、雙線和可重玩選擇。
