# 第一組 Phase 1｜33 篇製作鎖定與遊戲改編規格 V1

**狀態**：第一階段施工文件；尚未代表 33 篇正文完成。採用 `WORLD01_33_CHAPTER_PLAN_AND_QA_V1.md` 為章節索引。第一、二章為不足 3000 字的試稿，第二階段必須重寫擴充，不可直接算完稿。

## 寫作與遊戲雙軌硬規則
1. 正文按連載小說規格寫：完整場景、人物慾望與阻力、對話潛台詞、快慢節奏；不能使用人物傳記或企劃摘要冒充正文。
2. 去 AI 套式：每章檢查抽象結語、過度排比、相同句型、說教台詞、每個角色同一口吻。禁止只為達字數而重複場景。
3. 每場標註獨立的 `scene_id`、相對年份、地點、視角、登場角色、劇情功能、線索進出、可互動元素、可跳過／回放方式。這些標籤放在**改編表**，不放小說正文。
4. 主線六幕要能在不抽到白律等角色時理解；角色私密回憶可作抽卡後解鎖的支線，不能封鎖主線必要資訊。
5. 重要事件須有遊戲化方案：對話立繪、分層動畫、環境音、可探索物件、證物檢查、疏散／救援機制等；不強迫每場都戰鬥。
6. 死亡不作可刷素材的娛樂化表演；回憶副本可改編角色面對的困境，不必逐字重演死亡。
7. 章節品質以實際字數和內容驗收，不能只用檔案數宣稱完成。
