## 二、原始稿間的重大差異（需明確裁決）

### P0-01｜第十三頁「直接展示全文」或「延後揭露」
- 原始完整故事初稿 V1 **序章**已直接寫出手寫第十三頁的事故指控文字。
- 深化 V2 明確改成序幕只展示缺頁痕跡，第五幕才完整展示內容，且必須查筆跡、形成時間與保管鏈。
- CH16 目前只找到移交清冊索引，符合 V2 的延後揭露，但**不符合初稿序章的早期公開方式**。建議以 V2 為正式敘事揭露策略，保留 V1 所寫的文字作為「待查文件內容候選」，不可提前當成鑑定事實。
- 另：初稿用「事故前七十二小時改為常閉狀態」；CH01–02 已有更早的鎖門與多次報修，CH13 只是**新扣件加固**。必須釐清「早期鎖門／新增扣件／七十二小時前變更」分別是哪次改動，不能把同一事件說成首次鎖門。

### P0-02｜鐵時死亡機制與調查證據
- 原始 V1 寫鐵時折返、肩骨受傷、把無線電放門縫報受困位置、死於封閉通道；總綱亦保留封門相關死亡。
- CH14 現在只呈現小澄通話、老趙有限目擊與社工初步轉述，尚不能確定無線電、受困位置、死因與封門直接因果。
- **建議保留原始終點作為創作意圖**，但後續必須有可信現場、救援及專業證據才能將其寫成經查明的事實；不能用單張事前照片代替。

### P0-03｜未寄訊息與已寄訊息不能混用
- V1 原始鐵時最後未寄草稿為「今天下班，我想跟妳好好談談」；V2 強調小澄可能永遠不知其完整心意。
- CH05 鐵時已**成功寄出**「還有，門沒有修好。我之前騙了妳。」；CH14 有最後通話提及週末看房。
- **兩件事可以共存**：一則坦承門況的已寄訊息＋另一則沒有寄出的私密草稿；但現行 CH14–15 尚未明確核對原始未寄草稿是否存在。不可把 CH05 已寄訊息誤稱未寄。

### P0-04｜錄音事件至少有兩條線
- V1/V2：白律早年公開匿名證人錄音，匿名證人失業、搬家；豆豆藏有對白律不利的舊案錄音。
- CH11 分別有何先生（案件當事人）與匿名證人；CH12 豆豆找到的是**何先生事後申訴訪談錄音**，提到公開其照片與工作資料，並在第七日自行交回。
- CH16 已改成提及匿名證人的聲音，但目前 **CH12 錄音所錄者不等於匿名證人**；需要明確寫成「白律舊案造成的兩種不同傷害」，或統一改寫來源，不能將何先生申訴錄音說成匿名證人的原始錄音。
- 原始豆豆「藏到師父發現」已被 CH12「自行坦承」改寫。建議保留更具能動性的現稿，但應在角色弧線規格中明記此變更，並確保後續 CH21 不再演一次相同的隱瞞揭露戲。

### P1-05｜五分鐘資格與工作
- V1 寫被志工隊革職、後為商場疏散員；CH09 明確是**承包單位演練助理**，沒有消防志工帶隊資格。此為職務細化，不是獨立角色。
- 後續 CH21 的出庭資格與現場接觸權限，不能寫成他仍具有消防志工隊長身分。

### P1-06｜白律父親的知情邊界
- V1 寫父親參與分散責任的契約格式，並有父親病重的未來情節；V2 強調父親不是幕後黑手，須核對版本。
- CH17 目前只證實父親**記得曾審舊範本**，不能因此證明他核准本案鎖門。父親病重也不能從 V1 直接倒填為 CH17 當下事實。

### P1-07｜原始角色結局與未來章節
- 原始十人各有不同的職場死亡場景；CH26–30 章綱要在不同年份處理。原始 V1 梨奈、茉莉、千式、阿拓、赤線、五分鐘、小澄、白律、豆豆的終局，目前**均未成為已寫正文**。
- 應保留死亡類型與相對先後，但不應強迫所有人以「回頭救人」同一節奏收束。

4. CH21 不得直接揭露「第十三頁」的完整真相，也不得提前證實父親核准封門。
5. 先將 CH12 何先生錄音／匿名證人錄音的差異、CH05 已寄／未寄訊息差異，以及早期鎖門／CH13 新扣件的區分，納入後續事件帳。
