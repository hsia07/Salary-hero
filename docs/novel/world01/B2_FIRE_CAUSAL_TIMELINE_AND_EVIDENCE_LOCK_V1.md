# 第一世界｜B2 火災事故因果、動線與證據鎖定 V1

**狀態：事故設計提案／調查待證，不是消防鑑定、既成史實或 CH21–25 已完成正文。**
**適用：CH01–02、CH05、CH13–17、CH21–25；不得將鐵時事故與其他角色後續各自職災合併。**

## 一、不可變的敘事事實

1. 鐵時發現 B2 西側防火門在逃生方向無法開啟，拍照、報修、向正式窗口寄送申訴；未取得承辦受理或改善完成的確認。
2. 星期五 21:30 左右，東側樓梯可由 B2 方向推開；西側固定門仍無法開啟。**這只能證明火災前的門況。**
3. 星期五 22:41、22:47、22:53 鐵時三次來電，小澄未接；第四通接通 27 秒，鐵時在「一樓往下的樓梯口」，說東側剛有人上來、仍在確認人數；第五、六通是小澄撥出而無人接聽。
4. 老趙稱鐵時扶他抵達東側樓梯口；他往上走了幾階後聽見下方有人喊叫，再回頭時煙霧已遮住走道。他曾向鐵時說清潔間附近仍有人，但**未看見喊叫者、鐵時折返的完整過程，也不能證明喊聲來自清潔間**。此為**目擊者陳述**，尚非完整現場重建。
5. 鐵時在事故中死亡；「為救受困同事而折返」為原始角色設定。CH14 角色此刻只能接觸初步轉述，不能提前確定折返路徑、時間、受救者身分或死亡機制。
6. 西側加鎖違反逃生方向可開啟的設計需求是主要調查方向；實際法規適用、責任主體及死亡因果須以建物資料與正式調查支持，不得讓小說人物憑單張照片定罪。

## 一之一、設備語義與事故前72小時的證據閘門（2026-11-14 補充）

- **「常閉」不是「鎖閉」**：防火門保持關閉可能是正常防火區劃要求；必須另證逃生方向是否能直接開啟。原始 V1 手寫附頁的「事故前七十二小時改為常閉」目前僅是未經鑑別的文件主張，**不是已確認的非法鎖門時點**。
- **舊管制鎖／兩週前更換／星期四新扣件／星期五持續管制公告**是至少四個不同事件或狀態；不能把它們合併成單次「72小時前加鎖」。
- CH13 星期四 02:00 是**發現扣件**，不是已知的安裝時刻；老趙聽說前夜有保全工程，也不能證實誰裝扣件。
- CH13 星期五 21:30 實測西側不能開；CH14 22:41 起的通話只證明後續時間順序，**不構成火警當下門況的獨立檢驗**。
- **CH21–25 的取證清單必須有設備識別欄位**：門扇／門弓器、門鎖、外側門禁、內側逃生五金、金屬扣件；分別記錄安裝者、工單、核准權限、實際時間、內側推門試驗、照片原檔、火警時是否仍存在。
- **禁止用手寫附頁單獨判定責任**：須先驗原件、形成時間與用詞，再與有效消防圖說、實際門具及獨立目擊交叉核對；不確定時保持「未證」。
- 對應專項詳見 `ORIGINAL_CANON_EVIDENCE_AND_REVEAL_LEDGER_V1.md`。**P0-A～E 不因新增本節而自動關閉。**

## 二、建議採用的因果模型（創作設定，尚待劇情證據支持）

**火源／煙流未鎖定 → 部分人沿東側成功撤離 → 另一批人按指示往西側，遇固定門折返 → 延誤與煙霧增加通往東側的危險 → 鐵時在已協助老趙抵達東側後，得知清潔間附近仍有人而折返 → 搜救期間受困死亡。**

此鏈每個箭頭都要有獨立支持；尤其「西側受阻」不能直接等於「鐵時死亡由鎖門單一造成」。不能讓東側樓梯突然被鎖、讓濃煙無視空間條件、或把救人塑造成足以免除管理責任的英雄犧牲。

## 三、空間配置：僅供場景設計，不能冒充實際平面圖

- B2 有**東側樓梯**與**西側防火門後的另一座樓梯**，這是 CH13 已寫明的最低限度結構。
- **清潔間**與 B2 兩路相對位置、走廊分叉、煙霧穿越防火區劃的方式，均尚未鎖定。
- **一樓往下的樓梯口**是 CH14 第四通鐵時自述位置，不能寫成他當時已在 B2；其後是否、何時再入地下樓層須調查。
- 東側「火災前可通行」與「火災時因煙熱難以抵達」並不矛盾，但後者目前只是待驗假說。

## 三之一、B2 可繪製的「最小空間模型」與禁止推定

這裡採用**拓樸節點**而非虛構比例尺。讀者和遊戲玩家只需先知道路徑如何相連；尚不能把它畫成經過建物圖說確認的實際平面圖。

```text
                    地面／一樓
                        │
                 [E1 東側樓梯]
                        │
                  [E0 東側門]
                        │
            [J? B2 走廊／分叉：位置待定]
                  ╱             ╲
       [C? 清潔間附近]        [W0 西側防火門]
             │                       │
      [B? B2 工作區]          [W1 西側樓梯]
```

- **已證實的相連關係**：B2 可以通往東側樓梯；往西側樓梯須經過西側防火門（CH13）。鐵時與老趙曾抵達東側樓梯口（CH14 老趙陳述）。
- **圖中問號代表未鎖定**：清潔間是否位於兩出口之間、工作區是否有其他隔間、走廊有無防火分區、J 節點是否存在單一分叉。**這些線條只表達待查路徑，不表達真實方位與距離。**
- **第四通的「一樓往下的樓梯口」**是 E1 上端可能位置，不等於 E0。要查鐵時從 B2 陪老趙到 E0、再上到一樓、通話後是否再下樓的順序；老趙說的「我上了幾階」也不能直接認定是鐵時最後折返的瞬間。
- **關鍵敘事風險**：若鐵時第四通時位於一樓，老趙最後見到他的時間就可能早於第四通；不能寫成「第四通後他才第一次帶老趙到樓梯口」，除非另有證據。
- **封門造成延誤的待證路徑**：須有一名受困者或另一獨立證人，能指出原本走向 W0、因無法開啟而折回的經過；不能讓老趙替自己沒有看見的西側情況作證。

3. **P0-C 煙流**：確認火源所在防火區劃、煙霧到達各走廊的合理順序；需專業校核，現階段**未驗證**。

## 六之一、五條不可互相替代的責任與因果證據鏈（CH21～25 寫作閘門）

**證據鏈 A｜危險存在。** 問題：火災前西側門是否由逃生方向無法開啟？現有 CH13 鐵時現場試門、照片、交接簿；CH15 僅取得部分影本。需補原始照片、原始報修、門體及扣件查驗。**能支持：事故前有具體危險。不能直接支持：火災當下仍鎖著、有人因此死亡。**

**證據鏈 B｜通知到達。** 問題：哪個人或單位在何時收到可辨識的警告？現有 CH13 郵件寄件確認、管理處回覆與交接；尚缺收件紀錄、處理流向、主管簽收或回覆原檔。**寄出不等於特定責任人已閱讀**；單位收到也不等於每位主管知情。

**證據鏈 C｜改善權限。** 問題：誰能核准解除固定、停止使用該動線、改標示或要求現場改善？CH17 只有舊契約範本與父親記憶；需實際有效契約、授權表、工單、業主核准文件與承攬分工。**有檢查義務不必然有加鎖核准權；曾審範本不等於曾批准現場改動。**

**證據鏈 D｜未改善與當時門況。** 問題：收到通知後是否採取措施，火災時 W0 是否仍無法從逃生方向開啟？CH13 星期五 21:30 的檢查只能證明該時點；需後續維修／解鎖工單、門禁紀錄、事故現場照片、消防勘驗及獨立證人。**21:30 無法開門，不自動等於火災時無法開門。**

**證據鏈 E｜具體傷害因果。** 問題：哪個人何時沿哪條路撤離、是否因 W0 折返、延誤多久、如何接觸煙熱、鐵時何時及為何再次下樓？目前 CH14 老趙只能說自己在東側樓梯的見聞，CH14 社工只能轉述未署名消息。需分開取得撤離者證詞、消防救援紀錄、可驗證的通聯／監控時間軸、火場及醫療專業資料。**西側門失效可以是重大危險或促成因素，但不能跳過實際暴露與折返過程就認定為單一死因。**

### P0 放行規則

- A～D 每條至少有一份**可追溯來源的原始資料**或明確標示限制的獨立證詞；缺少者只能寫成待查。
- E 必須能把**至少一位具體撤離者**的路線、W0 受阻及後續處境連起來，才能敘述「封門造成實際延誤」。鐵時死亡的法律與醫學因果另行論證。
- 「清潔間附近有人」「有人呼喊」「有人獲救」目前是三個**尚未證明同一身分**的線索。
- 任何新證人、火源位置、煙流時間、救援結果或簽核人姓名，都必須先在章節及證據表建立來源；不得為補完結論直接倒填。

### C. 作者選定的核心機制：兩條出口，不是一扇魔法門

- **事前的系統性危險**：西側出口在逃生方向受阻，且疏散標示仍指向該處；同時組織把「門禁防盜」「解除設備」「修改標示」「現場停用動線」拆成不同權限，讓已報修風險持續存在。
- **火警時的待證假說**：有人依標示往西，發現 W0 不能開，因而折返；煙熱使折返成本提高。此處至少要有一名具名或受保護代號的撤離者、其路線與原始時間來源，否則只保留為調查假說。
- **鐵時的行動**：先確定協助老趙走向東側的片段；第四通時已到一樓附近，正在核人數；之後的再次進入、遇險、死亡機制必須在後續章節**以證據逐格重建**。不要將老趙的「聽見喊叫」直接畫成鐵時衝入西側。
- **致死機制**：作者不以「門打不開→鐵時當場死亡」的跳接為定稿。火源、煙流、呼吸暴露、受困位置與救援先後須獨立成立；即使最後能認定封門是促成因素，也不等於它是唯一原因。
- **道德因果**：伍明的延誤、主管的敷衍、承攬責任切割與鐵時自身選擇可同時存在，但**不能互相抵銷**；個人英勇不替管理方免責，管理方失職也不消除伍明對自己選擇的反省。
