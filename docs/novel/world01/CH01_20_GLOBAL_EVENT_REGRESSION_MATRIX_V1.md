## 驗收程序與出口條件
1. **逐章全文**：每章列出 scene ID、視角、場景時序、人物所知、物證來源、原始稿對應位置，標出相互衝突的原句。
2. **跨章比對**：對所有事件建立唯一 ID，檢查同一事件在其他章節的日期、人物、地點、數量及因果描述。
3. **雙層判定**：機械可核對（文字／日期／數量／身分）與人工文學判斷（人物聲音／留白／節奏）分開；不可因文學好就跳過邏輯。
4. **修訂回歸**：每改一章，重新檢查 G 清單中所有相依章節；將變更、受影響章節、查核結果記入 commit。
5. **放行**：P0 全關閉、P1 有明確裁決與後續章節依據、角色弧線與文學審查通過，才可標「驗收通過」。未寫 CH21–30 不得借用章綱當正文。
