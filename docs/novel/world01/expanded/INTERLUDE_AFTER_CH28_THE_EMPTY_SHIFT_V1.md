# 《沒有寄出的事故報告》第一世界・擴寫版試寫
## 過渡章〈空出來的那一班〉

> 時間位置：CH28 梨奈事件之後、CH29 小澄救援任務之前。此章不新增死亡、不提前揭露其他人物命運；正式章號待全卷重排。

凌晨兩點，護理站的影印機吐出一張歪掉的班表。

小澄拿著那張紙去找值班督導。督導正在吃泡麵，筷子停在半空中。

「又少一個？」

「不是少一個。是同一個人排了兩個地方。」

督導把紙轉過來看。「支援病房那邊說可以借人。」

「他們借的是誰？」

「小林。」

「小林明天原本排了跟學姊一起帶教。」

「小林也不是第一天來了。」

小澄沒有接話。她把手上的筆放在桌邊，免得一開口就敲桌子。那是她以前會做的事，敲得太響，最後連自己原本想問什麼都忘了。

督導把泡麵蓋上。「妳想怎樣？」

「借調要有人接手帶教。不然就換一個能獨立值班的人。」

「那妳去跟病房說。」

「好。」

她轉身要走，督導又叫住她。

「妳現在很會講程序。可是那邊今天真的忙到有人連飯都沒吃。」

「我知道。」

「妳知道就好。」

小澄回到護理站，撥了三次電話才找到病房負責人。對方一聽見她的聲音就說：「拜託，不要再跟我說你們沒人。」

「我不是要收回支援。」小澄說，「我想問，你們缺的是能獨立照顧病人的人，還是能幫忙搬送、補物品的人？」

電話那頭安靜了一會兒。

「都缺。」

「如果只能先補一種？」

「能獨立照顧病人的。」

小澄看著排班表，想起新人小林昨天在交接時把藥袋拿錯，又在發現後急得差點哭出來。她沒有替小林隱瞞，也沒有因此認為小林永遠不能獨立工作。只是明天還不是那一天。

「我去確認誰能調。」她說。

掛斷電話，她才發現手機上有一通未接來電，是房東。上個月的租約要續簽，對方已經催過兩次。她點開訊息，房東說原本留給她的房間，早上八點以前要確認，否則就讓下一組人看。

她原本約好七點半去看房。現在如果留到八點處理借調，就趕不上。

她把手機放到口袋，去找督導。

「我可以留到早上八點，把借調安排完。」

「那八點以後呢？」

「我有事。」

督導抬頭看她。「妳以前不會這樣講。」

「我以前講不出口。」

「病人會因為妳有事就不需要人嗎？」

「不會。所以我現在先把人找好。」

督導最後協調另一個單位調來一名有經驗的護理師，代價是隔天下午的教育訓練必須延期。督導不高興，說要由小澄親自向講師解釋。小澄說好，當場打電話，沒有讓新人替她承受那句抱怨。

天亮後，小林拿著兩杯便利商店咖啡來找她。

「學姊，我聽說妳不讓我去支援。」

「我說明天不能讓妳一個人去。」

「妳覺得我不行？」

小澄把其中一杯推回去。「妳昨天那個藥袋，後來怎麼處理？」

「有重新核對，寫異常報告。」

「我知道。我看過。」

「那妳還不放心？」

「昨天妳發現藥袋拿錯，第一個找的是誰？」

「帶我的學姊。」

「明天那邊沒有人能讓妳這樣問。」

小林把咖啡拿走，沒說謝謝。

小澄叫了她一聲。小林沒回頭，兩杯咖啡都拿走了。小澄低頭看見桌上留下兩圈濕痕，抽了張衛生紙去擦，擦到一半又停下。

早上八點十分，交班完成。小澄搭車去看房，到了門口才看見七點四十八分的訊息：「不好意思，下一組已付訂金。」

她站在騎樓下，打開地圖，附近還有兩間房可看。第一間太貴，第二間沒有窗戶。她沒有立刻打電話給房東求情。

中午，小林傳來訊息：「下午教學延了，那下次什麼時候補？」

小澄回：「我明天排時間，妳選兩個能來的時段。」

隔了幾分鐘，小林傳來兩個日期，後面又補一句：「我沒有要妳幫我扛。」

小澄看著那句話，笑了一下，打了「我知道」又刪掉。

她回：「那妳下次自己跟督導說，妳需要誰帶。」

小林回了一個很醜的生氣貼圖。

小澄在公車站等車，買了一個飯糰。飯糰的海苔黏在包裝上，怎麼撕都撕不乾淨。她索性把海苔一起塞進嘴裡，邊吃邊查下一間房的地址。
