# 《薪水勇者》角色分類正式命名規範

狀態：使用者於 2026-11-12 正式確認。後續開發須遵循，除非使用者明確修改。

- **薪奴**：玩家主角，保留已核准的疲倦厭世、略瘦 Q 版日本大叔形象。不可改成熱血少年。
- **同事**：六人戰鬥編制中的可招募、養成、轉職角色；不再使用「社畜英傑」作為介面分類名稱。
- **同事編制**：六人隊伍管理、站位、流派與羈絆的介面名稱。
- **徵才**：招募同事的系統名稱（暫定介面配套名稱）。
- **員工名冊**：同事收藏／圖鑑的系統名稱（暫定介面配套名稱）。

角色分類「薪奴」與「同事」已確定；主角是否佔六人戰鬥欄位、同事總數、轉職與抽取規則仍待後續確認，不可把提案當成已核准規格。

任何介面文案與新功能以此命名為準；現有程式內部 ID 與存檔欄位不應為改名而直接破壞相容性。
