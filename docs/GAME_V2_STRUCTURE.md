## 1. 遊戲循環
- **上班（首頁・辦公室）**：薪奴在辦公室掛機，依台灣時間上班時段累積薪水、金幣、材料、同事訓練經驗；離線收益上限沿用（8 小時）。
- **下班（深度玩法）**：主線章節、每日副本、無限之塔、週末混亂、奇遇、傳記／覺醒副本。全部用同一套 **7 人編隊戰鬥**。
- **養成**：薪奴等級與轉職、同事等級／突破／升星、羈絆與融合、專武與覺醒、裝備／鍛造、技能、寵物、造型。

## 3. 戰鬥核心（7 人）
- 我方：薪奴 1（獨立欄位，站位依其職業）＋同事前排 3＋後排 3。敵方：波次。
- 每名角色：專屬逐格動作（待機、移動、普攻、受擊、大招＋特寫＋繪製特效，之後補格擋、倒地、勝利）。
- 玩家操作：每名角色能量滿可手動放大招（可切自動）、點敵人集火。
- 模擬沿用 `formation-combat-runtime`（純函式、可測），擴充為 7 人與站位規則。

3. **主城與章節地圖**（需美術）：主城場景、建築熱區、章節地圖、關卡點圖示。
