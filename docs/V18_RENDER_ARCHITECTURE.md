# V18 動態戰鬥美術架構與驗收門檻

## 不可違反的原則
- `art/v18/home-master.webp` 是構圖、風格、配色參考圖，**不得**作為動態戰鬥的永久背景。
- 禁止在包含靜態勇者、怪物、劍光的完整圖片上，再疊加第二套動態角色、怪物或劍光。
- 禁止用透明遮罩蓋住舊角色、假裝已經拆圖；不得用低品質 SVG 幾何圖代替已核定的角色美術。
- V17 正式遊戲與存檔保持不變，V18 新引擎獨立測試。

## 分層資產
1. **場景底圖**：不含勇者、怪物、劍光、傷害數字、UI 字樣；保留透視、光照和地面。
2. **勇者精靈**：獨立透明素材，至少待機、攻擊、受傷、勝利；裝備外觀能更換。
3. **敵人精靈**：獨立透明素材，至少待機、受擊、死亡；消失後不留殘影。
4. **特效**：獨立斬擊、命中、掉寶粒子；位置跟隨真實角色碰撞/攻擊節點。
5. **UI**：金幣、薪資、血量、戰鬥開關均由真實狀態渲染，不再把設計稿上的固定數字當成遊戲數值。
6. **辦公桌摸魚區**：獨立無角色背景與睡覺勇者/橘貓前景，和戰鬥區共享遊戲狀態。

## 施工順序
- V18.5：美術驗收頁修正（消除重複數字、版本文字）；不宣稱戰鬥已動態化。
- V18.6：製作/取得經核定的無角色戰場底圖、勇者/怪物透明素材；檢查空白底圖上沒有靜態人物殘留。
- V18.7：以真正狀態機製作移動/揮劍/受傷/死亡/重生、HP 與獎勵，動畫只渲染獨立精靈。
- V18.8：換裝外觀、摸魚事件、UI 狀態與自動託管接入；測試不同手機比例。

## 必須通過的驗收
- 關閉所有角色精靈後，戰場完全沒有勇者、怪物或劍光。
- 怪物 HP 歸零後，畫面中完全沒有該怪物。
- 換裝前後勇者外觀確實不同。
- 停止自動戰鬥時，攻擊和掉血都停止。
- 薪資與 HP 只有一份數值，並與遊戲狀態同步。
- iPhone Safari 上連續運行至少 5 分鐘，沒有雙影、畫面位移或遮擋主要按鈕。

## 目前狀態
`v18-art-test.html` 仍為整張設計稿的靜態展示/觸控原型；上面既有斬擊只是展示效果，**不能**算正式戰鬥動畫。只有完成獨立素材後才可開始正式戰鬥引擎接入。
