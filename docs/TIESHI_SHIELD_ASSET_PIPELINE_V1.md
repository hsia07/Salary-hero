# 終夜打卡盾：正式素材管線與時鐘規則 V1

## 狀態
- 本次新增純邏輯模組 `v19/tieshi-clock.mjs` 與對應測試；尚未接到戰鬥畫面。
- 目前圖片為設計參考圖，不是可編輯的分層 PSD/透明素材，不得標記正式完成。

## 必須分層的美術
1. shield/frame：黑金金屬外框（透明 PNG）
2. shield/plate：深色盾面（透明 PNG）
3. shield/emblem：公會／企業徽記（透明 PNG）
4. shield/clock-housing：時鐘外殼（透明 PNG）
5. shield/clock-display：數字顯示區背景（透明 PNG）
6. clock/digits：以程式控制 08:59 或 09:00，禁止將數字烙印到盾牌圖片
7. shield/straps：背面握把、固定帶（透明 PNG）
8. vfx/block、vfx/bash、vfx/intercept、vfx/ultimate：獨立特效序列

## 時間狀態
- 預設 08:59，與真實世界時間無關。
- 傳記完成且覺醒必殺正在播放時短暫顯示 09:00，結束後恢復 08:59。
- 不能單靠升星或抽到卡面就解鎖 09:00。
- `tieshiClockDigits` 提供可單獨渲染的時、分、冒號。
- `canTriggerTieshiAwakenedUltimate` 提供傳記完成、能量、冷卻與存活狀態的門檻判定。

## 美術驗收
- 清晰、去 AI 雜訊與破碎邊緣；無錯字、無多餘手指、無無意義裝飾。
- 正式立繪採正常成人比例；Q 版只在戰鬥。
- 角色、盾牌、數字、魔法特效必須能獨立組裝。
- 動作需有前搖、碰撞、收招；命中與碰撞時機同步，不以單張圖片抖動代替。
