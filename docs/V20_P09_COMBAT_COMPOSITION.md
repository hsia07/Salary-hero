# 薪水勇者 V20 P0.9｜戰鬥構圖與接地修正

開發日期：2026-11-11
驗收定位：**正式遊戲畫面構圖修正，不等於完整美術驗收通過。**

## 根據玩家 iPhone 畫面所修正
- 角色已是核准的疲倦 Q 版日本社畜，保持形象、七格攻擊與五格受傷素材不變。
- 舊版敵人中心固定接近畫面最右側，且 720×620 Canvas 上有一整塊右側戰利品 DOM 浮層，敵人右半被遮蔽。正式模式把普通／菁英／首領中心分別向內收，並保留各自足夠寬度。
- 新增 v20-battle-stage.mjs 作為純構圖資料與接地光影。練習／訓練模式保持原始的 heroX=100、enemyX=458，確保既有動畫驗證不變。
- 傷害彈字由絕對 x=546 改為跟隨實際敵人 x+90，以免移動敵人後文字飄錯位置。
- 角色與敵人採用兩層真正漸層接地陰影加微弱暖光反射，維持地板透視感，不做整張 sprite 的假搖晃。
- 右側戰利品欄縮短邊框間距與按鈕高度，避免壓在 HP 上；最低視窗 320×568 啟動更緊湊佈局；底部導覽、薪資、真人存檔與互動均維持原方式。
- 淡化覆蓋戰場的額外 SVG 裝飾，真正的 WebP 環境繪景依舊存在並繼續使用。
